# 1. Understanding problem-solving patterns

## 1.1 What is a problem-solving pattern?

A problem-solving pattern is a reusable approach to solving a particular category of problems. Knowing how to write a loop is different from knowing how to use a loop to solve a problem.

Consider `const numbers = [12, 7, 4, 19, 8];`. You could count even numbers, calculate the sum, find the largest number, determine whether a negative number exists, extract numbers greater than 10 or double every number.

## 1.2 Loop syntax versus problem-solving logic

The loop provides the mechanism for visiting every element. What you do inside the loop determines the problem being solved.

| Pattern          | Result                |
|------------------|-----------------------|
| Counting         | 3 even numbers        |
| Accumulation     | Sum = 50              |
| Maximum tracking | Largest = 19          |
| Filtering        | \[12, 19\]            |
| Searching        | No negative number    |
| Transformation   | \[24, 14, 8, 38, 16\] |

## 1.3 The fundamental structure

```js
const numbers = [12, 7, 4, 19, 8];
let result = 0;
for (const number of numbers) {
  result += number;
}
console.log(result);
```

| Component      | Purpose                       |
|----------------|-------------------------------|
| Input          | Data to process               |
| Initialization | Establish initial state       |
| Traversal      | Visit relevant elements       |
| Processing     | Examine or update information |
| Result         | Produce final answer          |

## 1.4 Mental model

**Visit â†’ Examine â†’ Decide â†’ Update â†’ Repeat.**

# 2. Counting pattern

## Understanding counting

Counting determines how many times something occurs or how many elements satisfy a condition. A counter stores the number of occurrences encountered so far.

## Problem: Count even numbers

```js
const numbers = [12, 7, 4, 19, 8];
let count = 0;
for (const number of numbers) {
  if (number % 2 === 0) {
    count++;
  }
}
console.log(count); // 3
```

## Detailed breakdown

`let count = 0` initializes the counter outside the loop so it retains its value. `for (const number of numbers)` retrieves the current element. `number % 2 === 0` first calculates the remainder, then compares it with zero. For 12: `12 % 2` â†’ `0` â†’ `0 === 0` â†’ `true`. For 7: `7 % 2` â†’ `1` â†’ `false`. `count++` is equivalent here to `count = count + 1`. It counts occurrences, not values.

| Number | Condition | Count before | Count after |
|-------:|-----------|-------------:|------------:|
|     12 | True      |            0 |           1 |
|      7 | False     |            1 |           1 |
|      4 | True      |            1 |           2 |
|     19 | False     |            2 |           2 |
|      8 | True      |            2 |           3 |

## General pattern

```js
let count = 0;
for (const item of collection) {
  if (condition) {
    count++;
  }
}
```

**Mental model:** Whenever an element satisfies the condition, increase the counter by one.

# 3. Accumulation pattern

Accumulation involves progressively combining values into a stored result. Unlike counting, accumulation updates the result using the value being processed.

## Calculate the sum

```js
const numbers = [10, 20, 30, 40];
let total = 0;
for (const number of numbers) {
  total += number;
}
console.log(total); // 100
```

`total += number` means `total = total + number`. If total is 30 and number is 30, the new total is 60. The previous result becomes part of the next result.

| Number | Previous total | New total |
|-------:|---------------:|----------:|
|     10 |              0 |        10 |
|     20 |             10 |        30 |
|     30 |             30 |        60 |
|     40 |             60 |       100 |

## Conditional accumulation

```js
const numbers = [12, 7, 4, 19, 8];
let total = 0;
for (const number of numbers) {
  if (number % 2 === 0) total += number;
}
console.log(total); // 24
```

## Multiplicative accumulation

```js
const numbers = [2, 3, 4];
let product = 1;
for (const number of numbers) {
  product *= number;
}
console.log(product); // 24
```

`product *= number` means `product = product * number`. Initialize to 1 because multiplying by zero would keep the result zero.

## String accumulation

```js
const letters = ["J", "S", "L", "O", "O", "P"];
let word = "";
for (const letter of letters) {
  word += letter;
}
console.log(word); // JSLOOP
```

| Operation            | Initial value |
|----------------------|---------------|
| Addition             | `0`           |
| Multiplication       | `1`           |
| String concatenation | `""`          |
| Collecting elements  | `[]`          |

Counting adds one and answers how many; accumulation adds the current value and answers how much.

**Mental model:** Combine the current value with the result accumulated so far.

# 4. Searching pattern

Searching examines elements until a particular value or condition is found. It may return a value, index, existence or all matches.

## Find the first negative number

```js
const numbers = [12, 7, 4, -5, 20, -8];
let found = null;
for (const number of numbers) {
  if (number < 0) {
    found = number;
    break;
  }
}
console.log(found); // -5
```

`null` represents no result. `number < 0` tests negativity. `found = number` stores the match. `break` stops immediately. The first three elements fail, -5 matches, and 20 and -8 are not visited.

## Search for an index

```js
const numbers = [12, 7, 4, 19, 8];
let foundIndex = -1;
for (let i = 0; i < numbers.length; i++) {
  if (numbers[i] === 19) {
    foundIndex = i;
    break;
  }
}
console.log(foundIndex); // 3
```

At i = 3, `numbers[i] === 19` becomes `numbers[3] === 19`, then `19 === 19`, which is true. Store the index rather than the value. -1 cannot conflict with a valid array index.

## Search for the last match

```js
const numbers = [12, -7, 4, -19, 8];
let found = null;
for (const number of numbers) {
  if (number < 0) found = number;
}
console.log(found); // -19
```

There is no break because later matches must be examined. Alternatively traverse backward and stop at the first match.

**Mental model:** Examine elements until the required match is found, then stop if further searching is unnecessary.

# 5. Filtering pattern

Filtering creates a collection containing only elements satisfying a condition. It normally examines the entire collection.

```js
const numbers = [12, 7, 4, 19, 8];
const result = [];
for (const number of numbers) {
  if (number % 2 === 0) {
    result.push(number);
  }
}
console.log(result); // [12, 4, 8]
```

`const result = []` creates an empty array. Its contents can be modified despite const. `result.push(number)` appends the current number. If result is \[12\] and number is 4, it becomes \[12, 4\].

| Processed number | Result       |
|------------------|--------------|
| 12               | \[12\]       |
| 7                | \[12\]       |
| 4                | \[12, 4\]    |
| 19               | \[12, 4\]    |
| 8                | \[12, 4, 8\] |

Other conditions: odd â†’ \[7, 19\]; greater than 10 â†’ \[12, 19\].

## General pattern

```js
const result = [];
for (const item of collection) {
  if (condition) result.push(item);
}
```

Counting uses `count++`; filtering uses `result.push(number)`. The condition can remain identical.

**Mental model:** Examine every element and collect only those that satisfy the condition.

# 6. Transformation pattern

Transformation converts each element into a new value according to a rule, such as doubling numbers, converting temperatures or changing text to uppercase.

```js
const numbers = [2, 4, 6, 8];
const result = [];
for (const number of numbers) {
  const doubled = number * 2;
  result.push(doubled);
}
console.log(result); // [4, 8, 12, 16]
```

When number is 6, `const doubled = number * 2` becomes `const doubled = 6 * 2`, then `const doubled = 12`. `result.push(doubled)` stores 12. The shorter `result.push(number * 2)` evaluates multiplication before calling push.

| Input | Rule | Output |
|------:|------|-------:|
|     2 | Ã—2   |      4 |
|     4 | Ã—2   |      8 |
|     6 | Ã—2   |     12 |
|     8 | Ã—2   |     16 |

## Transform the original array

```js
const numbers = [2, 4, 6, 8];
for (let i = 0; i < numbers.length; i++) {
  numbers[i] = numbers[i] * 2;
}
console.log(numbers);
```

At i = 1, `numbers[1] = numbers[1] * 2` becomes `numbers[1] = 4 * 2`, then `numbers[1] = 8`.

Filtering selects elements and may produce fewer; transformation converts elements and usually produces one output per input.

**Mental model:** Take each element, apply a rule and store the resulting value.

# 7. Tracking minimum and maximum values

Tracking maintains the best candidate encountered so far rather than combining every value.

```js
const numbers = [12, 7, 25, 19, 30, 8];
let largest = numbers[0];
for (const number of numbers) {
  if (number > largest) largest = number;
}
console.log(largest); // 30
```

`numbers[0]` retrieves 12 as the initial candidate. `number > largest` compares the current value with the record. `largest = number` replaces the record only when a better candidate appears.

| Current | Previous largest | New largest |
|--------:|-----------------:|------------:|
|      12 |               12 |          12 |
|       7 |               12 |          12 |
|      25 |               12 |          25 |
|      19 |               25 |          25 |
|      30 |               25 |          30 |
|       8 |               30 |          30 |

Initializing to zero fails for \[-12, -7, -25\] because zero is not an element. Using the first element assumes a nonempty array.

## Minimum and maximum

```js
let smallest = numbers[0];
let largest = numbers[0];
for (const number of numbers) {
  if (number < smallest) smallest = number;
  if (number > largest) largest = number;
}
```

The smallest is 7 and largest is 30. A single traversal can maintain multiple pieces of information.

**Mental model:** Remember the best candidate and replace it whenever a better candidate appears.

# 8. Boolean flag tracking

A flag stores a boolean representing whether a condition or event has occurred.

## Any negative number?

```js
const numbers = [12, 7, 4, -5, 8];
let hasNegative = false;
for (const number of numbers) {
  if (number < 0) {
    hasNegative = true;
    break;
  }
}
console.log(hasNegative); // true
```

Start false because no match has been encountered. One match is sufficient to set true and stop.

## Are all numbers positive?

```js
let allPositive = true;
for (const number of numbers) {
  if (number <= 0) {
    allPositive = false;
    break;
  }
}
console.log(allPositive); // false
```

Start true until a violation is found. Both zero and negative numbers violate positivity. For an empty collection, any returns false and all returns true.

**Mental model:** Maintain a boolean answer and change it when sufficient evidence is encountered.

# 9. Frequency counting pattern

Frequency counting maintains a separate count for each distinct value.

```js
const fruits = ["apple", "banana", "apple", "orange", "banana", "apple"];
const frequency = {};
for (const fruit of fruits) {
  if (Object.hasOwn(frequency, fruit)) {
    frequency[fruit]++;
  } else {
    frequency[fruit] = 1;
  }
}
console.log(frequency); // { apple: 3, banana: 2, orange: 1 }
```

`frequency[fruit]` accesses a dynamic property. When fruit is "apple", it becomes `frequency["apple"]`. `frequency.fruit` instead accesses a literal property named fruit. `Object.hasOwn(frequency, fruit)` checks for an existing own property. Increment an existing count or initialize it to one.

| Fruit  | Apple | Banana | Orange |
|--------|------:|-------:|-------:|
| apple  |     1 |      0 |      0 |
| banana |     1 |      1 |      0 |
| apple  |     2 |      1 |      0 |
| orange |     2 |      1 |      1 |
| banana |     2 |      2 |      1 |
| apple  |     3 |      2 |      1 |

## Shorter expression

```js
const frequency = {};
for (const fruit of fruits) {
  frequency[fruit] = (frequency[fruit] ?? 0) + 1;
}
```

The nullish coalescing operator returns zero when the existing value is null or undefined. First apple: `(undefined ?? 0) + 1` â†’ `0 + 1` â†’ `1`. Second apple: `(1 ?? 0) + 1` â†’ `2`. For arbitrary property names prefer a Map or `Object.create(null)`.

**Mental model:** Maintain a separate counter for each distinct value encountered.

# 10. Previous and current element comparison

Neighboring comparisons examine relationships between consecutive elements, such as increases, decreases and adjacent duplicates.

```js
const numbers = [10, 15, 12, 20, 25, 18];
let count = 0;
for (let i = 1; i < numbers.length; i++) {
  if (numbers[i] > numbers[i - 1]) count++;
}
console.log(count); // 3
```

Start at index 1 because index 0 has no predecessor. At i = 2, `numbers[i]` retrieves 12; `numbers[i - 1]` becomes `numbers[2 - 1]`, then `numbers[1]`, retrieving 15. `12 > 15` is false.

| Previous | Current | Increased? | Count |
|---------:|--------:|------------|------:|
|       10 |      15 | Yes        |     1 |
|       15 |      12 | No         |     1 |
|       12 |      20 | Yes        |     2 |
|       20 |      25 | Yes        |     3 |
|       25 |      18 | No         |     3 |

## Adjacent duplicates

```js
const numbers = [2, 2, 5, 7, 7, 9];
for (let i = 1; i < numbers.length; i++) {
  if (numbers[i] === numbers[i - 1]) console.log(numbers[i]);
}
// 2, 7
```

**Mental model:** Compare the current element with its immediate neighbor to identify relationships or changes.

# 11. State management pattern

State is information remembered between iterations. Counters, accumulators, trackers and flags are all forms of state.

## Track a bank balance

```js
const transactions = [50, -20, 100, -30, -10];
let balance = 100;
for (const transaction of transactions) {
  balance += transaction;
}
console.log(balance); // 190
```

Each transaction changes the balance inherited by the next iteration: 100 â†’ 150 â†’ 130 â†’ 230 â†’ 200 â†’ 190.

## Conditional state updates

```js
const transactions = [50, -200, 100, -30];
let balance = 100;
for (const transaction of transactions) {
  if (balance + transaction >= 0) balance += transaction;
}
console.log(balance); // 220
```

If balance is 150 and transaction is -200, `balance + transaction >= 0` becomes `150 + (-200) >= 0`, then `-50 >= 0`, which is false. The transaction is rejected.

| Transaction | Proposed balance | Accepted? | Actual balance |
|------------:|-----------------:|-----------|---------------:|
|         +50 |              150 | Yes       |            150 |
|        -200 |              -50 | No        |            150 |
|        +100 |              250 | Yes       |            250 |
|         -30 |              220 | Yes       |            220 |

**Mental model:** Remember the current state, evaluate the incoming event and update according to the rule.

# 12. Consecutive element tracking

Consecutive occurrences appear continuously without interruption. In \[1, 1, 0, 1, 1, 1, 0, 1\], six ones occur in groups of lengths 2, 3 and 1.

```js
const numbers = [1, 1, 0, 1, 1, 1, 0, 1];
let currentStreak = 0;
let longestStreak = 0;
for (const number of numbers) {
  if (number === 1) {
    currentStreak++;
    if (currentStreak > longestStreak) {
      longestStreak = currentStreak;
    }
  } else {
    currentStreak = 0;
  }
}
console.log(longestStreak); // 3
```

`currentStreak` stores the length currently being processed. `longestStreak` stores the record anywhere in the array. Increment the current streak on a one, compare with the record, update if larger. Reset only the current streak on interruption.

| Number | Current streak | Longest streak |
|-------:|---------------:|---------------:|
|      1 |              1 |              1 |
|      1 |              2 |              2 |
|      0 |              0 |              2 |
|      1 |              1 |              2 |
|      1 |              2 |              2 |
|      1 |              3 |              3 |
|      0 |              0 |              3 |
|      1 |              1 |              3 |

**Mental model:** Extend the current sequence when the condition holds, reset it when interrupted and preserve the best sequence.

# 13. Running totals

A running total records the accumulated result after each iteration rather than only the final result.

```js
const numbers = [10, 20, 30, 40];
let total = 0;
const result = [];
for (const number of numbers) {
  total += number;
  result.push(total);
}
console.log(result); // [10, 30, 60, 100]
```

`total += number` updates the accumulated total. `result.push(total)` stores a snapshot. Reversing these operations produces \[0, 10, 30, 60\] because the previous total is stored first.

| Number | Updated total | Result array        |
|-------:|--------------:|---------------------|
|     10 |            10 | \[10\]              |
|     20 |            30 | \[10, 30\]          |
|     30 |            60 | \[10, 30, 60\]      |
|     40 |           100 | \[10, 30, 60, 100\] |

**Mental model:** Accumulate a value and preserve the accumulated result after every iteration.

# 14. Combining problem-solving patterns

Real-world problems frequently require multiple patterns working together.

## Average of positive numbers

```js
const numbers = [10, -5, 20, 0, 30, -8];
let total = 0;
let count = 0;
for (const number of numbers) {
  if (number > 0) {
    total += number;
    count++;
  }
}
const average = count > 0 ? total / count : null;
console.log(average); // 20
```

Selection recognizes positive numbers; accumulation sums them; counting determines how many exist; final computation divides total by count. Both updates occur inside the same condition.

`count > 0 ? total / count : null` is the ternary operator: `condition ? valueIfTrue : valueIfFalse`. It avoids division by zero. Equivalent:

```js
let average;
if (count > 0) {
  average = total / count;
} else {
  average = null;
}
```

| Number | Positive? | Total | Count |
|-------:|-----------|------:|------:|
|     10 | Yes       |    10 |     1 |
|     -5 | No        |    10 |     1 |
|     20 | Yes       |    30 |     2 |
|      0 | No        |    30 |     2 |
|     30 | Yes       |    60 |     3 |
|     -8 | No        |    60 |     3 |

Final calculation: 60 / 3 = 20.

**Mental model:** Break a complex requirement into smaller patterns and maintain the necessary state for each.

# 15. Loop problem-solving methodology

Before writing code, understand the problem.

| Question                            | Purpose                       |
|-------------------------------------|-------------------------------|
| What is the input?                  | Identify data                 |
| What is the expected output?        | Identify result               |
| What repeats?                       | Determine traversal           |
| What condition matters?             | Determine selection           |
| What must be remembered?            | Determine state variables     |
| How does state change?              | Determine update expressions  |
| When should processing stop?        | Determine termination         |
| When should the result be produced? | Determine operation placement |

| Requirement            | Pattern        | Operation                   |
|------------------------|----------------|-----------------------------|
| How many?              | Counting       | `count++`                   |
| Combined value?        | Accumulation   | `total += value`            |
| Where is the match?    | Searching      | `found = value; break;`     |
| Which elements?        | Filtering      | `result.push(value)`        |
| What does each become? | Transformation | `result.push(newValue)`     |
| Best value?            | Tracking       | `best = value`              |
| Does a condition hold? | Flag           | `found = true`              |
| How often each value?  | Frequency      | `frequency[value]++`        |
| Neighbor relationship? | Comparison     | `values[i] > values[i - 1]` |
| Longest sequence?      | Streak         | `currentStreak++`           |

| Situation                                   | Appropriate loop |
|---------------------------------------------|------------------|
| Array values                                | `for...of`       |
| Indexes or neighbors                        | `for`            |
| Uncertain condition                         | `while`          |
| Execute at least once                       | `do...while`     |
| Enumerable object keys                      | `for...in`       |
| Combinations or multidimensional structures | Nested loops     |

These are practical defaults, not strict restrictions. Initialize persistent state outside the loop. Initializing `let total = 0` inside the loop resets it each iteration.

```js
const collection = [];
let result;
for (const item of collection) {
  // Examine the current item
  // Evaluate relevant conditions
  // Update the state
}
// Produce the final result
```

## Exercise 1: Count numbers divisible by three

**Question:** Given `[3, 7, 9, 12, 14, 18]`, count numbers divisible by three.

**Expected output:** `4`

**Hint:** Use remainder zero.

**Problem-solving pattern:** Counting

### Solution

```js
const numbers = [3, 7, 9, 12, 14, 18];
let count = 0;
for (const number of numbers) {
  if (number % 3 === 0) count++;
}
console.log(count);
```

### Detailed code and expression breakdown

Initialize count to zero. For 9, `9 % 3 === 0` becomes `0 === 0`, true. Increment for each match.

### Execution trace

Input visited: `3, 7, 9, 12, 14, 18`.

State progression: `0 â†’ 1 â†’ 1 â†’ 2 â†’ 3 â†’ 3 â†’ 4`.

The counter changes only when the remainder is zero.

## Exercise 2: Sum numbers greater than ten

**Question:** Given `[5, 12, 8, 20, 3, 15]`, sum numbers greater than ten.

**Expected output:** `47`

**Hint:** Select values greater than 10.

**Problem-solving pattern:** Conditional accumulation

### Solution

```js
const numbers = [5, 12, 8, 20, 3, 15];
let total = 0;
for (const number of numbers) {
  if (number > 10) total += number;
}
console.log(total);
```

### Detailed code and expression breakdown

`number > 10` selects 12, 20 and 15. `total += number` combines them: 12 + 20 + 15 = 47.

### Execution trace

Input visited: `5, 12, 8, 20, 3, 15`.

State progression: `0 â†’ 0 â†’ 12 â†’ 12 â†’ 32 â†’ 32 â†’ 47`.

Rejected values leave the total unchanged.

## Exercise 3: Find the first number greater than twenty

**Question:** Given `[5, 12, 8, 25, 30, 15]`, find the first number greater than twenty.

**Expected output:** `25`

**Hint:** Store the first match and break.

**Problem-solving pattern:** Searching

### Solution

```js
const numbers = [5, 12, 8, 25, 30, 15];
let found = null;
for (const number of numbers) {
  if (number > 20) {
    found = number;
    break;
  }
}
console.log(found);
```

### Detailed code and expression breakdown

Null represents no result. The condition tests each value. Store 25 and break before 30 is examined.

### Execution trace

Input visited: `5, 12, 8, 25`.

State progression: `null â†’ null â†’ null â†’ 25`.

The break prevents visiting 30 and 15.

## Exercise 4: Extract negative numbers

**Question:** Given `[12, -7, 4, -19, 8, -2]`, extract negative numbers.

**Expected output:** `[-7, -19, -2]`

**Hint:** Append matching elements to an empty array.

**Problem-solving pattern:** Filtering

### Solution

```js
const numbers = [12, -7, 4, -19, 8, -2];
const result = [];
for (const number of numbers) {
  if (number < 0) result.push(number);
}
console.log(result);
```

### Detailed code and expression breakdown

Create a result array. `number < 0` selects negatives. `push` appends without modifying the original array.

### Execution trace

Input visited: `12, -7, 4, -19, 8, -2`.

State progression: `[] â†’ [-7] â†’ [-7, -19] â†’ [-7, -19, -2]`.

Only accepted values are appended.

## Exercise 5: Square every number

**Question:** Given `[2, 3, 4, 5]`, square every number.

**Expected output:** `[4, 9, 16, 25]`

**Hint:** Multiply each number by itself.

**Problem-solving pattern:** Transformation

### Solution

```js
const numbers = [2, 3, 4, 5];
const result = [];
for (const number of numbers) {
  result.push(number * number);
}
console.log(result);
```

### Detailed code and expression breakdown

For 4, `number * number` becomes `4 * 4`, producing 16. Push stores the evaluated result.

### Execution trace

Input visited: `2, 3, 4, 5`.

State progression: `4, 9, 16, 25`.

For example, 4 * 4 evaluates to 16 before push runs.

State progression: `18 â†’ 18 â†’ 5 â†’ 5 â†’ -3 â†’ -3`.

The record changes only when a smaller value appears.

## Exercise 7: Check whether all numbers are even

**Question:** Given `[2, 4, 8, 9, 12]`, check whether all numbers are even.

**Expected output:** `false`

**Hint:** Assume true until an odd number appears.

**Problem-solving pattern:** Boolean flag tracking

### Solution

```js
const numbers = [2, 4, 8, 9, 12];

for (const number of numbers) {
  if (number % 2 !== 0) {
    allEven = false;
    break;
```

### Detailed code and expression breakdown

### Execution trace

State progression: `true â†’ true â†’ true â†’ false`.

9 % 2 is 1, so the inequality with zero is true; break stops traversal.

## Exercise 8: Count character frequencies

**Question:** Given `"banana"`, count character frequencies.

**Expected output:** `{ b: 1, a: 3, n: 2 }`

## Exercise 9: Count decreases in a sequence

**Question:** Given `[10, 8, 12, 7, 6, 15]`, count decreases in a sequence.

**Expected output:** `3`

**Hint:** Start at index 1.

**Problem-solving pattern:** Neighbor comparison

### Solution

```js
const numbers = [10, 8, 12, 7, 6, 15];

for (let i = 1; i < numbers.length; i++) {
  if (numbers[i] < numbers[i - 1]) count++;
}

```

### Detailed code and expression breakdown

`i - 1` retrieves the preceding index. Detect 8 \< 10, 7 \< 12 and 6 \< 7. Increment for each decrease.

### Execution trace

Input visited: `10, 8, 12, 7, 6, 15`.

State progression: `0 â†’ 1 â†’ 1 â†’ 2 â†’ 3 â†’ 3`.

Compare current with previous, not with the running minimum.

## Exercise 10: Track the longest positive streak

**Question:** Given `[2, 4, -1, 5, 7, 8, -2, 3]`, track the longest positive streak.

**Expected output:** `3`

**Hint:** Maintain current and longest streaks.

**Problem-solving pattern:** Consecutive tracking

### Solution

```js
const numbers = [2, 4, -1, 5, 7, 8, -2, 3];
let current = 0;
let longest = 0;
for (const number of numbers) {
  if (number > 0) {
    current++;
    if (current > longest) longest = current;
  } else {
    current = 0;
  }
}
console.log(longest);
```

### Detailed code and expression breakdown

Extend current when positive, compare with longest and update the record. Reset current on interruption but preserve longest.

### Execution trace

Input visited: `2, 4, -1, 5, 7, 8, -2, 3`.

State progression: `Current: 1, 2, 0, 1, 2, 3, 0, 1; best: 1, 2, 2, 2, 2, 3, 3, 3`.

Reset the current streak but retain the best.

## Exercise 12: Calculate the average of even numbers

**Question:** Given `[2, 7, 4, 9, 6, 8]`, calculate the average of even numbers.

**Expected output:** `5`

**Hint:** Maintain both sum and count.

**Problem-solving pattern:** Counting and accumulation

### Solution

```js
const numbers = [2, 7, 4, 9, 6, 8];
let total = 0;
let count = 0;
for (const number of numbers) {
  if (number % 2 === 0) {
    total += number;
    count++;
  }
}
const average = count > 0 ? total / count : null;
console.log(average);
```

### Detailed code and expression breakdown

Select 2, 4, 6 and 8. Total is 20 and count is 4. Divide 20 / 4 = 5. The condition prevents division by zero.

### Execution trace

Input visited: `2, 7, 4, 9, 6, 8`.

State progression: `(2,1) â†’ (2,1) â†’ (6,2) â†’ (6,2) â†’ (12,3) â†’ (20,4)`.

Each pair is (total, count); the final average is 20 / 4 = 5.

|---|---|

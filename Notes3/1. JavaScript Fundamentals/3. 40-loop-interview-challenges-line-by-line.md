## Micro-lessons: every symbol matters

### The expression you asked about: `run = attended[i] ? run + 1 : 0;`

Read this one character group at a time:

```javascript
run = attended[i] ? run + 1 : 0;
```

1. `run` (left of `=`): the variable we want to update. It represents the number of consecutive attended days ending today.
2. `=`: assignment. Compute the entire expression on the right, then store its result in `run`. It does **not** test equality.
3. `attended`: an array such as `[true, true, false]`.
4. `[i]`: get the value at index `i`. For `i = 0`, `attended[0]` is the first entry.
5. `?`: begins the ternary operator; the part before it is the condition.
6. `run + 1`: if today is truthy (`true`), take the **previous** streak and add one.
7. `:`: separates the truthy branch from the falsy branch.
8. `0`: if today is falsy (`false`), reset the current streak to zero.
9. `;`: ends the statement.

The exact equivalent written with `if...else`:

```javascript
if (attended[i]) {
  run = run + 1;
} else {
  run = 0;
}
```

**Manual trace** (starting `run = 0`):

| `i` | `attended[i]` | Condition | Calculation | New `run` |
|---:|---|---|---|---:|
| 0 | `true` | Truthy | `0 + 1` | 1 |
| 1 | `true` | Truthy | `1 + 1` | 2 |
| 2 | `false` | Falsy | Choose `0` | 0 |
| 3 | `true` | Truthy | `0 + 1` | 1 |

**Why it matters:** a ternary is an *expression that produces a value*. The assignment stores that value. It is not the same as writing `if (attended[i]) run++;` because the latter would not reset the streak on absence.

### Read common operators slowly

| Syntax | Expanded beginner interpretation |
|---|---|
| `x += y` | `x = x + y`; add and store |
| `x++` | Increase `x` by one |
| `x--` | Decrease `x` by one |
| `i < a.length` | Keep going while `i` is smaller than the number of elements |
| `a[i]` | Element of array `a` at zero-based index `i` |
| `a[i][j]` | Element `j` inside the nested array at position `i` |
| `x === y` | Same type and value |
| `x !== y` | Not strictly equal |
| `a && b` | Both conditions must be truthy |
| `a || b` | At least one condition must be truthy |
| `condition ? a : b` | If condition truthy use `a`; otherwise use `b` |
| `break` | Leave nearest loop |
| `continue` | Skip the rest of this iteration |
| `const [a, b] = pair` | Unpack first and second items into `a` and `b` |

### Nested-loop mental model

```text
Outer loop chooses a group
|-- Inner loop chooses an item inside that group
|   |-- Process item
|   \-- Repeat for remaining items
\-- Move to next group

Three levels:
Store --> Department --> Product --> Process
```

For three levels, the deepest body runs once per innermost element, **not** automatically `n^3` unless all three dimensions have size `n`.

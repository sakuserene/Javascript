## 1. Learning objectives

By the end of this lesson, you should be able to explain the `dblclick` event, register and remove listeners, describe its relationship to `click`, inspect the `MouseEvent` interface, use coordinates and `detail`, reason about propagation and delegation, avoid conflicting click/double-click actions, handle synthetic events, and design keyboard- and touch-accessible alternatives. You will also build two complete runnable projects and practice with questions and exercises.

## 2. What is dblclick?

`dblclick` is dispatched when the browser recognizes a qualifying double-click interaction, ordinarily using the primary pointing-device button.

```html
<button id="myButton" type="button">Double-click me</button>
<script>
  const button = document.getElementById("myButton");
  button.addEventListener("dblclick", function () {
    console.log("Button double-clicked!");
  });
</script>
```

The correct event name is **`"dblclick"`**, not `"doubleclick"`. The browser decides whether the timing and position of two clicks qualify as a double-click.

## 3. Event sequence

A typical primary-mouse-button double-click produces:

```text
mousedown -> mouseup -> click (detail 1)
mousedown -> mouseup -> click (detail 2)
dblclick (detail 2)
```

Pointer and focus events may also occur. This is a simplified common sequence, not a universal guarantee for all devices and browsers.

## 4. Click versus dblclick

| Feature | `click` | `dblclick` |
|---|---|---|
| Meaning | Completed activation | Recognized double-click |
| Typical event interface | `PointerEvent` in modern browsers | `MouseEvent` |
| Bubbles | Yes | Yes |
| Cancelable | Yes | Yes |
| Composed | Yes | Yes |
| Native keyboard activation | Yes for native buttons | No standard equivalent |
| Touch support | Broad | Double-tap not reliably mapped to `dblclick` |
| Typical `detail` | 1, then 2 | 2 |

## 5. Registering listeners

```javascript
function handleDoubleClick(event) {
  console.log("Double-click:", event.target);
}

button.addEventListener("dblclick", handleDoubleClick);
button.removeEventListener("dblclick", handleDoubleClick);
```

Pass `handleDoubleClick` without parentheses: `handleDoubleClick()` would call it immediately. Anonymous functions and arrow functions can also serve as callbacks.

## 6. Listener options

```javascript
const controller = new AbortController();
button.addEventListener("dblclick", handleDoubleClick, {
  capture: false,
  once: false,
  passive: false,
  signal: controller.signal
});
controller.abort(); // Removes this listener.
```

| Option | Default | Purpose |
|---|---|---|
| `capture` | `false` | Listen during capture |
| `once` | `false` | Remove after first invocation |
| `passive` | Usually `false` | Promise not to cancel default behavior |
| `signal` | None | Remove when signal aborts |

`addEventListener()` returns `undefined`. A Boolean third argument is shorthand for `capture`.

## 7. MouseEvent inheritance

```text
Event
  `-- UIEvent
        `-- MouseEvent
```

A browser-generated `dblclick` event is a `MouseEvent`:

```javascript
button.addEventListener("dblclick", function (event) {
  console.log(event instanceof MouseEvent); // true
});
```

## 8. Event property inventory

**Event properties:** `type`, `target`, `currentTarget`, `eventPhase`, `bubbles`, `cancelable`, `composed`, `defaultPrevented`, `isTrusted`, `timeStamp`.

**UIEvent properties:** `detail`, `view`.

**MouseEvent properties:** `screenX`, `screenY`, `clientX`, `clientY`, `pageX`, `pageY`, `offsetX`, `offsetY`, `movementX`, `movementY`, `button`, `buttons`, `ctrlKey`, `shiftKey`, `altKey`, `metaKey`, `relatedTarget`.

**Inherited Event methods:** `preventDefault()`, `stopPropagation()`, `stopImmediatePropagation()`, `composedPath()`.

**MouseEvent method:** `getModifierState(key)` returns whether the named modifier is active.

Not every property is meaningful for every event; for example, `relatedTarget` is more useful for pointer entry/exit events.

## 9. event.detail

For a typical double-click:

```javascript
button.addEventListener("click", e => console.log("click", e.detail));
button.addEventListener("dblclick", e => console.log("dblclick", e.detail));
```

Typical output:

```text
click 1
click 2
dblclick 2
```

A newly constructed `MouseEvent("dblclick")` defaults to `detail: 0` unless you supply a value. Never assume every synthetic double-click has `detail === 2`.

## 10. Double-click timing

Operating systems and browsers use platform-specific timing and movement thresholds. **There is no standard browser API to read the operating system's double-click interval.** Prefer native browser recognition over inventing your own fixed interval.

## 11. Handling click and dblclick together

```javascript
button.addEventListener("click", () => console.log("Select"));
button.addEventListener("dblclick", () => console.log("Open"));
```

A double-click typically logs `Select`, `Select`, `Open`. This is a good pairing because selecting twice is harmless. A dangerous pairing would be single-click Delete and double-click Edit: the delete action may execute first.

A timer-based attempt to distinguish them:

```javascript
let clickTimer = null;
button.addEventListener("click", () => {
  if (clickTimer !== null) return;
  clickTimer = setTimeout(() => {
    console.log("Single-click action");
    clickTimer = null;
  }, 300);
});
button.addEventListener("dblclick", () => {
  if (clickTimer !== null) {
    clearTimeout(clickTimer);
    clickTimer = null;
  }
  console.log("Double-click action");
});
```

**Caveat:** 300 ms is an illustrative application delay, not the user's actual OS double-click threshold. A timer may run before a slower double-click is recognized. Prefer compatible actions and explicit controls.

## 12. Execution traces

| Single-click step | Operation |
|---|---|
| 1 | Browser dispatches `click` |
| 2 | Handler schedules timer |
| 3 | No qualifying second click arrives |
| 4 | Timer executes single-click action |

| Double-click step | Operation |
|---|---|
| 1 | First click schedules timer |
| 2 | Second click arrives |
| 3 | Browser dispatches `dblclick` |
| 4 | Double-click handler cancels pending timer |
| 5 | Double-click action executes |

## 13. Propagation

```html
<div id="parent"><button id="child" type="button">Double-click</button></div>
```

```javascript
const parent = document.getElementById("parent");
const child = document.getElementById("child");
parent.addEventListener("dblclick", () => console.log("Capture"), true);
child.addEventListener("dblclick", () => console.log("Child"));
parent.addEventListener("dblclick", () => console.log("Bubble"));
```

Double-clicking the child normally outputs `Capture`, `Child`, `Bubble`. `stopPropagation()` stops propagation to later targets; `stopImmediatePropagation()` also blocks later listeners on the current target. `preventDefault()` is separate from propagation control.

## 14. Targets

`event.target` identifies the event's target, while `event.currentTarget` identifies the target whose listener is running. If a button contains a span, a double-click on the span may yield `target === span` and `currentTarget === button` in the button's listener.

```javascript
button.addEventListener("dblclick", function (event) {
  event.currentTarget.classList.toggle("selected");
});
```

## 15. Delegation

```javascript
const list = document.getElementById("fileList");
list.addEventListener("dblclick", function (event) {
  if (!(event.target instanceof Element)) return;
  const item = event.target.closest("[data-file]");
  if (!item || !list.contains(item)) return;
  console.log("Open:", item.dataset.file);
});
```

Delegation works for dynamically added descendants. Always provide another way to open files for keyboard and touch users.

## 16. Browser default behavior

Double-clicking text may select a word. For a graphical control where text selection is undesirable, a narrow CSS rule may help:

```css
.interactive-canvas { user-select: none; }
```

Avoid disabling ordinary text selection throughout the page. Preventing `mousedown` defaults can also interfere with focus, so use caution.

## 17. Coordinates

```javascript
element.addEventListener("dblclick", function (event) {
  const rect = element.getBoundingClientRect();
  const x = event.clientX - rect.left;
  const y = event.clientY - rect.top;
  console.log({ x, y });
});
```

`clientX` and `clientY` are viewport-relative. `getBoundingClientRect()` returns the element's viewport-relative bounding rectangle. Subtraction gives coordinates relative to that rectangle's top-left corner; CSS transforms and canvas backing-store scaling may require additional calculations.

## 18. Buttons and modifiers

A typical primary-button `dblclick` has `event.button === 0`. `event.buttons` is a bitmask of buttons currently held and is not interchangeable with `button`. Modifier booleans include `shiftKey`, `ctrlKey`, `altKey`, and `metaKey`.

```javascript
element.addEventListener("dblclick", e => {
  if (e.shiftKey) console.log("Shift + double-click");
});
```

## 19. Touch and mobile

Double-tap is **not** reliably translated into `dblclick` on all touch browsers. A double-tap may instead trigger a browser gesture. Never make an important operation available only through double-click.

## 20. Keyboard accessibility

There is no standard native keyboard gesture that dispatches `dblclick`. Provide an ordinary button:

```html
<button id="openFile" type="button">Open selected file</button>
```

```javascript
document.getElementById("openFile").addEventListener("click", openSelectedFile);
```

The same `openSelectedFile` application function can be called from a double-click handler.

## 21. Synthetic events

```javascript
const synthetic = new MouseEvent("dblclick", {
  bubbles: true,
  cancelable: true,
  composed: true,
  detail: 2,
  clientX: 100,
  clientY: 50,
  button: 0
});
element.dispatchEvent(synthetic);
```

This dispatches **one** synthetic `dblclick`; it does not generate the preceding physical press/release/click sequence. `synthetic.isTrusted` is `false`. There is no standard `element.dblclick()` method.

## 22. MouseEvent constructor

```javascript
new MouseEvent(type, options)
```

| Option | Default |
|---|---|
| `bubbles`, `cancelable`, `composed` | `false` |
| `view` | `null` |
| `detail` | `0` |
| `screenX`, `screenY`, `clientX`, `clientY` | `0` |
| `ctrlKey`, `shiftKey`, `altKey`, `metaKey` | `false` |
| `button`, `buttons` | `0` |
| `relatedTarget` | `null` |

The `type` string is required. The constructor returns a `MouseEvent`. Incorrect option types may be converted or rejected according to Web IDL rules; an invalid `view` can cause a type error.

## 23. ondblclick property

```javascript
button.ondblclick = function () { console.log("Double-clicked"); };
```

Assigning another `ondblclick` handler replaces the previous property handler. `addEventListener()` supports multiple independent listeners and is generally preferable.

## 24. Common mistakes

| Mistake | Correction |
|---|---|
| `"doubleclick"` | Use `"dblclick"` |
| Expecting no `click` events | Typical double-click generates two clicks first |
| Assuming universal timing threshold | Browser/OS determines threshold |
| Requiring double-click on touch | Provide visible alternative |
| Calling `element.dblclick()` | Use `dispatchEvent(new MouseEvent(...))` |
| Assuming `detail` is always 2 | Synthetic values depend on initialization |
| Modifying `event.target` when you mean the listener element | Use `event.currentTarget` |
| Conflicting single/double-click actions | Use compatible actions |

### script.js

```javascript
const testButton = document.getElementById("testButton");
const syntheticButton = document.getElementById("syntheticButton");
const clearButton = document.getElementById("clearButton");
const clickCountOutput = document.getElementById("clickCount");
const doubleClickCountOutput = document.getElementById("doubleClickCount");
const eventDetails = document.getElementById("eventDetails");
const eventHistory = document.getElementById("eventHistory");
let clickCount = 0;
let doubleClickCount = 0;
let eventNumber = 0;

function recordEvent(event) {
  eventNumber = eventNumber + 1;
  if (event.type === "click") clickCount = clickCount + 1;
  if (event.type === "dblclick") doubleClickCount = doubleClickCount + 1;
  clickCountOutput.textContent = String(clickCount);
  doubleClickCountOutput.textContent = String(doubleClickCount);
  const details = {
    eventNumber: eventNumber,
    type: event.type,
    detail: event.detail,
    target: event.target.id || event.target.tagName,
    currentTarget: event.currentTarget.id,
    clientX: event.clientX,
    clientY: event.clientY,
    button: event.button,
    buttons: event.buttons,
    isTrusted: event.isTrusted,
    bubbles: event.bubbles,
    cancelable: event.cancelable
  };
  eventDetails.textContent = JSON.stringify(details, null, 2);
  const item = document.createElement("li");
  item.textContent = eventNumber + ". " + event.type +
    " | detail=" + event.detail + " | trusted=" + event.isTrusted;
  eventHistory.appendChild(item);
}

function dispatchSyntheticDoubleClick() {
  const event = new MouseEvent("dblclick", {
    bubbles: true, cancelable: true, composed: true,
    detail: 2, button: 0, view: window
  });
  testButton.dispatchEvent(event);
}

function clearResults() {
  clickCount = 0;
  doubleClickCount = 0;
  eventNumber = 0;
  clickCountOutput.textContent = "0";
  doubleClickCountOutput.textContent = "0";
  eventDetails.textContent = "No event yet.";
  eventHistory.replaceChildren();
}

testButton.addEventListener("click", recordEvent);
testButton.addEventListener("dblclick", recordEvent);
syntheticButton.addEventListener("click", dispatchSyntheticDoubleClick);
clearButton.addEventListener("click", clearResults);
```

### Project 1 code breakdown and trace

1. `getElementById()` retrieves existing HTML nodes.
2. `let clickCount = 0` and `let doubleClickCount = 0` initialize mutable counters.
3. The same `recordEvent()` callback handles both event types and branches on `event.type`.
4. `JSON.stringify(details, null, 2)` produces indented JSON text for display.
5. `createElement("li")` and `appendChild()` add history entries without injecting HTML.
6. `new MouseEvent(...)` creates a synthetic event; `dispatchEvent()` sends it to the test button.
7. `replaceChildren()` removes the existing history entries when resetting.

| Real double-click step | Event | Click count | Double-click count |
|---|---|---:|---:|
| 1 | `click` | 1 | 0 |
| 2 | `click` | 2 | 0 |
| 3 | `dblclick` | 2 | 1 |

The synthetic button increments only the double-click count because it dispatches only a `dblclick` event.

### script.js

```javascript
const fileList = document.getElementById("fileList");
const openButton = document.getElementById("openButton");
const addButton = document.getElementById("addButton");
const viewer = document.getElementById("viewer");
const status = document.getElementById("status");
const files = {
  "1": { name: "report.txt", content: "Quarterly report: Sample content." },
  "2": { name: "notes.txt", content: "JavaScript event notes." },
  "3": { name: "readme.txt", content: "Welcome to the file explorer." }
};
let selectedFileId = null;
let nextFileId = 4;

function getFileButton(event) {
  if (!(event.target instanceof Element)) return null;
  const button = event.target.closest(".file");
  if (!button || !fileList.contains(button)) return null;
  return button;
}

function selectFile(button) {
  const buttons = fileList.querySelectorAll(".file");
  for (const currentButton of buttons) {
    const selected = currentButton === button;
    currentButton.classList.toggle("selected", selected);
    currentButton.setAttribute("aria-pressed", String(selected));
  }
  selectedFileId = button.dataset.fileId;
  openButton.disabled = false;
  status.textContent = files[selectedFileId].name + " selected.";
}

function openFile(fileId) {
  const file = files[fileId];
  if (!file) {
    status.textContent = "File not found.";
    return;
  }
  viewer.textContent = "File: " + file.name + "\n\n" + file.content;
  status.textContent = file.name + " opened.";
}

function handleFileClick(event) {
  const button = getFileButton(event);
  if (button) selectFile(button);
}

function handleFileDoubleClick(event) {
  const button = getFileButton(event);
  if (!button) return;
  selectFile(button);
  openFile(button.dataset.fileId);
}

function openSelectedFile() {
  if (selectedFileId === null) {
    status.textContent = "Select a file first.";
    return;
  }
  openFile(selectedFileId);
}

function addSampleFile() {
  const id = String(nextFileId);
  const name = "sample-" + id + ".txt";
  files[id] = { name: name, content: "Dynamically created sample file." };
  const button = document.createElement("button");
  button.type = "button";
  button.className = "file";
  button.dataset.fileId = id;
  button.textContent = name;
  button.setAttribute("aria-pressed", "false");
  fileList.appendChild(button);
  nextFileId = nextFileId + 1;
  status.textContent = name + " added.";
}

fileList.addEventListener("click", handleFileClick);
fileList.addEventListener("dblclick", handleFileDoubleClick);
openButton.addEventListener("click", openSelectedFile);
addButton.addEventListener("click", addSampleFile);
```

### Project 2 code breakdown and trace

- The `files` object maps IDs to sample names and content; `selectedFileId` tracks selection.
- `getFileButton()` guards against non-element targets and finds the nearest `.file` button inside the list.
- `selectFile()` updates the CSS class and `aria-pressed` state of every file button.
- `openFile()` is an ordinary reusable function; it does not depend on an event object.
- `handleFileClick()` selects; `handleFileDoubleClick()` selects and opens.
- The explicit Open button calls `openSelectedFile()`, providing a keyboard/touch alternative.
- The list's delegated listeners also handle buttons created later by `addSampleFile()`.

| Double-clicking notes.txt | Result |
|---|---|
| First `click` | Notes selected |
| Second `click` | Notes remains selected |
| `dblclick` | Notes selected and opened |
| Viewer update | Sample notes content displayed |

## 27. Interview questions and answers

1. **What is `dblclick`?** A `MouseEvent` dispatched when the browser recognizes a qualifying double-click.
2. **Does it replace `click`?** No. Two `click` events ordinarily occur first.
3. **What is its exact name?** `"dblclick"`.
4. **What does `detail` mean?** It commonly reports the click count; usually 2 for a physical double-click.
5. **Can JavaScript read the OS double-click threshold?** Not through a standard web API.
6. **Which interface represents it?** `MouseEvent`, inheriting from `UIEvent` and `Event`.
7. **Does it bubble?** Yes, browser-generated `dblclick` ordinarily bubbles and is composed.
8. **How do you dispatch one synthetically?** `element.dispatchEvent(new MouseEvent("dblclick", { bubbles: true }))`.
9. **Is it reliable on touchscreens?** No; provide another way to perform the action.
10. **How should click and dblclick actions be paired?** Prefer compatible operations such as select and open.

## 29. Quiz with explained answers

1. **Correct event name?** A. `doubleclick` / **B. `dblclick`** / C. `click2`. **Answer B:** Standard event type is `dblclick`.
2. **Typical event order?** A. `dblclick` only / **B. `click`, `click`, `dblclick`** / C. `dblclick`, `click`. **Answer B:** The clicks precede the recognized double-click.
3. **Event interface?** A. `KeyboardEvent` / **B. `MouseEvent`** / C. `FocusEvent`. **Answer B:** `dblclick` uses `MouseEvent`.
4. **Typical `detail`?** A. 0 / B. 1 / **C. 2**. **Answer C:** A qualifying double-click usually has click count 2.

6. **Is `element.dblclick()` standard?** A. Yes / **B. No**. **Answer B:** Use `dispatchEvent()` for synthetic dispatch.
7. **Does synthetic `dblclick` create two preceding `click` events?** A. Yes / **B. No**. **Answer B:** It dispatches only the supplied event.

9. **Best click/dblclick pairing?** A. Delete/Edit / **B. Select/Open** / C. Pay/Cancel. **Answer B:** Selection is harmless before opening.
10. **Listener's current target?** A. `event.target` / **B. `event.currentTarget`** / C. `event.detail`. **Answer B:** `currentTarget` identifies the listener's target.

## 33. Summary

`dblclick` is a browser-recognized double-click event. A typical physical double-click generates two `click` events before `dblclick`. It is useful as an optional shortcut, but should not be the sole way to perform an important action. Use explicit controls for accessibility and design single-click and double-click actions so they do not conflict.

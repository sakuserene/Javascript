# Module 16: JavaScript DOM Events and Event Listeners

## Lesson 16.13 â€” The Mouse Move Event (`mousemove`)

**Level:** Beginner to Advanced  
**Lesson:** 13 of 80  
**Previous:** 16.12 â€” The Mouse Up Event (`mouseup`)  
**Next:** 16.14 â€” The Mouse Over Event (`mouseover`)

The `mousemove` event fires when the mouse pointer changes position over an element. It supports mouse tracking, drag interactions, drawing, magnifiers, tooltips, and interactive charts. It does **not** require a pressed button, and its frequency is not fixed.

## 1. Learning objectives

By the end of this lesson, you should be able to explain when `mousemove` fires; compare it with mouse and pointer events; register and remove listeners; use MouseEvent properties; convert coordinate systems; calculate distance and direction; inspect pressed buttons; use propagation and delegation; optimize frequent events; and build the two projects below.

## 2. First example

```html
<div id="area">Move the mouse here</div>
<script>
  const area = document.getElementById("area");
  area.addEventListener("mousemove", function (event) {
    console.log(event.clientX, event.clientY);
  });
</script>
```

`addEventListener()` registers a callback. `"mousemove"` is the event type. The browser passes a `MouseEvent` to the callback. `clientX` and `clientY` are viewport-relative coordinates in CSS pixels.

Typical sequences:

```text
Moving without pressing: mousemove -> mousemove -> mousemove
Dragging: mousedown -> mousemove -> mousemove -> mouseup
```

There is no guaranteed number of movement events, and no new movement events are required while the pointer is stationary.

## 3. Related events

| Event | Trigger | Typical use |
|---|---|---|
| `mousemove` | Mouse pointer movement | Track position |
| `mousedown` | Mouse button pressed | Start drag |
| `mouseup` | Mouse button released | End drag |
| `mouseover` | Entry into an element or descendant | Bubbling hover entry |
| `mouseout` | Exit from an element or descendant | Bubbling hover exit |
| `mouseenter` | Entry into an element | Non-bubbling entry |
| `mouseleave` | Exit from an element | Non-bubbling exit |
| `pointermove` | Pointer movement | Mouse, touch, pen |
| `pointerrawupdate` | Lower-level pointer updates, where supported | Specialized high-frequency tracking |

`mousemove` is mouse-oriented; for touch and pen support, prefer Pointer Events. Pointer Events have additional APIs such as `pointerId`, `pointerType`, pressure, pointer capture, and coalesced event data; these are deferred to the dedicated Pointer Events lessons.

## 4. Listener registration, options, and cleanup

```javascript
function handleMove(event) {
  console.log(event.clientX);
}

const controller = new AbortController();

area.addEventListener("mousemove", handleMove, {
  capture: false,
  once: false,
  passive: true,
  signal: controller.signal
});

// Remove by aborting:
controller.abort();

// Or, for a listener registered without that signal:
area.addEventListener("mousemove", handleMove);
area.removeEventListener("mousemove", handleMove);
```

| Option | Default | Meaning |
|---|---|---|
| `capture` | `false` | Observe during capture phase |
| `once` | `false` | Remove after first invocation |
| `passive` | Usually `false` for `mousemove` | Promise not to cancel the default action |
| `signal` | None | AbortSignal that removes the listener |

The third argument can also be a Boolean capture flag. `addEventListener()` and `removeEventListener()` return `undefined`. Removal requires the same event type, callback identity, and capture setting. Registering the same callback with the same type and capture setting does not create duplicate registrations.

A property handler also exists:

```javascript
area.onmousemove = handleMove;
area.onmousemove = null; // Remove property handler
```

Unlike `addEventListener()`, this property stores one handler value at a time.

## 5. Event object and API inventory

Inheritance:

```text
Event
  `-- UIEvent
       `-- MouseEvent
```

```javascript
area.addEventListener("mousemove", (event) => {
  console.log(event instanceof MouseEvent); // true for browser-generated event
  console.log(event instanceof UIEvent);    // true
  console.log(event instanceof Event);      // true
});
```

### Event properties

| Property | Meaning |
|---|---|
| `type` | `"mousemove"` |
| `target` | Dispatch target, possibly retargeted |
| `currentTarget` | Target whose listener is executing |
| `eventPhase` | Capture, target, or bubble phase |
| `bubbles` | Whether event bubbles (normally true) |
| `cancelable` | Whether default action can be canceled (normally true) |
| `composed` | Whether it crosses shadow boundaries (normally true) |
| `defaultPrevented` | Whether default was prevented |
| `isTrusted` | Whether generated by user agent |
| `timeStamp` | Timestamp of event |

### UIEvent properties

| Property | Meaning |
|---|---|
| `detail` | Event-specific detail, normally 0 for mousemove |
| `view` | Associated Window |

### MouseEvent properties

| Property | Meaning |
|---|---|
| `clientX`, `clientY` | Viewport coordinates |
| `pageX`, `pageY` | Document coordinates |
| `screenX`, `screenY` | Screen coordinates |
| `offsetX`, `offsetY` | Target-relative coordinates |
| `movementX`, `movementY` | Browser-reported relative movement |
| `button` | Button associated with event; not a held-button indicator |
| `buttons` | Bitmask of currently held buttons |
| `ctrlKey`, `shiftKey`, `altKey`, `metaKey` | Modifier-key states |
| `relatedTarget` | Related target where applicable |

Methods include `preventDefault()`, `stopPropagation()`, `stopImmediatePropagation()`, `composedPath()`, and `getModifierState(key)`. The first three return `undefined`; `composedPath()` returns an array; `getModifierState()` returns a Boolean.

## 6. Coordinate systems and calculations

```javascript
area.addEventListener("mousemove", (event) => {
  const rect = area.getBoundingClientRect();
  const x = event.clientX - rect.left;
  const y = event.clientY - rect.top;
  console.log({ x, y });
});
```

- `clientX/Y`: position within viewport.
- `pageX/Y`: position within document, accounting for scrolling.
- `screenX/Y`: screen coordinate system.
- `offsetX/Y`: relative to event target; can jump as target changes between nested children.
- `getBoundingClientRect()`: viewport-relative bounding rectangle of the chosen element.

Example: `clientX = 230`, rectangle left `80`, so local X is `150`. Similarly, `clientY = 270` and rectangle top `120` gives local Y `150`.

For canvas with CSS scaling, multiply local coordinates by `canvas.width / rect.width` and `canvas.height / rect.height`. CSS transforms may require further conversion.

### Movement delta

```javascript
let previousX = null;
let previousY = null;

area.addEventListener("mousemove", (event) => {
  if (previousX !== null && previousY !== null) {
    const dx = event.clientX - previousX;
    const dy = event.clientY - previousY;
    const distance = Math.hypot(dx, dy);
    const angleRadians = Math.atan2(dy, dx);
    const angleDegrees = angleRadians * 180 / Math.PI;
    console.log({ dx, dy, distance, angleDegrees });
  }
  previousX = event.clientX;
  previousY = event.clientY;
});
```

`Math.hypot(dx, dy)` computes Euclidean distance. `Math.atan2(dy, dx)` computes vector direction, in radians. In viewport coordinates, positive Y points down. Browser-provided `movementX/Y` can differ from consecutive `clientX/Y` subtraction because of platform-specific units and processing.

## 7. Button states and modifiers

`event.buttons` is a bitmask:

| Bit value | Button held |
|---:|---|
| 0 | None |
| 1 | Primary |
| 2 | Secondary |
| 4 | Auxiliary |
| 8 | Fourth |
| 16 | Fifth |

```javascript
area.addEventListener("mousemove", (event) => {
  if ((event.buttons & 1) !== 0) {
    console.log("Primary button is held");
  }
  if (event.shiftKey) {
    console.log("Shift held");
  }
  console.log(event.getModifierState("Control"));
});
```

`&` is bitwise AND; it tests the primary-button flag. `event.button` is **not** the right property to determine which buttons are currently held during movement.

## 8. Target, propagation, and delegation

```html
<div id="parent"><span id="child">Move here</span></div>
```

```javascript
const parent = document.getElementById("parent");
const child = document.getElementById("child");

parent.addEventListener("mousemove", () => console.log("Capture"), true);
child.addEventListener("mousemove", () => console.log("Target"));
parent.addEventListener("mousemove", () => console.log("Bubble"));
```

Typical output over child:

```text
Capture
Target
Bubble
```

`event.target` is the originating/retargeted element, while `event.currentTarget` is the listener's current element. `stopPropagation()` stops travel to later targets; `stopImmediatePropagation()` also stops later listeners on the current target; `preventDefault()` requests cancellation of default behavior, not propagation. `composedPath()` returns the exposed path.

Delegation example:

```javascript
const list = document.getElementById("items");
list.addEventListener("mousemove", (event) => {
  if (!(event.target instanceof Element)) return;
  const item = event.target.closest("li[data-id]");
  if (!item || !list.contains(item)) return;
  console.log(item.dataset.id);
});
```

This callback can run many times over one item. If you only care when the hovered item changes, track the previous item or use entry/exit events.

## 9. Performance: animation frames, throttle, debounce

### Animation-frame scheduling

```javascript
const tracker = document.getElementById("tracker");
let latestX = 0;
let latestY = 0;
let pending = false;

document.addEventListener("mousemove", (event) => {
  latestX = event.clientX;
  latestY = event.clientY;
  if (pending) return;
  pending = true;
  requestAnimationFrame(() => {
    tracker.style.transform = `translate(${latestX}px, ${latestY}px)`;
    pending = false;
  });
});
```

Trace: event 1 schedules frame; events 2â€“5 update saved coordinates; animation callback renders the latest position once. Transforms often perform better than repeated layout-affecting `left`/`top` changes, depending on the page.

### Throttling

```javascript
let lastRun = 0;
document.addEventListener("mousemove", (event) => {
  const now = performance.now();
  if (now - lastRun < 100) return;
  lastRun = now;
  console.log(event.clientX);
});
```

### Debouncing

```javascript
let timer;
document.addEventListener("mousemove", (event) => {
  const { clientX, clientY } = event;
  clearTimeout(timer);
  timer = setTimeout(() => {
    console.log("Movement paused near", clientX, clientY);
  }, 250);
});
```

Throttling limits frequency; debouncing waits for inactivity; `requestAnimationFrame()` coordinates visual updates with rendering.

## 10. Mouse-only dragging and interruption cleanup

```javascript
const draggable = document.getElementById("draggable");
let dragging = false;

draggable.addEventListener("mousedown", (event) => {
  if (event.button === 0) dragging = true;
});

document.addEventListener("mousemove", (event) => {
  if (!dragging) return;
  if ((event.buttons & 1) === 0) {
    dragging = false;
    return;
  }
  console.log(event.clientX, event.clientY);
});

document.addEventListener("mouseup", () => { dragging = false; });
window.addEventListener("blur", () => { dragging = false; });
```

Listening on `document` helps when the pointer leaves the draggable element but remains within the document. It cannot guarantee event delivery outside the browser. Pointer Events with pointer capture are better for robust cross-device dragging.

## 11. Synthetic mousemove

```javascript
const synthetic = new MouseEvent("mousemove", {
  bubbles: true,
  cancelable: true,
  composed: true,
  clientX: 120,
  clientY: 80,
  buttons: 0
});
const accepted = area.dispatchEvent(synthetic);
console.log(accepted, synthetic.isTrusted); // true, false unless canceled
```

`dispatchEvent()` does not physically move the pointer. It returns `false` only if a cancelable event was canceled; otherwise `true`. It can throw `InvalidStateError` for invalid dispatch state.

### MouseEvent constructor options

| Option | Default |
|---|---|
| `bubbles`, `cancelable`, `composed` | `false` |
| `view`, `relatedTarget` | `null` |
| `detail`, `screenX`, `screenY`, `clientX`, `clientY`, `button`, `buttons` | `0` |
| `ctrlKey`, `shiftKey`, `altKey`, `metaKey` | `false` |

`new MouseEvent(type, options)` returns a MouseEvent. Invalid values can cause conversion errors or exceptions. Synthetic events have `isTrusted === false`.

## 12. Accessibility and common mistakes

Do not make critical controls depend only on mouse movement. Provide keyboard-focusable controls, focus-triggered information, and explicit alternatives for dragging. Touch and pen should use Pointer Events.

| Mistake | Correction |
|---|---|
| Expecting fixed event frequency | Make logic independent of frequency |
| Treating mousemove as a timer | Use a timer for periodic work |
| Using `button` for held state | Use `buttons` |
| Using `offsetX` across nested children | Use a chosen element's bounding rectangle |
| Heavy DOM updates per event | Batch with `requestAnimationFrame()` |
| Accumulating anonymous listeners | Use named handlers and cleanup |
| Assuming document tracks outside browser | Handle interruptions and use pointer capture when appropriate |
| Relying on mouse-only essential UI | Provide keyboard/touch alternatives |

### `script.js`

```javascript
const area = document.getElementById("trackingArea");
const marker = document.getElementById("marker");
const localXOutput = document.getElementById("localX");
const localYOutput = document.getElementById("localY");
const distanceOutput = document.getElementById("distance");
const buttonsOutput = document.getElementById("buttons");
const details = document.getElementById("details");
const resetButton = document.getElementById("resetButton");

let previousX = null;
let previousY = null;
let totalDistance = 0;
let latestEventData = null;
let framePending = false;

function handleMouseMove(event) {
  const rect = area.getBoundingClientRect();
  const x = event.clientX - rect.left;
  const y = event.clientY - rect.top;

  if (previousX !== null && previousY !== null) {
    totalDistance += Math.hypot(x - previousX, y - previousY);
  }

  previousX = x;
  previousY = y;

  latestEventData = {
    x, y,
    clientX: event.clientX,
    clientY: event.clientY,
    pageX: event.pageX,
    pageY: event.pageY,
    movementX: event.movementX,
    movementY: event.movementY,
    buttons: event.buttons,
    shiftKey: event.shiftKey,
    ctrlKey: event.ctrlKey,
    isTrusted: event.isTrusted
  };

  if (!framePending) {
    framePending = true;
    requestAnimationFrame(render);
  }
}

function render() {
  framePending = false;
  if (latestEventData === null) return;
  const data = latestEventData;
  marker.style.display = "block";
  marker.style.left = data.x + "px";
  marker.style.top = data.y + "px";
  localXOutput.textContent = Math.round(data.x);
  localYOutput.textContent = Math.round(data.y);
  distanceOutput.textContent = Math.round(totalDistance);
  buttonsOutput.textContent = data.buttons;
  details.textContent = JSON.stringify(data, null, 2);
}

function handleMouseLeave() {
  previousX = null;
  previousY = null;
  marker.style.display = "none";
}

function resetInspector() {
  previousX = null;
  previousY = null;
  totalDistance = 0;
  latestEventData = null;
  localXOutput.textContent = "0";
  localYOutput.textContent = "0";
  distanceOutput.textContent = "0";
  buttonsOutput.textContent = "0";
  details.textContent = "Move the mouse to begin.";
  marker.style.display = "none";
}

area.addEventListener("mousemove", handleMouseMove);
area.addEventListener("mouseleave", handleMouseLeave);
resetButton.addEventListener("click", resetInspector);
```

### Project 1 walkthrough and trace

1. `getBoundingClientRect()` measures the area in viewport coordinates.
2. Subtracting `rect.left` and `rect.top` converts pointer position into local coordinates.
3. `Math.hypot()` accumulates observed segment lengths.
4. `requestAnimationFrame(render)` batches visual output while preserving event-derived distance updates.
5. `mouseleave` resets the previous point so re-entry does not create a false long segment.

Example positions `(10,10)`, `(40,10)`, `(40,50)` give segment distances `0`, `30`, `40` and total `70` CSS pixels. This is the length along observed samples, not necessarily the exact physical path.

### `script.js`

```javascript
const imageArea = document.getElementById("imageArea");
const scene = document.getElementById("scene");
const lens = document.getElementById("lens");
const zoomLevel = document.getElementById("zoomLevel");
const zoomOutput = document.getElementById("zoomOutput");
const resetButton = document.getElementById("resetButton");
const status = document.getElementById("status");
const lensSize = 160;

let zoom = Number(zoomLevel.value);
let pointerX = 0;
let pointerY = 0;
let pointerInside = false;
let framePending = false;

const svgSource = new XMLSerializer().serializeToString(scene);
const imageUrl = "data:image/svg+xml;charset=utf-8," + encodeURIComponent(svgSource);
lens.style.backgroundImage = `url("${imageUrl}")`;

function clamp(value, minimum, maximum) {
  return Math.max(minimum, Math.min(value, maximum));
}

function scheduleRender() {
  if (framePending) return;
  framePending = true;
  requestAnimationFrame(function () {
    framePending = false;
    renderLens();
  });
}

function handleMouseMove(event) {
  const rect = scene.getBoundingClientRect();
  pointerX = clamp(event.clientX - rect.left, 0, rect.width);
  pointerY = clamp(event.clientY - rect.top, 0, rect.height);
  pointerInside = true;
  scheduleRender();
}

function renderLens() {
  if (!pointerInside) {
    lens.style.display = "none";
    return;
  }
  const width = scene.clientWidth;
  const height = scene.clientHeight;
  const left = clamp(pointerX - lensSize / 2, 0, Math.max(0, width - lensSize));
  const top = clamp(pointerY - lensSize / 2, 0, Math.max(0, height - lensSize));
  lens.style.display = "block";
  lens.style.left = left + "px";
  lens.style.top = top + "px";
  lens.style.backgroundSize = width * zoom + "px " + height * zoom + "px";
  const backgroundX = lensSize / 2 - pointerX * zoom;
  const backgroundY = lensSize / 2 - pointerY * zoom;
  lens.style.backgroundPosition = backgroundX + "px " + backgroundY + "px";
}

function hideLens() {
  pointerInside = false;
  lens.style.display = "none";
}

function updateZoom() {
  zoom = Number(zoomLevel.value);
  zoomOutput.textContent = zoom + "x";
  status.textContent = "Zoom: " + zoom + "x";
  scheduleRender();
}

function resetMagnifier() {
  zoomLevel.value = "3";
  zoom = 3;
  zoomOutput.textContent = "3x";
  hideLens();
  status.textContent = "Magnifier reset.";
}

imageArea.addEventListener("mousemove", handleMouseMove);
imageArea.addEventListener("mouseleave", hideLens);
zoomLevel.addEventListener("input", updateZoom);
resetButton.addEventListener("click", resetMagnifier);
window.addEventListener("resize", scheduleRender);
```

### Project 2 walkthrough and trace

- `XMLSerializer().serializeToString(scene)` turns the inline SVG element into a string; `encodeURIComponent()` makes it suitable for an SVG data URL.
- `backgroundSize = width * zoom` enlarges the scene within the lens.
- `backgroundPosition` offsets the enlarged background so the point under the pointer appears near the lens center.
- `pointer-events: none` prevents the lens from intercepting mouse events.
- `requestAnimationFrame()` schedules visual updates.

Example: lens size 160, pointer X 100, zoom 3. Horizontal background position is `160/2 - 100*3 = -220` pixels. The example is mouse-oriented; a production magnifier should offer keyboard-controlled panning and adapt lens size to small viewports.

# 27. Ten interview questions and answers

1. **What is mousemove?** A MouseEvent fired when the mouse pointer changes position over an element.
2. **Must a mouse button be held?** No.
3. **clientX versus pageX?** `clientX` is viewport-relative; `pageX` is document-relative.
4. **movementX versus clientX subtraction?** Browser-reported relative movement can differ from the delta of successive viewport coordinates.
5. **What is buttons?** A bitmask of currently pressed mouse buttons.
6. **Why use requestAnimationFrame?** To coordinate visual updates with rendering and combine many events into fewer DOM updates.
7. **mousemove versus mouseover?** Movement versus entry into an element or descendant.
8. **mousemove versus pointermove?** Mouse-specific versus unified mouse, touch, and pen input.
9. **Why use getBoundingClientRect?** To compute coordinates relative to a chosen element consistently.
10. **How do you remove a listener?** `removeEventListener()` with the same function and capture setting, or abort its signal.

# 29. Ten quiz questions with answers and explanations

1. **When does mousemove fire?** **B.** When the pointer moves. Explanation: It is a movement event, not a press/release event.
2. **Does it require a pressed button?** **No.** Movement with no buttons held still triggers it.
3. **Viewport-relative X?** **clientX.** It measures horizontal position within the viewport.
4. **Document-relative Y?** **pageY.** It accounts for page scrolling.
5. **What does buttons = 1 mean?** **Primary button held.** The primary bitmask flag is 1.
6. **Which API schedules work before repaint?** **requestAnimationFrame().** It coordinates visual updates with rendering.
7. **Which method calculates straight-line distance?** **Math.hypot().** It computes the Euclidean length of the displacement vector.
8. **Which event supports mouse, touch, and pen?** **pointermove.** It is part of Pointer Events.
9. **Does dispatchEvent physically move the pointer?** **No.** It only dispatches a JavaScript event.
10. **Why can offsetX jump over nested elements?** **The target-relative reference can change.** Prefer coordinates relative to a chosen element's rectangle.

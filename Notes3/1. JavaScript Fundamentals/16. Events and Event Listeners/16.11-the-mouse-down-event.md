# Module 16 â€” DOM Events and Event Listeners
## Lesson 16.11 â€” The Mouse Down Event (`mousedown`)

**Previous:** 16.10 â€” Double-Click Event  
**Next:** 16.12 â€” Mouse Up Event

## 1. Learning objectives

By the end, you can register `mousedown` listeners, explain the mouse press/release sequence, read `MouseEvent` properties, distinguish `button` from `buttons`, manage propagation and defaults, and build a basic mouse-only drag interaction with an accessible alternative.

## 2. What is `mousedown`?

`mousedown` fires when a mouse button is pressed while the pointer is over an element. It occurs **before release**. It can fire for primary, secondary, and auxiliary buttons.

```html
<button id="myButton" type="button">Press a mouse button</button>
<script>
  const button = document.getElementById("myButton");
  button.addEventListener("mousedown", function (event) {
    console.log("Pressed button:", event.button);
  });
</script>
```

## 3. Typical event sequence

For an ordinary primary-button click:

```text
pointerdown â†’ mousedown â†’ pointerup â†’ mouseup â†’ click
```

This is a common simplified sequence; other events (such as focus events) can occur.

## 4. Related events

| Event | Meaning |
|---|---|
| `mousedown` | Mouse button pressed |
| `mouseup` | Mouse button released |
| `click` | Completed primary activation |
| `dblclick` | Recognized double-click |
| `mousemove` | Pointer moves |
| `pointerdown` | Pointer becomes active; supports mouse, touch, pen |
| `contextmenu` | Context menu requested |
| `auxclick` | Auxiliary-button activation |

`mousedown` fires for each mouse button press, including an additional button pressed while another is held. For a mouse, `pointerdown` generally fires only on the transition from no buttons pressed to at least one.

## 5. Registering and removing listeners

```javascript
function handleMouseDown(event) {
  console.log(event.type, event.button);
}

button.addEventListener("mousedown", handleMouseDown);
button.removeEventListener("mousedown", handleMouseDown);
```

Do not accidentally call `handleMouseDown()` when registering: pass the function reference.

Full signature:

```javascript
element.addEventListener("mousedown", listener, options);
```

| Option | Typical default | Purpose |
|---|---|---|
| `capture` | `false` | Capture-phase listener |
| `once` | `false` | Remove after first invocation |
| `passive` | `false` for ordinary mouse listeners | Promise not to prevent default |
| `signal` | None | Abort-based listener removal |

```javascript
const controller = new AbortController();
button.addEventListener("mousedown", handleMouseDown, {
  capture: false,
  once: false,
  passive: false,
  signal: controller.signal
});
controller.abort();
```

`addEventListener()` and `removeEventListener()` return `undefined`. Removing a listener requires the same callback reference and capture setting. The `onmousedown` property is another registration mechanism, but assigning it again replaces the previous property handler.

## 6. MouseEvent inheritance and API inventory

```text
Event â†’ UIEvent â†’ MouseEvent
```

Browser-generated `mousedown` events are `MouseEvent` instances.

**Event properties:** `type`, `target`, `currentTarget`, `eventPhase`, `bubbles`, `cancelable`, `composed`, `defaultPrevented`, `isTrusted`, `timeStamp`.

**UIEvent properties:** `detail`, `view`.

**MouseEvent properties:** `button`, `buttons`, `clientX`, `clientY`, `pageX`, `pageY`, `screenX`, `screenY`, `offsetX`, `offsetY`, `movementX`, `movementY`, `ctrlKey`, `shiftKey`, `altKey`, `metaKey`, `relatedTarget`.

**Useful methods:** `preventDefault()`, `stopPropagation()`, `stopImmediatePropagation()`, `composedPath()`, `getModifierState(key)`.

For normal browser-generated `mousedown`, `bubbles`, `cancelable`, and `composed` are true. Some inherited properties are less useful for `mousedown` than for other mouse events; for example, `relatedTarget` is mainly used with entry/exit events.

## 7. `event.button` versus `event.buttons`

`button` identifies the button associated with the press:

| `button` | Meaning |
|---:|---|
| 0 | Primary |
| 1 | Auxiliary (often wheel) |
| 2 | Secondary |
| 3 | Fourth |
| 4 | Fifth |

`buttons` is a bitmask of all currently held buttons:

| `buttons` bit | Meaning |
|---:|---|
| 1 | Primary |
| 2 | Secondary |
| 4 | Auxiliary |
| 8 | Fourth |
| 16 | Fifth |

For example, primary + secondary gives `buttons === 3` (`1 | 2`). Check whether the primary button is held using `(event.buttons & 1) !== 0`.

```javascript
element.addEventListener("mousedown", function (event) {
  if (event.button !== 0) return;
  console.log("Primary mouse press");
});
```

## 8. Coordinates

- `clientX` / `clientY`: viewport coordinates.
- `pageX` / `pageY`: document coordinates, including scrolling.
- `screenX` / `screenY`: screen coordinates.
- `offsetX` / `offsetY`: target-relative coordinates; nested targets can change the reference.
- `movementX` / `movementY`: relative pointer movement values.

To measure coordinates relative to a specific element:

```javascript
panel.addEventListener("mousedown", function (event) {
  const rect = panel.getBoundingClientRect();
  const x = event.clientX - rect.left;
  const y = event.clientY - rect.top;
  console.log({ x, y });
});
```

CSS transforms and canvas backing-store scaling can require additional conversions.

## 9. Modifier keys

```javascript
button.addEventListener("mousedown", function (event) {
  console.log(event.shiftKey, event.ctrlKey, event.altKey, event.metaKey);
  console.log(event.getModifierState("Shift"));
});
```

These return Booleans. Some combinations may be reserved by the browser or operating system.

## 10. Targets, propagation, and delegation

`event.target` is the originating or retargeted node; `event.currentTarget` is the node whose listener is executing. They can differ if a button contains a nested span.

Propagation generally follows capturing â†’ target â†’ bubbling.

```javascript
const toolbar = document.getElementById("toolbar");
toolbar.addEventListener("mousedown", function (event) {
  if (!(event.target instanceof Element)) return;
  const button = event.target.closest("button");
  if (!button || !toolbar.contains(button)) return;
  console.log(button.dataset.tool);
});
```

One delegated listener works for dynamically added descendants.

## 11. Default actions and cancellation

A mouse press can initiate focus, selection, or dragging. Use `preventDefault()` narrowly; it can interfere with focus or text selection.

```javascript
element.addEventListener("mousedown", function (event) {
  if (event.cancelable) event.preventDefault();
});
```

`stopPropagation()` stops further propagation to other targets; `stopImmediatePropagation()` additionally stops later listeners on the same target. Neither cancels default actions. `preventDefault()` in a passive listener is ignored.

## 12. Mouse-only dragging and interruption

```javascript
const dragArea = document.getElementById("dragArea");
let dragging = false;

dragArea.addEventListener("mousedown", function (event) {
  if (event.button !== 0) return;
  dragging = true;
});

document.addEventListener("mousemove", function (event) {
  if (!dragging) return;
  if ((event.buttons & 1) === 0) {
    dragging = false;
    return;
  }
  console.log("Drag at", event.clientX, event.clientY);
});

document.addEventListener("mouseup", function () {
  dragging = false;
});
window.addEventListener("blur", function () {
  dragging = false;
});
```

Listening on `document` helps when the mouse leaves the draggable element, though it does not guarantee delivery after the pointer leaves the window. Pointer Events with pointer capture are generally preferable for cross-device drag interactions.

## 13. Keyboard and touch accessibility

`mousedown` is mouse-oriented and is not a substitute for keyboard activation. For ordinary actions, use native `<button>` elements and `click` listeners. For draggable content, provide buttons or keyboard controls as alternatives. Touch/pen interactions are better addressed with Pointer Events.

## 14. Synthetic `mousedown` events

```javascript
const event = new MouseEvent("mousedown", {
  bubbles: true,
  cancelable: true,
  composed: true,
  button: 0,
  buttons: 1,
  clientX: 120,
  clientY: 80
});
element.dispatchEvent(event);
```

`new MouseEvent(type, options)` supports inherited `EventInit`, `UIEventInit`, and `MouseEventInit` fields. Defaults include `bubbles: false`, `cancelable: false`, `composed: false`, `detail: 0`, `button: 0`, `buttons: 0`, coordinates 0, modifiers false, and `view: null`.

`dispatchEvent()` returns false if the cancelable event was canceled; otherwise true. It can throw `InvalidStateError` for invalid dispatch state. A synthetic event has `isTrusted === false` and does not physically press the mouse or grant user-activation privileges.

## 15. Common mistakes

| Mistake | Correction |
|---|---|
| Treating `mousedown` as `click` | Use `click` for ordinary activation |
| Ignoring `event.button` | Filter for the desired mouse button |
| Confusing `button` and `buttons` | One identifies a changed button; the other is a bitmask |
| Listening for `mouseup` only on draggable element | Listen on document or use pointer capture |
| Forgetting interruptions | Reset drag state on release and blur |
| Canceling every `mousedown` | Avoid breaking focus/selection |
| Using `mousedown` as sole activation method | Provide keyboard/touch alternatives |

### `script.js`

```javascript
const testArea = document.getElementById("testArea");
const syntheticButton = document.getElementById("syntheticButton");
const clearButton = document.getElementById("clearButton");
const downCountOutput = document.getElementById("downCount");
const upCountOutput = document.getElementById("upCount");
const details = document.getElementById("details");
const history = document.getElementById("history");
let downCount = 0;
let upCount = 0;

function recordEvent(event) {
  if (event.type === "mousedown") downCount += 1;
  if (event.type === "mouseup") upCount += 1;
  downCountOutput.textContent = String(downCount);
  upCountOutput.textContent = String(upCount);
  const data = {
    type: event.type, button: event.button, buttons: event.buttons,
    clientX: event.clientX, clientY: event.clientY,
    pageX: event.pageX, pageY: event.pageY,
    ctrlKey: event.ctrlKey, shiftKey: event.shiftKey,
    altKey: event.altKey, metaKey: event.metaKey,
    isTrusted: event.isTrusted, bubbles: event.bubbles,
    cancelable: event.cancelable, detail: event.detail
  };
  details.textContent = JSON.stringify(data, null, 2);
  const item = document.createElement("li");
  item.textContent = `${event.type} | button=${event.button} | buttons=${event.buttons} | trusted=${event.isTrusted}`;
  history.prepend(item);
}
function handleMouseDown(event) {
  recordEvent(event);
  if (event.button === 0) testArea.classList.add("pressed");
}
function handleMouseUp(event) {
  recordEvent(event);
  if ((event.buttons & 1) === 0) testArea.classList.remove("pressed");
}
function dispatchSyntheticMouseDown() {
  testArea.dispatchEvent(new MouseEvent("mousedown", {
    bubbles: true, cancelable: true, composed: true,
    button: 0, buttons: 1, clientX: 120, clientY: 80
  }));
  testArea.classList.remove("pressed");
}
function clearResults() {
  downCount = 0;
  upCount = 0;
  downCountOutput.textContent = "0";
  upCountOutput.textContent = "0";
  details.textContent = "No event recorded.";
  history.replaceChildren();
  testArea.classList.remove("pressed");
}
testArea.addEventListener("mousedown", handleMouseDown);
document.addEventListener("mouseup", handleMouseUp);
window.addEventListener("blur", () => testArea.classList.remove("pressed"));
syntheticButton.addEventListener("click", dispatchSyntheticMouseDown);
clearButton.addEventListener("click", clearResults);
```

### `script.js`

```javascript
const workspace = document.getElementById("workspace");
const panel = document.getElementById("panel");
const dragHandle = document.getElementById("dragHandle");
const controls = document.querySelector(".button-grid");
const resetButton = document.getElementById("resetButton");
const positionOutput = document.getElementById("position");
let dragging = false;
let panelX = 20, panelY = 20;
let startMouseX = 0, startMouseY = 0;
let startPanelX = 0, startPanelY = 0;

function clamp(value, minimum, maximum) {
  return Math.max(minimum, Math.min(value, maximum));
}
function updatePosition(x, y) {
  const maxX = Math.max(0, workspace.clientWidth - panel.offsetWidth);
  const maxY = Math.max(0, workspace.clientHeight - panel.offsetHeight);
  panelX = clamp(x, 0, maxX);
  panelY = clamp(y, 0, maxY);
  panel.style.left = panelX + "px";
  panel.style.top = panelY + "px";
  positionOutput.textContent = `Position: X = ${Math.round(panelX)}, Y = ${Math.round(panelY)}`;
}
function startDrag(event) {
  if (event.button !== 0) return;
  dragging = true;
  startMouseX = event.clientX;
  startMouseY = event.clientY;
  startPanelX = panelX;
  startPanelY = panelY;
  dragHandle.classList.add("dragging");
  event.preventDefault();
}
function moveDrag(event) {
  if (!dragging) return;
  if ((event.buttons & 1) === 0) {
    stopDrag();
    return;
  }
  const deltaX = event.clientX - startMouseX;
  const deltaY = event.clientY - startMouseY;
  updatePosition(startPanelX + deltaX, startPanelY + deltaY);
}
function stopDrag() {
  dragging = false;
  dragHandle.classList.remove("dragging");
}
function moveWithControls(direction) {
  const step = 20;
  if (direction === "left") updatePosition(panelX - step, panelY);
  if (direction === "right") updatePosition(panelX + step, panelY);
  if (direction === "up") updatePosition(panelX, panelY - step);
  if (direction === "down") updatePosition(panelX, panelY + step);
}
function handleControlClick(event) {
  if (!(event.target instanceof Element)) return;
  const button = event.target.closest("[data-move]");
  if (!button || !controls.contains(button)) return;
  moveWithControls(button.dataset.move);
}
dragHandle.addEventListener("mousedown", startDrag);
document.addEventListener("mousemove", moveDrag);
document.addEventListener("mouseup", stopDrag);
window.addEventListener("blur", stopDrag);
controls.addEventListener("click", handleControlClick);
resetButton.addEventListener("click", function () {
  stopDrag();
  updatePosition(20, 20);
});
window.addEventListener("resize", () => updatePosition(panelX, panelY));
updatePosition(panelX, panelY);
```

### Execution trace

If the mouse press starts at `(100, 100)` and the panel starts at `(20, 20)`, then moving to `(150, 130)` yields `deltaX = 50`, `deltaY = 30`, and requested panel position `(70, 50)`. `clamp()` keeps the panel within the workspace.

# 10 Interview Questions with Answers

1. **What is `mousedown`?** A `MouseEvent` fired when a mouse button is pressed over an element.
2. **How is it different from `click`?** `mousedown` occurs on press; `click` normally represents completed primary activation.
3. **Does it fire for secondary buttons?** Yes, for secondary and auxiliary presses as well as primary presses.
4. **`button` versus `buttons`?** `button` identifies the changed button; `buttons` is a pressed-button bitmask.
5. **`mousedown` versus `pointerdown`?** `pointerdown` supports multiple pointer types and has different multi-button semantics.
6. **Why use document-level drag listeners?** To continue receiving movement and release when the pointer leaves the dragged element within the document.
7. **What does `preventDefault()` do?** Requests cancellation of default behavior when allowed; can affect focus or selection.
8. **Does `mousedown` support keyboard activation?** No. Use native controls and `click` for general actions.
9. **How do you synthesize it?** `new MouseEvent('mousedown', options)` and `dispatchEvent()`.
10. **What if `mouseup` is missed?** Dragging state may remain active; handle blur and check `event.buttons`.

# 10 Quiz Questions with Explained Answers

1. **When does `mousedown` fire?** On mouse-button press. It does not wait for release.
2. **What interface represents it?** `MouseEvent`, which inherits from `UIEvent` and `Event`.
3. **What does `button === 0` mean?** Primary button caused the event.
4. **What does `buttons === 3` mean?** Primary and secondary buttons held (`1 | 2`).
5. **Which property is viewport-relative horizontal position?** `clientX`.
6. **Which event supports mouse, pen, and touch?** `pointerdown`.
7. **Does `mousedown` automatically support keyboard activation?** No.
8. **Which method requests default cancellation?** `preventDefault()`.
9. **Can `dispatchEvent()` physically press a mouse button?** No; it dispatches a synthetic event.
10. **Why use a document-level `mouseup` listener?** To observe release when the pointer leaves the original element within the document.

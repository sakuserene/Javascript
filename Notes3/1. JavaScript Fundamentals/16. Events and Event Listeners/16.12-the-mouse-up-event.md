## 1. Learning objectives

By the end of this lesson, you will understand when `mouseup` fires, its relationship to `mousedown`, `click`, and `pointerup`, how to inspect mouse buttons and coordinates, event propagation and delegation, default actions, synthetic events, drag cleanup, accessibility, and how to build two complete projects.

## 2. What is `mouseup`?

`mouseup` is a `MouseEvent` dispatched when a mouse button is released while the pointer is over an element. It can occur for primary, secondary, and auxiliary buttons.

```html
<button id="testButton" type="button">Press and Release</button>
```

```javascript
const button = document.getElementById("testButton");
button.addEventListener("mouseup", function () {
  console.log("Mouse button released!");
});
```

The release does **not** have to occur on the element that originally received `mousedown`.

## 3. Event sequence

A typical completed primary-button activation produces:

```text
pointerdown -> mousedown -> pointerup -> mouseup -> click
```

```javascript
button.addEventListener("mousedown", () => console.log("1. Down"));
button.addEventListener("mouseup", () => console.log("2. Up"));
button.addEventListener("click", () => console.log("3. Click"));
```

A `mouseup` does not necessarily result in a `click`: pointer movement, differing targets, and browser activation rules matter.

## 4. Related events

| Event | Trigger | Typical purpose |
|---|---|---|
| `mousedown` | Mouse button pressed | Begin interaction |
| `mouseup` | Mouse button released | Finish interaction |
| `click` | Completed primary activation | Activate controls |
| `dblclick` | Recognized double-click | Optional shortcut |
| `mousemove` | Mouse movement | Track position |
| `pointerup` | Pointer activation ends | Mouse/touch/pen handling |
| `auxclick` | Auxiliary activation | Non-primary activation |
| `contextmenu` | Context menu requested | Context actions |

`mouseup` can occur for each mouse-button release. For a mouse, `pointerup` generally occurs when the final held button is released.

## 5. Registering and removing listeners

```javascript
function handleMouseUp(event) {
  console.log("Released button:", event.button);
}

button.addEventListener("mouseup", handleMouseUp);
button.removeEventListener("mouseup", handleMouseUp);
```

The listener can be a named function, anonymous function, arrow function, or object implementing `handleEvent()`. Passing `handleMouseUp()` instead of `handleMouseUp` calls it immediately and does not register the intended callback.

### `addEventListener()` options

```javascript
const controller = new AbortController();
button.addEventListener("mouseup", handleMouseUp, {
  capture: false,
  once: false,
  passive: false,
  signal: controller.signal
});
controller.abort();
```

| Option | Default | Purpose |
|---|---|---|
| `capture` | `false` | Register capture-phase listener |
| `once` | `false` | Remove after first invocation |
| `passive` | Usually `false` | Promise not to call `preventDefault()` |
| `signal` | None | Remove when signal aborts |

`addEventListener()` and `removeEventListener()` return `undefined`. Removal requires the same listener reference and matching capture setting.

## 6. Event inheritance

```text
Event -> UIEvent -> MouseEvent
```

```javascript
button.addEventListener("mouseup", function (event) {
  console.log(event instanceof MouseEvent); // true for normal mouseup
  console.log(event instanceof UIEvent);    // true
  console.log(event instanceof Event);      // true
});
```

### `Event` properties

| Property | Description |
|---|---|
| `type` | `"mouseup"` |
| `target` | Target where the event is dispatched, subject to retargeting |
| `currentTarget` | Target whose listener is currently executing |
| `eventPhase` | Capturing, at-target, or bubbling phase |
| `bubbles` | Whether the event bubbles |
| `cancelable` | Whether its default action can be canceled |
| `composed` | Whether it can cross shadow boundaries |
| `defaultPrevented` | Whether default was prevented |
| `isTrusted` | Whether the user agent generated the event |
| `timeStamp` | Event timestamp |

Browser-generated `mouseup` events generally have `bubbles`, `cancelable`, and `composed` set to `true`.

### `UIEvent` properties

- `detail`: event-specific detail, commonly associated with click counting.
- `view`: associated `Window` or `null`.

### `MouseEvent` properties

| Property | Meaning |
|---|---|
| `button` | Button that changed state (released) |
| `buttons` | Bitmask of buttons still held |
| `clientX`, `clientY` | Viewport coordinates |
| `pageX`, `pageY` | Document coordinates |
| `screenX`, `screenY` | Screen coordinates |
| `offsetX`, `offsetY` | Coordinates relative to target's padding edge |
| `movementX`, `movementY` | Relative pointer movement |
| `ctrlKey`, `shiftKey`, `altKey`, `metaKey` | Modifier states |
| `relatedTarget` | Related target when applicable |

Methods include `preventDefault()`, `stopPropagation()`, `stopImmediatePropagation()`, `composedPath()`, and `getModifierState(key)`.

## 7. `event.button` versus `event.buttons`

`button` identifies the released button:

| `button` | Meaning |
|---:|---|
| 0 | Primary |
| 1 | Auxiliary (usually wheel) |
| 2 | Secondary |
| 3 | Fourth (often Back) |
| 4 | Fifth (often Forward) |

`buttons` is a bitmask of buttons still pressed:

| `buttons` bit | Meaning |
|---:|---|
| 1 | Primary held |
| 2 | Secondary held |
| 4 | Auxiliary held |
| 8 | Fourth held |
| 16 | Fifth held |

When the sole primary button is released:

```javascript
event.button  // 0: primary button was released
event.buttons // 0: no buttons remain held
```

When both primary and secondary are held and primary is released, `button` is `0`, while `buttons` may be `2`.

```javascript
const primaryStillHeld = (event.buttons & 1) !== 0;
```

`&` is bitwise AND; it checks the primary-button bit.

## 8. Mouse coordinates and modifier keys

```javascript
document.addEventListener("mouseup", function (event) {
  console.log(event.clientX, event.clientY); // viewport
  console.log(event.pageX, event.pageY);     // document
  console.log(event.screenX, event.screenY); // screen
  console.log(event.shiftKey, event.ctrlKey);
  console.log(event.altKey, event.metaKey);
  console.log(event.getModifierState("Shift"));
});
```

Convert coordinates relative to an element's bounding rectangle:

```javascript
const rect = element.getBoundingClientRect();
const x = event.clientX - rect.left;
const y = event.clientY - rect.top;
```

CSS transforms and canvas backing-store scaling may require further conversion.

## 9. `target`, `currentTarget`, and propagation

```html
<div id="parent"><button id="child"><span>Release</span></button></div>
```

```javascript
const parent = document.getElementById("parent");
const child = document.getElementById("child");
parent.addEventListener("mouseup", () => console.log("Parent capture"), true);
child.addEventListener("mouseup", (event) => {
  console.log("Target:", event.target);
  console.log("Current:", event.currentTarget);
  console.log("Child");
});
parent.addEventListener("mouseup", () => console.log("Parent bubble"));
```

Typical order: **Parent capture -> Child -> Parent bubble**. If the span is the target, `target` can be the span while `currentTarget` is the button. `currentTarget` is valid during the listener call; save it before asynchronous work.

`stopPropagation()` prevents propagation to later targets; `stopImmediatePropagation()` additionally prevents later listeners on the current target. Neither cancels browser defaults.

### Delegation

```html
<div id="toolbar">
  <button data-action="draw">Draw</button>
  <button data-action="erase">Erase</button>
</div>
```

```javascript
const toolbar = document.getElementById("toolbar");
toolbar.addEventListener("mouseup", function (event) {
  if (!(event.target instanceof Element)) return;
  const button = event.target.closest("button[data-action]");
  if (!button || !toolbar.contains(button)) return;
  console.log(button.dataset.action);
});
```

This also handles dynamically added buttons. Use `click`, not `mouseup`, for ordinary accessible button activation.

## 10. Default actions and cancellation

`mouseup` may participate in completing text selection, dragging, and activation. Calling `preventDefault()` on `mouseup` cannot necessarily undo actions that already began during `mousedown` or `mousemove`.

```javascript
element.addEventListener("mouseup", function (event) {
  if (event.cancelable) event.preventDefault();
  console.log(event.defaultPrevented);
});
```

Passive listeners ignore `preventDefault()` requests. Avoid indiscriminate cancellation because it may interfere with expected browser behavior.

## 11. Releasing outside the original element

```text
mousedown on A -> pointer moves to B -> mouseup on B
```

A listener attached only to A may miss the release. For mouse-only dragging, listen for `mouseup` on `document` and recover from interruptions:

```javascript
const panel = document.getElementById("panel");
let dragging = false;

panel.addEventListener("mousedown", function (event) {
  if (event.button === 0) dragging = true;
});

document.addEventListener("mousemove", function (event) {
  if (!dragging) return;
  if ((event.buttons & 1) === 0) {
    dragging = false;
    return;
  }
  console.log(event.clientX, event.clientY);
});

document.addEventListener("mouseup", () => { dragging = false; });
window.addEventListener("blur", () => { dragging = false; });
```

A release outside the browser window may still be missed. Pointer Events with pointer capture are preferable for robust cross-device interactions.

## 12. Accessibility

`mouseup` does not provide normal keyboard activation. For Save, Submit, Delete, or Open, use a native button and `click`:

```javascript
saveButton.addEventListener("click", saveData);
```

For drag operations, offer keyboard controls or other non-drag mechanisms. `pointerup` supports mouse, touch, and pen, unlike mouse-oriented `mouseup`.

## 13. Synthetic mouseup and constructor

```javascript
const event = new MouseEvent("mouseup", {
  bubbles: true,
  cancelable: true,
  composed: true,
  button: 0,
  buttons: 0,
  clientX: 150,
  clientY: 90
});
const result = element.dispatchEvent(event);
```

The event is synthetic (`isTrusted === false`), does not physically release a mouse button, and does not automatically generate `click`.

### `MouseEvent(type, options)` defaults

| Option | Default |
|---|---|
| `bubbles`, `cancelable`, `composed` | `false` |
| `view`, `relatedTarget` | `null` |
| `detail` | `0` |
| `screenX`, `screenY`, `clientX`, `clientY` | `0` |
| `ctrlKey`, `shiftKey`, `altKey`, `metaKey` | `false` |
| `button`, `buttons` | `0` |

The constructor returns a `MouseEvent`. Invalid values may cause conversion errors or exceptions. `dispatchEvent()` returns `false` when a cancelable event was canceled; otherwise `true`. It can throw `InvalidStateError` for invalid event dispatch state.

### `onmouseup`

```javascript
button.onmouseup = function (event) { console.log(event.button); };
button.onmouseup = null; // remove property handler
```

Only one handler is assigned through this property at a time; `addEventListener()` supports multiple listeners.

## 14. Common mistakes

| Mistake | Correction |
|---|---|
| Using `mouseup` for Save | Use native button `click` |
| Assuming release occurs on press target | Listen on document or use pointer capture |
| Assuming every release is a click | Treat events separately |
| Confusing `button` and `buttons` | Released button vs still-held bitmask |
| Ignoring interruptions | Reset state on blur and check `buttons` |
| Using `preventDefault()` to undo earlier selection | Handle the relevant earlier event |
| Assuming synthetic mouseup releases hardware | It only dispatches a JavaScript event |

Debugging:

```javascript
function debugMouseUp(event) {
  console.group("Mouse Up");
  console.log(event.type, event.button, event.buttons);
  console.log(event.target, event.currentTarget);
  console.log(event.clientX, event.clientY);
  console.log(event.isTrusted, event.cancelable);
  console.groupEnd();
}
document.addEventListener("mouseup", debugMouseUp);
```

## `script.js`

```javascript
const testArea = document.getElementById("testArea");
const syntheticButton = document.getElementById("syntheticButton");
const clearButton = document.getElementById("clearButton");
const downCountOutput = document.getElementById("downCount");
const upCountOutput = document.getElementById("upCount");
const clickCountOutput = document.getElementById("clickCount");
const details = document.getElementById("details");
const history = document.getElementById("history");
let downCount = 0;
let upCount = 0;
let clickCount = 0;
let trackingPrimaryPress = false;

function recordEvent(event) {
  if (event.type === "mousedown") downCount += 1;
  if (event.type === "mouseup") upCount += 1;
  if (event.type === "click") clickCount += 1;
  downCountOutput.textContent = String(downCount);
  upCountOutput.textContent = String(upCount);
  clickCountOutput.textContent = String(clickCount);
  const data = {
    type: event.type, button: event.button, buttons: event.buttons,
    detail: event.detail, clientX: event.clientX, clientY: event.clientY,
    target: event.target.id || event.target.tagName,
    isTrusted: event.isTrusted, bubbles: event.bubbles,
    cancelable: event.cancelable
  };
  details.textContent = JSON.stringify(data, null, 2);
  const item = document.createElement("li");
  item.textContent = event.type + " | button=" + event.button +
    " | buttons=" + event.buttons + " | trusted=" + event.isTrusted;
  history.appendChild(item);
}

function handleMouseDown(event) {
  recordEvent(event);
  if (event.button === 0) {
    trackingPrimaryPress = true;
    testArea.classList.add("pressed");
  }
}

function handleMouseUp(event) {
  if (trackingPrimaryPress || event.target === testArea) recordEvent(event);
  if (event.button === 0 || (event.buttons & 1) === 0) {
    trackingPrimaryPress = false;
    testArea.classList.remove("pressed");
  }
}

function dispatchSyntheticMouseUp() {
  const event = new MouseEvent("mouseup", {
    bubbles: true, cancelable: true, composed: true,
    button: 0, buttons: 0, clientX: 150, clientY: 80
  });
  testArea.dispatchEvent(event);
}

function clearResults() {
  downCount = 0; upCount = 0; clickCount = 0;
  trackingPrimaryPress = false;
  downCountOutput.textContent = "0";
  upCountOutput.textContent = "0";
  clickCountOutput.textContent = "0";
  details.textContent = "No event recorded.";
  history.replaceChildren();
  testArea.classList.remove("pressed");
}

testArea.addEventListener("mousedown", handleMouseDown);
document.addEventListener("mouseup", handleMouseUp);
testArea.addEventListener("click", recordEvent);
window.addEventListener("blur", function () {
  trackingPrimaryPress = false;
  testArea.classList.remove("pressed");
});
syntheticButton.addEventListener("click", dispatchSyntheticMouseUp);
clearButton.addEventListener("click", clearResults);
```

### Code walkthrough

1. `getElementById()` obtains references to existing HTML elements.
2. Counters track each event type separately.
3. `recordEvent()` checks `event.type`, updates counters, and displays a JSON representation of selected event properties.
4. `handleMouseDown()` records the start of a primary-button press and adds a CSS class.
5. The document-level `handleMouseUp()` observes release even when it occurs elsewhere in the document.
6. `dispatchSyntheticMouseUp()` creates and dispatches a synthetic event; it does not dispatch a `click`.
7. `clearResults()` resets counters, the event history, and the pressed visual state.

### Execution trace

| Step | Event | Down | Up | Click |
|---|---|---:|---:|---:|
| 1 | `mousedown` | 1 | 0 | 0 |
| 2 | `mouseup` | 1 | 1 | 0 |
| 3 | `click` | 1 | 1 | 1 |

Dispatching synthetic `mouseup` increments only the Up counter.

## `script.js`

```javascript
const canvas = document.getElementById("drawingCanvas");
const context = canvas.getContext("2d");
const penColor = document.getElementById("penColor");
const penWidth = document.getElementById("penWidth");
const widthValue = document.getElementById("widthValue");
const addDotButton = document.getElementById("addDot");
const clearButton = document.getElementById("clearCanvas");
const status = document.getElementById("status");
let drawing = false;

function getCanvasPosition(event) {
  const rect = canvas.getBoundingClientRect();
  const scaleX = canvas.width / rect.width;
  const scaleY = canvas.height / rect.height;
  return {
    x: (event.clientX - rect.left) * scaleX,
    y: (event.clientY - rect.top) * scaleY
  };
}

function configurePen() {
  context.strokeStyle = penColor.value;
  context.fillStyle = penColor.value;
  context.lineWidth = Number(penWidth.value);
  context.lineCap = "round";
  context.lineJoin = "round";
}

function startDrawing(event) {
  if (event.button !== 0) return;
  drawing = true;
  configurePen();
  const position = getCanvasPosition(event);
  context.beginPath();
  context.moveTo(position.x, position.y);
  status.textContent = "Drawing...";
  event.preventDefault();
}

function draw(event) {
  if (!drawing) return;
  if ((event.buttons & 1) === 0) {
    stopDrawing();
    return;
  }
  const position = getCanvasPosition(event);
  context.lineTo(position.x, position.y);
  context.stroke();
}

function stopDrawing() {
  if (!drawing) return;
  drawing = false;
  context.closePath();
  status.textContent = "Drawing stopped.";
}

function addCenterDot() {
  configurePen();
  const x = canvas.width / 2;
  const y = canvas.height / 2;
  context.beginPath();
  context.arc(x, y, Math.max(3, Number(penWidth.value)), 0, Math.PI * 2);
  context.fill();
  status.textContent = "Center dot added.";
}

function clearDrawing() {
  stopDrawing();
  context.clearRect(0, 0, canvas.width, canvas.height);
  status.textContent = "Canvas cleared.";
}

canvas.addEventListener("mousedown", startDrawing);
document.addEventListener("mousemove", draw);
document.addEventListener("mouseup", stopDrawing);
window.addEventListener("blur", stopDrawing);
penWidth.addEventListener("input", function () {
  widthValue.textContent = penWidth.value;
});
addDotButton.addEventListener("click", addCenterDot);
clearButton.addEventListener("click", clearDrawing);
```

### Code walkthrough

- `canvas.getContext("2d")` obtains the 2D drawing context.
- `getBoundingClientRect()` and the scale factors translate viewport coordinates to the canvas's internal resolution.
- `configurePen()` sets stroke color, fill color, width, and line cap/join.
- `startDrawing()` checks for the primary button, sets `drawing = true`, and starts a path with `beginPath()` and `moveTo()`.
- `draw()` checks that the primary button remains held, adds a segment with `lineTo()`, and renders it with `stroke()`.
- `stopDrawing()` sets `drawing = false` and closes the path.
- `addCenterDot()` draws a filled circle using `arc()` and `fill()`.
- `clearDrawing()` clears the drawing surface using `clearRect()`.

### Execution trace

| Step | Event | State | Action |
|---|---|---|---|
| 1 | `mousedown` | `drawing = true` | Start path |
| 2 | `mousemove` | `drawing = true` | Draw segment |
| 3 | `mousemove` | `drawing = true` | Continue stroke |
| 4 | `mouseup` | `drawing = false` | End stroke |
| 5 | `mousemove` | `drawing = false` | No drawing |

**Limitation:** This project is intentionally mouse-oriented. The center-dot button is not full keyboard-equivalent drawing. A production drawing app should add comprehensive keyboard controls and Pointer Events for touch and pen.

# 17. Ten interview questions and answers

1. **What is `mouseup`?** A `MouseEvent` dispatched when a mouse button is released.
2. **How is it different from `click`?** `mouseup` reports release; `click` represents completed activation. Not every `mouseup` generates a `click`.
3. **Does it work with secondary buttons?** Yes; it supports releases of primary, secondary, auxiliary, and other mouse buttons.
4. **What does `event.button` mean?** Which button was released; primary is 0, auxiliary 1, secondary 2.
5. **What does `event.buttons` mean?** A bitmask of buttons still held after release.
6. **Why might the original element miss the release?** The pointer can move to another element before the button is released.
7. **How is `mouseup` different from `pointerup`?** `mouseup` is mouse-oriented and may fire for each button release; `pointerup` supports multiple pointer types and for mouse normally fires when the final button is released.
8. **Can `preventDefault()` on `mouseup` undo earlier selection?** Not necessarily; selection may have begun earlier.
9. **How do you dispatch a synthetic release?** `target.dispatchEvent(new MouseEvent("mouseup", options))`.
10. **Why is `click` preferred for button activation?** Native `click` activation works with keyboard and other supported input methods.

# 19. Ten quiz questions with explained answers

1. **When does `mouseup` fire?** A. Press B. Release C. Key release D. Pointer entry. **Answer: B.** It fires when a mouse button is released.
2. **Which interface represents it?** A. KeyboardEvent B. MouseEvent C. InputEvent D. FocusEvent. **Answer: B.** It is a MouseEvent.
3. **Does every `mouseup` produce `click`?** A. Yes B. No. **Answer: B.** Not every release qualifies as activation.
4. **What does `button === 2` mean?** A. Primary B. Secondary C. No buttons D. Double-click. **Answer: B.** Two is the secondary-button code.
5. **What does `buttons === 0` mean?** A. Primary B. No buttons held C. Secondary D. Invalid. **Answer: B.** The pressed-button bitmask is empty.
6. **Which property gives viewport horizontal position?** A. screenX B. pageX C. clientX D. button. **Answer: C.** `clientX` is viewport-relative.
7. **Why might the original element miss `mouseup`?** A. Pointer moved elsewhere B. Mouseup never bubbles C. Only works on buttons D. JS blocks it. **Answer: A.** Release may target another element.
8. **Which event supports mouse, touch, and pen release?** A. mouseup B. pointerup C. dblclick D. auxclick. **Answer: B.** Pointer Events cover multiple pointer types.
9. **Can synthetic `mouseup` physically release hardware?** A. Yes B. No. **Answer: B.** Synthetic dispatch invokes event listeners, not hardware.
10. **Best event for native Save button activation?** A. mouseup B. mousedown C. click D. mousemove. **Answer: C.** `click` supports normal native activation, including keyboard activation.

## Final summary

`mouseup` reports a mouse-button release. `event.button` identifies **which** button was released; `event.buttons` identifies **which buttons remain held**. Use `mouseup` for mouse-specific interaction cleanup and `click` for ordinary accessible activation.

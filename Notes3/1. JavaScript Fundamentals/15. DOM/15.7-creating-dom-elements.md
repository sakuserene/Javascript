## Learning Objectives

Learn to create, configure, nest, clone, and insert DOM elements; understand text nodes, fragments, templates, loops, event listeners, and safe handling of untrusted strings. Every major expression is explained step by step.

## 1. Understanding DOM Element Creation

Given:

```html
<body>
  <h1>Welcome</h1>
  <p>Hello World</p>
</body>
```

The DOM is a tree:

```text
document
`-- html
    `-- body
        |-- h1
        |   `-- "Welcome" (text node)
        `-- p
            `-- "Hello World" (text node)
```

JavaScript can create more nodes after the page loads. **Creating a node does not insert it into the visible document.**

## 2. document.createElement()

**Syntax:**

```javascript
const element = document.createElement("tagName");
```

Example:

```javascript
const paragraph = document.createElement("p");
```

| Token | Explanation |
|---|---|
| `const` | Declares a binding that cannot be reassigned. The element itself remains mutable. |
| `paragraph` | Name of the variable holding the element reference. |
| `=` | Assignment operator: stores the expression's result. |
| `document` | Current document object. |
| `.` | Property access operator. |
| `createElement` | Document method for creating a new element. |
| `(` and `)` | Enclose arguments to the method call. |
| `"p"` | String identifying the paragraph tag name. |
| `;` | Statement terminator. |

**Execution trace:** (1) Resolve `document`. (2) Access `createElement`. (3) Pass `"p"`. (4) Browser creates an HTMLParagraphElement. (5) Method returns its reference. (6) `paragraph` receives the reference.

Other examples:

```javascript
const heading = document.createElement("h1");
const button = document.createElement("button");
const image = document.createElement("img");
const container = document.createElement("div");
const list = document.createElement("ul");
const item = document.createElement("li");
```

Two calls create two separate objects:

```javascript
const first = document.createElement("p");
const second = document.createElement("p");
console.log(first === second); // false
```

`===` compares the identity of objects, not whether they have the same tag. `first` and `second` point to different objects, so the result is `false`.

## 3. Creating vs Inserting

```javascript
const paragraph = document.createElement("p"); // Create
paragraph.textContent = "Hello World";           // Configure
document.body.appendChild(paragraph);             // Insert
```

**`parent.appendChild(child)`** adds a node as the parent's last child and returns the node. `document.body` is the body element. `appendChild` moves an existing node rather than copying it.

Execution: (1) Create detached paragraph. (2) Assign its text. (3) Read body element. (4) Append paragraph to body. (5) Paragraph is now part of the document.

## 4. Adding Text

```javascript
const heading = document.createElement("h2");
heading.textContent = "Learning JavaScript";
document.body.appendChild(heading);
console.log(heading.textContent); // Learning JavaScript
```

`textContent` treats HTML-looking strings as text:

```javascript
heading.textContent = "<strong>Hello</strong>";
```

This displays the literal characters `<strong>Hello</strong>`; it does not create a strong element. Setting `textContent` replaces existing descendants.

## 5. Adding Attributes

```javascript
const image = document.createElement("img");
image.setAttribute("src", "photo.jpg");
image.setAttribute("alt", "A mountain landscape");
document.body.appendChild(image);
```

Alternatively use reflected DOM properties:

```javascript
const image = document.createElement("img");
image.src = "photo.jpg";
image.alt = "A mountain landscape";
```

Create a link:

```javascript
const link = document.createElement("a");
link.href = "https://example.com";
link.textContent = "Visit Website";
document.body.appendChild(link);
```

**Trace:** create anchor -> assign URL -> assign text -> append to body. Validate URLs supplied by untrusted sources before assigning them to `href` or `src`.

## 6. Adding CSS Classes

```javascript
const card = document.createElement("div");
card.classList.add("card");
card.classList.add("highlight");
card.textContent = "Hello";
document.body.appendChild(card);
```

Multiple classes can be added together:

```javascript
card.classList.add("card", "active", "rounded");
```

Compare:

```javascript
card.className = "card active rounded";
```

`className =` replaces the entire class string; `classList.add()` preserves existing class tokens.

## 7. document.createTextNode()

**Syntax:** `document.createTextNode(data)`.

```javascript
const paragraph = document.createElement("p");
const textNode = document.createTextNode("Hello JavaScript");
paragraph.appendChild(textNode);
document.body.appendChild(paragraph);
```

| Expression | Meaning |
|---|---|
| `document` | Current document. |
| `.createTextNode` | Method creating a text node. |
| `"Hello JavaScript"` | String to store in the node. |
| `const textNode = ...` | Binds the returned text node reference. |

Tree:

```text
p (element)
`-- "Hello JavaScript" (text node)
```

For simple text, `paragraph.textContent = "Hello JavaScript"` is usually shorter. `createTextNode()` is useful when you need an independent text node object.

## 8. Nested HTML Elements

Goal:

```html
<div class="card">
  <h2>Product Name</h2>
  <p>Product description</p>
</div>
```

Build it:

```javascript
const card = document.createElement("div");
card.classList.add("card");

const heading = document.createElement("h2");
heading.textContent = "Product Name";

const description = document.createElement("p");
description.textContent = "Product description";

card.appendChild(heading);
card.appendChild(description);
document.body.appendChild(card);
```

**Trace:** create parent -> add class -> create heading -> set heading text -> create paragraph -> set paragraph text -> append both to card -> append card to body.

`append()` can accept several nodes or strings:

```javascript
card.append(heading, description);
card.append(heading, " - ", description);
```

Unlike `appendChild()`, `append()` returns `undefined`.

## 9. Reusable Element Functions

```javascript
function createMessage(text) {
  const paragraph = document.createElement("p");
  paragraph.textContent = text;
  return paragraph;
}

const firstMessage = createMessage("Hello");
const secondMessage = createMessage("Welcome");
document.body.append(firstMessage, secondMessage);
```

| Syntax | Meaning |
|---|---|
| `function` | Defines a function. |
| `createMessage` | Function name. |
| `(text)` | Parameter receiving a value from the caller. |
| `{ ... }` | Function body. |
| `return paragraph` | Sends the created element back to the caller. |

**Call trace:** `createMessage("Hello")` -> parameter `text` becomes `"Hello"` -> new paragraph created -> text assigned -> paragraph returned -> stored in `firstMessage`. The next call creates a different paragraph.

## 10. Creating Elements from Arrays

```javascript
const fruits = ["Apple", "Banana", "Orange"];
const list = document.createElement("ul");

fruits.forEach(function (fruit) {
  const item = document.createElement("li");
  item.textContent = fruit;
  list.appendChild(item);
});

document.body.appendChild(list);
```

`forEach()` invokes its callback once per array element. `function (fruit) { ... }` defines a callback with one parameter, `fruit`, which receives the current array item. The braces enclose the code repeated for each item.

| Iteration | `fruit` | Node created |
|---|---|---|
| 1 | `"Apple"` | `<li>Apple</li>` |
| 2 | `"Banana"` | `<li>Banana</li>` |
| 3 | `"Orange"` | `<li>Orange</li>` |

Each iteration calls `createElement("li")` again, so each list item is a distinct node.

## 11. DocumentFragment

A `DocumentFragment` is a lightweight node container whose children can be moved into the document together.

```javascript
const fruits = ["Apple", "Banana", "Orange"];
const list = document.createElement("ul");
const fragment = document.createDocumentFragment();

fruits.forEach(function (fruit) {
  const item = document.createElement("li");
  item.textContent = fruit;
  fragment.appendChild(item);
});

list.appendChild(fragment);
document.body.appendChild(list);
```

**Trace:** create list -> create fragment -> create each item -> append items to fragment -> append fragment to list -> items move into list -> fragment becomes empty -> append list to body.

Fragments help organize node creation, but do not guarantee faster performance for every operation.

## 12. cloneNode()

**Syntax:** `node.cloneNode(deep)`.

```html
<div id="original">
  <h2>Hello</h2>
  <p>Welcome</p>
</div>
```

```javascript
const original = document.getElementById("original");
const shallow = original.cloneNode(false);
const deep = original.cloneNode(true);
deep.id = "copy";
document.body.appendChild(deep);
```

- `false`: clone the element and attributes, but not descendants.
- `true`: clone the element and its descendants.

**Important:** Cloned IDs can conflict with existing IDs. Update IDs on the clone and any cloned descendants where necessary. Event listeners registered with `addEventListener()` are **not** copied.

```javascript
const button = document.createElement("button");
button.textContent = "Click Me";
button.addEventListener("click", function () {
  console.log("Original clicked");
});
const clonedButton = button.cloneNode(true);
// clonedButton does not have that addEventListener listener.
```

## 13. HTML Templates

HTML:

```html
<template id="cardTemplate">
  <article class="card">
    <h2 class="title"></h2>
    <p class="description"></p>
  </article>
</template>
<div id="cards"></div>
```

JavaScript:

```javascript
const template = document.getElementById("cardTemplate");
const cards = document.getElementById("cards");
const clone = template.content.cloneNode(true);
clone.querySelector(".title").textContent = "New Card";
clone.querySelector(".description").textContent =
  "This card was created from a template.";
cards.appendChild(clone);
```

`template.content` is a `DocumentFragment` containing the template's inert content. `cloneNode(true)` copies all descendants. `querySelector()` finds the matching descendant within the cloned fragment. `textContent` inserts safe plain text.

## 14. Project 1: Product Cards

Create these three files in one directory.

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Dynamic Product Cards</title>
  <link rel="stylesheet" href="styles.css">
  <script src="script.js" defer></script>
</head>
<body>
  <h1>Products</h1>
  <div id="products"></div>
</body>
</html>
```

**styles.css**

```css
body {
  font-family: Arial, sans-serif;
  padding: 24px;
}
#products {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(200px, 1fr));
  gap: 16px;
}
.product-card {
  border: 1px solid #dddddd;
  border-radius: 8px;
  padding: 16px;
}
.product-card h2 { margin-top: 0; }
```

**script.js**

```javascript
const products = [
  { id: 1, name: "Keyboard", price: 3500 },
  { id: 2, name: "Mouse", price: 1500 },
  { id: 3, name: "Monitor", price: 12000 }
];

const container = document.getElementById("products");

products.forEach(function (product) {
  const card = document.createElement("article");
  card.classList.add("product-card");
  card.dataset.productId = String(product.id);

  const heading = document.createElement("h2");
  heading.textContent = product.name;

  const price = document.createElement("p");
  price.textContent = `Price: ${product.price}`;

  card.append(heading, price);
  container.appendChild(card);
});
```

**Detailed execution:** On the first iteration, `product` is `{ id: 1, name: "Keyboard", price: 3500 }`. `product.id` evaluates to `1`; `String(1)` evaluates to `"1"`; `card.dataset.productId = "1"` sets `data-product-id="1"`. `product.name` evaluates to `"Keyboard"` and becomes heading text. The template literal `` `Price: ${product.price}` `` evaluates the expression between `${` and `}`, converts `3500` to text, and produces `"Price: 3500"`. The heading and price paragraph are appended to the article, then the article is appended to the container. The process repeats for Mouse and Monitor.

**Template literal syntax:** Backticks delimit the template literal. `Price: ` is fixed text. `${` begins an embedded JavaScript expression. `product.price` reads the property. `}` ends the expression. The resulting value is interpolated into the string.

## 15. Project 2: Dynamic Task List

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Task List</title>
  <script src="script.js" defer></script>
</head>
<body>
  <h1>My Tasks</h1>
  <label for="taskInput">New task</label>
  <input id="taskInput" type="text">
  <button id="addButton" type="button">Add Task</button>
  <ul id="taskList"></ul>
</body>
</html>
```

**script.js**

```javascript
const taskInput = document.getElementById("taskInput");
const addButton = document.getElementById("addButton");
const taskList = document.getElementById("taskList");

addButton.addEventListener("click", function () {
  const taskText = taskInput.value.trim();

  if (taskText === "") {
    return;
  }

  const item = document.createElement("li");
  const text = document.createElement("span");
  text.textContent = taskText;

  const removeButton = document.createElement("button");
  removeButton.type = "button";
  removeButton.textContent = "Remove";
  removeButton.setAttribute("aria-label", `Remove task: ${taskText}`);

  removeButton.addEventListener("click", function () {
    item.remove();
  });

  item.append(text, " ", removeButton);
  taskList.appendChild(item);
  taskInput.value = "";
});
```

**Line-by-line explanation:**

1. Three `getElementById()` calls retrieve the input, add button, and list.
2. `addEventListener("click", function () { ... })` registers a callback to run when the add button is clicked. The callback is not executed during registration.
3. `taskInput.value` reads the user's current input as a string.
4. `.trim()` returns a new string without leading or trailing whitespace; it does not change the input automatically.
5. `taskText === ""` compares the trimmed string with the empty string using strict equality.
6. If true, `return;` exits the callback immediately; no list item is created.
7. `createElement("li")` creates a new list item; `createElement("span")` creates a span.
8. `text.textContent = taskText` adds user text without interpreting it as HTML.
9. A new button is created, given `type="button"`, text, and an accessible label.
10. The remove button's callback captures `item`, so it removes the correct list item when clicked.
11. `item.append(text, " ", removeButton)` inserts the span, a space text node, and the button.
12. `taskList.appendChild(item)` inserts the completed task.
13. `taskInput.value = ""` clears the input.

**Input trace:** For `"  Learn DOM  "`, `.trim()` yields `"Learn DOM"`. The comparison `"Learn DOM" === ""` is `false`, so the function continues. A list item containing `Learn DOM` and a Remove button is inserted. Clicking Remove calls `item.remove()` on that specific item.

## 16. Safe DOM Construction

Untrusted strings should normally be inserted as plain text:

```javascript
const userInput = "<img src=x onerror=alert(1)>";
const paragraph = document.createElement("p");
paragraph.textContent = userInput;
container.appendChild(paragraph);
```

This displays the literal characters rather than parsing them into HTML. Avoid interpolating untrusted text into `innerHTML`:

```javascript
// Unsafe if userProvidedTitle is untrusted:
container.innerHTML = `<h2>${userProvidedTitle}</h2>`;
```

Use a maintained sanitizer if accepting HTML is genuinely required. Validate untrusted URLs before assigning them to link or image attributes.

## 17. Common Mistakes

| Mistake | Why it matters | Correct approach |
|---|---|---|
| Create without inserting | Detached node is not displayed | Append or insert it |
| Reuse one node in multiple places | Node moves, not copies | Create or clone separate nodes |
| `innerHTML` with untrusted strings | May introduce XSS | Prefer `textContent` |
| Duplicate IDs after cloning | IDs should be unique | Update cloned IDs |
| Assume listeners are cloned | `addEventListener` listeners are not copied | Reattach or delegate listeners |
| `cloneNode(false)` expecting children | Shallow clone omits descendants | Use `cloneNode(true)` |
| Forget `return` in a factory | Caller receives `undefined` | Return the new element |
| Assume fragment remains as wrapper | Fragment's children move | Use an element for a wrapper |
| Fail to clear input | Old input remains | Set `.value = ""` |
| Append before configuring and assume it is necessary | Often harder to reason about | Build, configure, then insert |

## 18. 10 Interview Questions and Answers

**1. What does `document.createElement()` do?**  
It creates a new element node with the specified tag name. The element is initially disconnected from the document.

**2. Does `createElement()` automatically display the element?**  
No. It must be inserted into the document.

**3. What is the difference between `createElement()` and `createTextNode()`?**  
The first creates an element node; the second creates a text node holding character data.

**4. What does `appendChild()` do if the node is already in the document?**  
It moves the existing node rather than creating a copy.

**5. What is the difference between `append()` and `appendChild()`?**  
`append()` accepts multiple nodes or strings and returns `undefined`; `appendChild()` accepts one node and returns the appended node.

**6. What is a `DocumentFragment`?**  
A lightweight node container used to hold nodes before moving them into a destination.

**7. What does `cloneNode(true)` mean?**  
Deep clone: copy the node and its descendants.

**8. What does `cloneNode(false)` mean?**  
Shallow clone: copy the node without its descendants.

**9. Are listeners registered with `addEventListener()` copied by `cloneNode()`?**  
No. Reattach listeners to the clone or use event delegation.

**10. Why is `textContent` safer than `innerHTML` for user-provided plain text?**  
Because it does not parse the string as HTML markup.

### Exercise 9: Use a DocumentFragment

**Task:** Create three paragraphs with a loop and insert them together.

```javascript
const fragment = document.createDocumentFragment();
for (let i = 1; i <= 3; i++) {
  const paragraph = document.createElement("p");
  paragraph.textContent = `Paragraph ${i}`;
  fragment.appendChild(paragraph);
}
document.body.appendChild(fragment);
```

**Loop breakdown:** `let i = 1` initializes `i`. `i <= 3` checks whether it is at most three. `i++` increments by one after each iteration. The body runs with `i` equal to 1, 2, and 3; at 4 the condition is false.

| Iteration | `i` | Created text |
|---|---|---|
| 1 | 1 | Paragraph 1 |
| 2 | 2 | Paragraph 2 |
| 3 | 3 | Paragraph 3 |
| Condition check | 4 | Stop |

### Exercise 10: Reusable element factory

**Task:** Write a function returning a paragraph containing the supplied text.

```javascript
function createParagraph(text) {
  const paragraph = document.createElement("p");
  paragraph.textContent = text;
  return paragraph;
}
const first = createParagraph("First");
const second = createParagraph("Second");
document.body.append(first, second);
```

**Explanation:** The parameter `text` receives each argument. `return paragraph` sends the new node back to the caller. Two calls produce two different paragraph nodes.

## 20. Knowledge Quiz and Answers

**Q1. What does `document.createElement("p")` return?**  
A. An HTML string  
B. A new paragraph element  
C. An automatically inserted paragraph  
D. A CSS rule  
**Answer: B.** It returns a detached element node.

**Q2. What happens when `appendChild()` receives a node already in the document?**  
A. It creates a copy  
B. It always throws  
C. It moves the node  
D. It converts it into text  
**Answer: C.** Existing nodes are moved, not cloned.

**Q3. What does `cloneNode(true)` do?**  
A. Clones only the outer node  
B. Clones the node and descendants  
C. Copies all registered event listeners  
D. Removes all attributes  
**Answer: B.** `true` requests a deep clone.

**Q4. What happens when a `DocumentFragment` is appended?**  
A. It becomes a div  
B. Its children move into the destination  
C. Its children are deleted  
D. It becomes a comment  
**Answer: B.** The fragment itself does not become a wrapper element.

**Q5. Which approach is preferred for displaying untrusted plain text?**  
A. `innerHTML` with interpolation  
B. `textContent`  
C. An inline `onclick` attribute  
D. `document.write()`  
**Answer: B.** It inserts text without HTML parsing.

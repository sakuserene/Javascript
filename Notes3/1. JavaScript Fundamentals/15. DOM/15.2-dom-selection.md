## 1. What is DOM selection?

DOM selection means locating HTML elements in the browser's document tree. A selection returns either an element object, `null`, or a collection of elements. Once selected, elements can be read or modified.

```html
<h1 id="title">Welcome</h1>
<p class="message">First paragraph</p>
<p class="message">Second paragraph</p>
```

```js
const title = document.getElementById("title");
console.log(title.textContent); // Welcome
```

**Trace:** (1) Access `document`. (2) Call its `getElementById` method with the string `"title"`. (3) Find the matching `h1`. (4) Return its object reference. (5) Assign that reference to `title`. (6) Read its `textContent`.

**Syntax anatomy:** `const` declares a non-reassignable binding; `title` is the variable name; `=` assigns the result; `.` accesses a property or method; `(...)` supplies arguments; `"title"` is a string; `;` terminates the statement.

## 2. Selection methods at a glance

| Method | Looks for | Returns | Live? |
|---|---|---|---|
| `document.getElementById("id")` | Exact ID | Element or `null` | N/A |
| `root.getElementsByClassName("class")` | Class token(s) | `HTMLCollection` | Yes |
| `root.getElementsByTagName("p")` | Tag | `HTMLCollection` | Yes |
| `document.getElementsByName("name")` | `name` attribute | `NodeList` | Yes |
| `root.querySelector(".class")` | CSS selector | First element or `null` | N/A |
| `root.querySelectorAll(".class")` | CSS selector | `NodeList` | No (static) |

`root` may be `document` or an element for the applicable methods. `getElementById` and `getElementsByName` are document methods. An empty collection has `.length === 0`; it is not `null`.

## 3. getElementById

```html
<h2 id="heading">Hello JavaScript</h2>
```

```js
const heading = document.getElementById("heading");
if (heading !== null) {
  console.log(heading.textContent); // Hello JavaScript
}
```

- The argument is the ID **without** `#`.
- The return value is an element reference or `null`.
- IDs should be unique. With duplicate IDs, the first matching element in tree order is returned.
- `!==` means strict inequality. `heading !== null` protects the property access.

**Incorrect:** `document.getElementById("#heading")` searches for the literal ID `#heading`.

## 4. getElementsByClassName

```html
<p class="message important">One</p>
<p class="message">Two</p>
<p class="message important">Three</p>
```

```js
const messages = document.getElementsByClassName("message");
console.log(messages.length); // 3
console.log(messages[0].textContent); // One

const important = document.getElementsByClassName("message important");
console.log(important.length); // 2
```

The plural `Elements` matters: this method always returns a collection. `messages[0]` uses zero-based indexing. Multiple class names separated by spaces mean **all specified classes**, not either one. The resulting `HTMLCollection` is **live**, so its contents update as the DOM changes.

## 5. getElementsByTagName

```html
<section id="container"><p>Inside A</p><p>Inside B</p></section>
<p>Outside</p>
```

```js
const allParagraphs = document.getElementsByTagName("p"); // 3
const section = document.getElementById("container");
const inside = section.getElementsByTagName("p"); // 2
console.log(allParagraphs.length, inside.length);
```

`getElementsByTagName("*")` finds all descendant elements. Called on an element, it searches that element's descendants rather than the entire document. It returns a live `HTMLCollection`.

## 6. getElementsByName

```html
<label><input type="radio" name="choice" value="A"> A</label>
<label><input type="radio" name="choice" value="B"> B</label>
```

```js
const options = document.getElementsByName("choice");
console.log(options.length); // 2
```

The `name` attribute is not the same as `id`. This method returns a **live NodeList** and is available on `document`.

## 7. querySelector

`querySelector(selector)` returns the **first** element matching a valid CSS selector, or `null`.

```html
<p class="note">First</p><p class="note">Second</p>
```

```js
const firstNote = document.querySelector(".note");
console.log(firstNote.textContent); // First
const missing = document.querySelector(".does-not-exist");
console.log(missing); // null
```

In `document.querySelector(".note")`, the first dot is JavaScript property access; the dot *inside the string* is CSS syntax for a class selector. `#title` means an ID selector; `p` means a tag selector. Invalid selector syntax throws a `SyntaxError`, unlike a valid selector that simply matches nothing.

## 8. querySelectorAll

```html
<p class="note">One</p><p class="note">Two</p><p class="note">Three</p>
```

```js
const notes = document.querySelectorAll(".note");
console.log(notes.length); // 3
console.log(notes[1].textContent); // Two
notes.forEach((note) => console.log(note.textContent));
```

`querySelectorAll()` returns a **static NodeList**. If there are no matches, the result is an empty NodeList (`length` is `0`). `forEach` is available directly on this NodeList, unlike an `HTMLCollection`.

## 9. CSS selectors in depth

| Selector | Meaning |
|---|---|
| `p` | Paragraph elements |
| `.message` | Elements with class `message` |
| `#title` | Element with ID `title` |
| `*` | All elements in query scope |
| `input[type="email"]` | Email-type inputs |
| `.card p` | Paragraph descendants of `.card` |
| `.card > p` | Direct paragraph children of `.card` |
| `h2 + p` | `p` immediately after an `h2` sibling |
| `h2 ~ p` | Later `p` siblings of an `h2` |
| `h1, h2, h3` | Any of these heading tags |
| `.message.important` | Same element has both classes |
| `.message .important` | Important-class descendant of a message-class element |

```html
<div class="card">
  <p class="message important">Direct</p>
  <section><p class="message">Nested</p></section>
</div>
```

```js
console.log(document.querySelectorAll(".card p").length); // 2
console.log(document.querySelectorAll(".card > p").length); // 1
console.log(document.querySelectorAll(".message.important").length); // 1
```

The space in `.card p` is a descendant combinator; `>` is a direct-child combinator. Removing or adding a space can change the meaning completely.

## 10. Advanced selectors

```js
document.querySelectorAll("li:first-child");
document.querySelectorAll("li:last-child");
document.querySelectorAll("li:nth-child(2)");
document.querySelectorAll("li:not(.disabled)");
document.querySelectorAll("input:checked");
document.querySelectorAll("button:disabled");
document.querySelectorAll(":is(h1, h2, h3)");
document.querySelectorAll(":where(h1, h2, h3)");
document.querySelectorAll("article:has(img)");
```

- `:nth-child(2)` counts **from 1**, whereas JavaScript collection indexes start at **0**. It matches an `li` only if it is its parent's second child.
- `:not(.disabled)` excludes elements matching `.disabled`.
- `:checked` and `:disabled` match current control states.
- `:is()` and `:where()` have similar matching behavior here, but different CSS specificity behavior in stylesheets.
- `:has(img)` matches an article containing an image descendant.

## 11. Scoped queries

```html
<section id="products">
  <div class="product"><h3>Laptop</h3></div>
  <div class="product"><h3>Mouse</h3></div>
</section>
<h3>Outside heading</h3>
```

```js
const section = document.getElementById("products");
const headings = section.querySelectorAll(".product h3");
console.log(headings.length); // 2
```

**Trace:** select the section, call the query on the section object, search its descendants, return the two matching headings. To express direct children of a particular element, use `:scope`:

```js
const directProducts = section.querySelectorAll(":scope > .product");
```

## 12. Plain loops vs built-in iteration

```html
<p class="message">One</p><p class="message">Two</p><p class="message">Three</p>
```

### Traditional for loop

```js
const messages = document.querySelectorAll(".message");
for (let i = 0; i < messages.length; i++) {
  console.log(messages[i].textContent);
}
```

**Syntax:** `let i = 0` initializes the index; `i < messages.length` tests whether to continue; `i++` increments by one *after each iteration*; `messages[i]` selects the item at index `i`.

| Iteration | `i` | `i < 3` | Action |
|---|---:|---|---|
| 1 | 0 | true | Print One |
| 2 | 1 | true | Print Two |
| 3 | 2 | true | Print Three |
| Stop | 3 | false | Exit loop |

### forEach

```js
messages.forEach(function (message, index) {
  console.log(index, message.textContent);
});
```

`forEach` calls the provided callback once for each item. `message` is the current element, `index` is its zero-based position. You cannot `break` out of `forEach`.

### for...of

```js
for (const message of messages) {
  console.log(message.textContent);
}
```

`for...of` iterates over values and supports `break` and `continue`.

## 13. HTMLCollection iteration

```js
const messages = document.getElementsByClassName("message");

// Plain loop
for (let i = 0; i < messages.length; i++) {
  console.log(messages[i].textContent);
}

// for...of
for (const message of messages) {
  console.log(message.textContent);
}

// Convert to an actual array for array methods
Array.from(messages).forEach((message) => {
  console.log(message.textContent);
});
```

`Array.from(messages)` creates a new array containing the elements present **at that moment**. The new array does not automatically grow when new DOM elements are added.

## 14. Live vs static collections

```html
<div id="container"><p class="item">A</p><p class="item">B</p></div>
```

```js
const live = document.getElementsByClassName("item");
const staticList = document.querySelectorAll(".item");
console.log(live.length, staticList.length); // 2 2

const p = document.createElement("p");
p.className = "item";
p.textContent = "C";
document.getElementById("container").appendChild(p);

console.log(live.length, staticList.length); // 3 2
```

A live collection updates automatically. A static query result is a snapshot. **Pitfall:** mutating a live collection while iterating forward may skip elements:

```js
const items = document.getElementsByClassName("item");
// Unsafe: indexes shift as each element is removed.
for (let i = 0; i < items.length; i++) {
  items[i].remove();
}
```

**Trace:** `[A,B,C,D]` -> remove `A` at index 0 -> `[B,C,D]` -> index 1 now points to `C` -> `B` is skipped.

Safer alternatives:

```js
while (items.length > 0) {
  items[0].remove();
}

// Or take a snapshot first:
Array.from(items).forEach((item) => item.remove());
```

## 15. Dynamic elements

```js
const paragraph = document.createElement("p");
paragraph.className = "message";
paragraph.textContent = "New paragraph";

// Not yet part of the document:
console.log(document.querySelectorAll(".message").length);

document.body.appendChild(paragraph);
// A new query can now find it.
```

`createElement` creates a detached element. Insertion methods such as `appendChild` make it part of the document. If earlier matching elements already exist, `querySelector` still returns the **first** one.

## 16. Performance and caching

```js
const title = document.getElementById("title");
if (title) {
  title.textContent = "Hello";
  title.style.color = "blue";
  title.classList.add("active");
}
```

Caching can avoid repeated queries. However, performance differences between ID lookups and CSS selector lookups are usually not the dominant cost in a small page. Optimize measured bottlenecks, not assumptions. Cached element references may remain valid even after the element is removed, so check whether a cached reference is still the intended element after DOM replacement.

## 17. CSS.escape and special IDs

```html
<div id="user:123">Profile</div>
```

```js
const id = "user:123";
const byId = document.getElementById(id); // Works directly
const bySelector = document.querySelector(`#${CSS.escape(id)}`);
```

The colon has special meaning in CSS selectors. `CSS.escape(id)` produces a safe identifier for selector construction. In `` `#${CSS.escape(id)}` ``, backticks define a template literal and `${...}` inserts the evaluated expression.

## 18. Common mistakes

| Incorrect | Why | Correct |
|---|---|---|
| `getElementById("#title")` | `#` is not part of the ID | `getElementById("title")` |
| `querySelector("title")` | Searches for a tag | `querySelector("#title")` |
| `querySelector("message")` | Searches for a tag | `querySelector(".message")` |
| `collection.forEach(...)` on HTMLCollection | Not an Array/NodeList method there | `Array.from(collection).forEach(...)` |
| `querySelectorAll("p").textContent` | Collection has no textContent | Iterate or index it |
| `element.textContent` when element is `null` | Throws TypeError | Check for `null` |
| Assume `querySelectorAll` is live | It is static | Re-query when needed |
| Remove items in forward loop over live collection | Indexes shift | Snapshot or `while` loop |
| Query before elements parse | No match yet | Use `defer` or end-of-body script |

## 19. Practical project

Create a product list and highlight products costing less than 5000. The code uses `dataset`, `Number`, comparisons, and class manipulation.

**Complete runnable HTML:**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Product Selector</title>
  <style>
    .product { padding: 10px; margin: 6px 0; border: 1px solid #999; }
    .affordable { background: lightgreen; }
  </style>
</head>
<body>
  <div id="products">
    <div class="product" data-price="50000">Laptop</div>
    <div class="product" data-price="1500">Mouse</div>
    <div class="product" data-price="3500">Keyboard</div>
    <div class="product" data-price="8000">Monitor</div>
  </div>
  <button id="highlight">Highlight Affordable Products</button>
  <script>
    const products = document.querySelectorAll(".product");
    const button = document.getElementById("highlight");

    button.addEventListener("click", function () {
      for (let i = 0; i < products.length; i++) {
        const product = products[i];
        const price = Number(product.dataset.price);
        if (price < 5000) {
          product.classList.add("affordable");
        } else {
          product.classList.remove("affordable");
        }
      }
    });
  </script>
</body>
</html>
```

**Execution trace on click:**

| Index | Product | Price string | Number | `price < 5000` | Action |
|---|---|---|---:|---|---|
| 0 | Laptop | `"50000"` | 50000 | false | Remove class |
| 1 | Mouse | `"1500"` | 1500 | true | Add class |
| 2 | Keyboard | `"3500"` | 3500 | true | Add class |
| 3 | Monitor | `"8000"` | 8000 | false | Remove class |

`dataset.price` is a string; `Number(...)` converts it to a number; `<` compares numeric values. `classList.add` and `classList.remove` update CSS classes. The event listener is a preview of the later Events module.

## 20. Ten interview questions and answers

1. **What is DOM selection?** Locating one or more DOM elements through browser APIs.
2. **What does `getElementById` return?** An element reference or `null`.
3. **What does `getElementsByClassName` return?** A live `HTMLCollection` of matching elements.
4. **How do `querySelector` and `querySelectorAll` differ?** The first returns one element or `null`; the second returns a static NodeList of all matches.
5. **What is the difference between `HTMLCollection` and `NodeList`?** HTMLCollection holds elements and is commonly live; NodeList may hold nodes, and its liveness depends on the API. `querySelectorAll` gives a static NodeList.
6. **Why does `.message` contain a dot?** It is CSS syntax for a class selector.
7. **How do you select by ID using `querySelector`?** `document.querySelector("#title")`.
8. **Can you call `forEach` on HTMLCollection?** Not directly in general; convert with `Array.from` or use a loop.
9. **What is a live collection?** A collection that reflects relevant DOM changes automatically.
10. **Why is a forward removal loop risky with a live collection?** Removal shifts indexes, so elements may be skipped.

## 21. Ten exercises with solutions

Each solution assumes the shown HTML has been parsed before JavaScript runs. Paste the HTML into a page and place the JS in a script just before `</body>`.

### Exercise 1 - Select by ID

**Task:** Print the text of the heading.

```html
<h1 id="title">JavaScript</h1>
```

```js
const title = document.getElementById("title");
console.log(title.textContent); // JavaScript
```

**Why:** The argument `"title"` matches the ID without `#`. `textContent` reads the heading's text.

### Exercise 2 - Select by class

**Task:** Count paragraphs with class `message`.

```html
<p class="message">One</p>
<p class="message">Two</p>
<p class="message">Three</p>
```

```js
const messages = document.getElementsByClassName("message");
console.log(messages.length); // 3
```

**Why:** The method returns a collection, and `.length` counts its elements.

### Exercise 3 - Select by tag

**Task:** Print every list item.

```html
<ul><li>Apple</li><li>Banana</li><li>Orange</li></ul>
```

```js
const items = document.getElementsByTagName("li");
for (let i = 0; i < items.length; i++) {
  console.log(items[i].textContent);
}
```

**Trace:** index 0 prints Apple; 1 prints Banana; 2 prints Orange; 3 fails `i < 3` and exits.

### Exercise 4 - First matching element

**Task:** Print the first note.

```html
<p class="note">First</p><p class="note">Second</p>
```

```js
const note = document.querySelector(".note");
console.log(note.textContent); // First
```

**Why:** `querySelector` returns only the first matching element.

### Exercise 5 - All matching elements

**Task:** Print every `.item` using `forEach`.

```html
<span class="item">Red</span><span class="item">Blue</span>
```

```js
const items = document.querySelectorAll(".item");
items.forEach(function (item) {
  console.log(item.textContent);
});
```

**Why:** `querySelectorAll` returns a NodeList with a `forEach` method. The callback receives each element.

### Exercise 6 - Plain loop vs forEach

**Task:** Print all paragraph texts both ways.

```html
<p>A</p><p>B</p><p>C</p>
```

```js
const paragraphs = document.querySelectorAll("p");

for (let i = 0; i < paragraphs.length; i++) {
  console.log(paragraphs[i].textContent);
}

paragraphs.forEach(function (paragraph) {
  console.log(paragraph.textContent);
});
```

**Why:** Both produce A, B, C. The plain loop exposes the index; `forEach` passes the current item to a callback.

### Exercise 7 - Scoped selection

**Task:** Count only paragraphs inside the container.

```html
<div id="container"><p>Inside 1</p><p>Inside 2</p></div>
<p>Outside</p>
```

```js
const container = document.getElementById("container");
const paragraphs = container.querySelectorAll("p");

```

**Why:** The second query starts from the container, not the document.

### Exercise 8 - Missing element

**Task:** Safely handle a query that finds nothing.

```html
<p class="known">Exists</p>
```

```js
const element = document.querySelector(".unknown");
if (element === null) {
  console.log("Element not found");
} else {
  console.log(element.textContent);
}
```

**Why:** `===` performs strict equality. A missing valid selector returns `null`, not an empty element.

### Exercise 9 - Attribute selector

**Task:** Count checkboxes.

```html

```

```js
const checkboxes = document.querySelectorAll('input[type="checkbox"]');

```

**Why:** The selector matches `input` elements whose `type` attribute equals `checkbox`.

### Exercise 10 - Filter products, two approaches

**Task:** Print products with prices below 5000.

```html
<div class="product" data-price="1000">Mouse</div>
<div class="product" data-price="7000">Monitor</div>
<div class="product" data-price="3000">Keyboard</div>
```

**Solution A - plain loop:**

```js
const products = document.querySelectorAll(".product");
for (let i = 0; i < products.length; i++) {
  const price = Number(products[i].dataset.price);
  if (price < 5000) {
    console.log(products[i].textContent);
  }
}
```

**Solution B - built-in methods:**

```js
const products = document.querySelectorAll(".product");
Array.from(products)
  .filter(function (product) {
    return Number(product.dataset.price) < 5000;
  })
  .forEach(function (product) {
    console.log(product.textContent);
  });
```

**Expected output (both):**

```text
Mouse
Keyboard
```

**Detailed trace:** `Array.from` makes an Array; `.filter` calls its callback for Mouse (1000 < 5000, keep), Monitor (7000 < 5000, discard), Keyboard (3000 < 5000, keep). It returns a new array of two elements. `.forEach` then logs their text. In the plain loop, the same tests happen one by one without creating a filtered array.

## 22. Knowledge check

1. Which method returns a single element or `null`? **Answer:** `getElementById` or `querySelector`.
2. Which method returns a static NodeList? **Answer:** `querySelectorAll`.
3. What does `.message` select? **Answer:** Elements with the class `message`.
4. What does `querySelectorAll` return if nothing matches? **Answer:** An empty NodeList.
5. Which collection automatically updates as matching elements are added? **Answer:** A live HTMLCollection, such as one from `getElementsByClassName`.

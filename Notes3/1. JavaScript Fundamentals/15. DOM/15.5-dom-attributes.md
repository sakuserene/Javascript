## 1. What are HTML attributes?

An HTML attribute provides information or configuration for an element.

```html
<input id="username" type="text" name="username" placeholder="Enter your username" required>
```

Anatomy:

```text
<input type="text" id="username" required>
 |     |    |      |             |
 tag  name value  name          boolean attribute
```

| Attribute | Purpose |
|---|---|
| `id` | Identifies an element |
| `type` | Defines input type |
| `name` | Defines a form field name |
| `placeholder` | Provides hint text |
| `required` | Indicates that input is required |
| `href` | Defines a link destination |
| `src` | Defines a resource URL |
| `alt` | Provides alternative text for an image |

Example:

```html
<img src="photo.jpg" alt="A mountain">
```

`src` and `alt` are attribute names. `photo.jpg` and `A mountain` are their values.

JavaScript can read, add, modify, remove, and test attributes.

## 2. getAttribute()

`getAttribute(name)` reads the stored value of an attribute.

```html
<a id="website" href="https://example.com">Visit Website</a>
```

```javascript
const website = document.getElementById("website");
const url = website.getAttribute("href");
console.log(url); // https://example.com
```

### Syntax, piece by piece

```javascript
const url = website.getAttribute("href");
```

| Token | Meaning |
|---|---|
| `const` | Declares a binding that cannot be reassigned |
| `url` | Name of the new variable |
| `=` | Assigns the result on the right |
| `website` | Variable referencing the anchor element |
| `.` | Accesses an object property or method |
| `getAttribute` | Method that retrieves an attribute value |
| `(` `)` | Enclose the method arguments |
| `"href"` | Name of the attribute to read |
| `;` | Ends the statement |

Execution trace:

1. Evaluate `website` to obtain the anchor element.
2. Find its `getAttribute` method.
3. Pass the string `"href"`.
4. Look up the stored attribute.
5. Return its string value and assign it to `url`.

Missing attributes return `null`, not `undefined`:

```javascript
website.getAttribute("title"); // null, if no title exists
```

An existing empty attribute returns `""`:

```html
<button id="save" title="">Save</button>
```

```javascript
const save = document.getElementById("save");
console.log(save.getAttribute("title")); // ""
```

All non-null results are strings:

```html
<img id="photo" src="mountain.jpg" alt="Mountain landscape" width="400">
```

```javascript
const photo = document.getElementById("photo");
console.log(photo.getAttribute("src"));   // mountain.jpg
console.log(photo.getAttribute("alt"));   // Mountain landscape
console.log(photo.getAttribute("width")); // "400" (string)
```

## 3. setAttribute()

`setAttribute(name, value)` creates or updates an attribute.

```javascript
website.setAttribute("href", "https://developer.mozilla.org");
```

| Token | Meaning |
|---|---|
| `website` | Target element |
| `.` | Method access |
| `setAttribute` | Method that sets an attribute |
| `"href"` | Attribute name (first argument) |
| `,` | Separates arguments |
| `"https://developer.mozilla.org"` | New value (second argument) |

Execution trace:

| Step | Operation | Stored `href` |
|---|---|---|
| 1 | Initial markup | `https://example.com` |
| 2 | Call `setAttribute` | Not changed yet |
| 3 | Assign new value | `https://developer.mozilla.org` |
| 4 | Read with `getAttribute` | `https://developer.mozilla.org` |

Create a previously absent attribute:

```javascript
const message = document.getElementById("message");
message.setAttribute("title", "This is a greeting");
```

The return value of `setAttribute()` is `undefined`:

```javascript
const result = message.setAttribute("title", "Greeting");
console.log(result); // undefined
```

The method modifies the element, not the variable holding its return value.

## 4. removeAttribute()

`removeAttribute(name)` removes the named attribute.

```html
<button id="submitButton" disabled>Submit</button>
```

```javascript
const button = document.getElementById("submitButton");
button.removeAttribute("disabled");
```

Before: `<button disabled>Submit</button>`  
After: `<button>Submit</button>`

Removing a missing attribute does nothing and does not itself throw:

```javascript
button.removeAttribute("title");
```

The method returns `undefined`.

## 5. hasAttribute()

`hasAttribute(name)` tests whether the attribute is present and returns `true` or `false`.

```html
<input id="email" type="email" required>
```

```javascript
const email = document.getElementById("email");
console.log(email.hasAttribute("required")); // true
```

Using a condition:

```javascript
if (button.hasAttribute("disabled")) {
  console.log("Button is disabled");
}
```

Step by step:

1. Evaluate `button.hasAttribute("disabled")`.
2. The result is a boolean.
3. `if` runs the block only when the result is `true`.
4. If the result is `false`, execution skips the block.

Attribute presence is not the same as an attribute value equal to `"true"`.

## 6. toggleAttribute()

`toggleAttribute(name)` adds an attribute if absent and removes it if present.

```javascript
const button = document.getElementById("action");
button.toggleAttribute("disabled"); // add if absent
button.toggleAttribute("disabled"); // remove if present
```

Optional force argument:

```javascript
button.toggleAttribute("disabled", true);  // ensure present
button.toggleAttribute("disabled", false); // ensure absent
```

The return value indicates whether the attribute is present after the call:

```javascript
const result = button.toggleAttribute("disabled", true);
console.log(result); // true
```

### Interactive-demo equivalent for GitHub

Save this as `toggle-demo.html` and open it in a browser:

```html
<!doctype html>
<html lang="en">
<head><meta charset="utf-8"><title>Toggle Demo</title></head>
<body>
  <button id="example">Example button</button>
  <button id="toggle">Toggle disabled attribute</button>
  <p id="state"></p>
  <script>
    const example = document.getElementById("example");
    const toggle = document.getElementById("toggle");
    const state = document.getElementById("state");
    function update() {
      state.textContent = example.hasAttribute("disabled")
        ? "disabled present"
        : "disabled absent";
    }
    toggle.addEventListener("click", function () {
      example.toggleAttribute("disabled");
      update();
    });
    update();
  </script>
</body>
</html>
```

The separate toggle control remains enabled so you can turn the example button back on.

## 7. Boolean attributes

Boolean HTML attributes include `disabled`, `required`, `checked`, `readonly`, `multiple`, `autofocus`, and `hidden`.

**Presence means true**, regardless of the string value:

```html
<button disabled="false">Submit</button>
```

This button is still disabled.

Correct ways to enable it:

```javascript
button.removeAttribute("disabled");
button.disabled = false;
button.toggleAttribute("disabled", false);
```

Not every attribute with a `true` or `false` string is a boolean HTML attribute. For example:

```html
<button aria-expanded="false">Menu</button>
```

`aria-expanded="false"` communicates a meaningful accessibility state. Removing it is not equivalent to setting it to `"false"`.

## 8. HTML attributes vs DOM properties

An HTML attribute is stored in markup. A DOM property is a JavaScript object property. Some are reflected, but others represent current state separately from defaults.

```html
<input id="username" value="Guest">
```

```javascript
const input = document.getElementById("username");
console.log(input.getAttribute("value")); // Guest
console.log(input.value);                 // Guest initially
```

After the user types `Alex`:

```javascript
console.log(input.getAttribute("value")); // Guest
console.log(input.value);                 // Alex
```

Why? The `value` attribute establishes the default; the `value` property represents the current input value.

| HTML attribute | DOM property | Notes |
|---|---|---|
| `id` | `id` | Generally reflected |
| `class` | `className` | Different names |
| `for` | `htmlFor` | Label element |
| `value` | `value` | Current value may differ from default |
| `checked` | `checked` | Current state may differ from default |
| `disabled` | `disabled` | Boolean reflection |
| `href` | `href` | Property may resolve to absolute URL |

### Runnable input demonstration

```html
<input id="username" value="Guest">
<button id="inspect">Inspect</button>
<pre id="output"></pre>
<script>
  const input = document.getElementById("username");
  document.getElementById("inspect").addEventListener("click", function () {
    document.getElementById("output").textContent =
      `Attribute: ${input.getAttribute("value")}\nProperty: ${input.value}`;
  });
</script>
```

Change the input and click Inspect to see the distinction.

## 9. Reading attributes through properties

Common reflected properties can be convenient:

```html
<img id="photo" src="images/mountain.jpg" alt="Mountain">
<a id="link" href="/about">About</a>
```

```javascript
const photo = document.getElementById("photo");
console.log(photo.src);
console.log(photo.alt);

const link = document.getElementById("link");
console.log(link.getAttribute("href")); // /about
console.log(link.href);                 // resolved absolute URL
```

If the page base URL is `https://example.com`, `link.href` typically becomes `https://example.com/about`.

Use `getAttribute()` for the stored attribute string. Use DOM properties for current state or normalized representations when appropriate.

## 10. dataset and data-* attributes

Custom attributes beginning with `data-` can store element-specific data.

```html
<div id="product" data-product-id="101" data-price="2500" data-category="electronics">Keyboard</div>
```

```javascript
const product = document.getElementById("product");
console.log(product.dataset.productId); // "101"
console.log(product.dataset.price);     // "2500"
console.log(product.dataset.category);  // "electronics"
```

All these values are **strings**.

| HTML name | JavaScript access |
|---|---|
| `data-price` | `dataset.price` |
| `data-user-id` | `dataset.userId` |
| `data-product-name` | `dataset.productName` |
| `data-order-status` | `dataset.orderStatus` |

This is called camelCase conversion: `product id` becomes `productId`.

Updating:

```javascript
product.dataset.price = "3000";
```

Creating:

```javascript
product.dataset.stock = "available";
```

Removing:

```javascript
delete product.dataset.stock;
// Or:
product.removeAttribute("data-stock");
```

Avoid dot syntax with hyphenated names:

```javascript
// Wrong:
// product.dataset.product-id
// Correct:
product.dataset.productId;
```

## 11. Number() and numeric conversion

```javascript
const price = Number(product.dataset.price);
```

Breakdown:

| Part | Meaning |
|---|---|
| `const` | Declares a binding |
| `price` | Variable name |
| `=` | Assignment |
| `Number` | Built-in conversion function |
| `product` | Element reference |
| `.dataset` | Access to `data-*` values |
| `.price` | Reads the `data-price` string |
| `Number(...)` | Attempts numeric conversion |

Execution trace:

```text
product.dataset.price -> "2500" (string)
Number("2500")       -> 2500 (number)
price                -> 2500
```

Invalid input:

```javascript
Number("hello");                 // NaN
Number.isNaN(Number("hello"));   // true
```

For external or user-provided values, validate the conversion before calculating.

## 12. Attribute selectors

Attributes are usable in CSS selectors:

```html
<input type="text" name="username">
<input type="email" name="email">
<input type="checkbox" name="remember">
```

```javascript
const emailInput = document.querySelector('input[type="email"]');
```

| Selector | Meaning |
|---|---|
| `[required]` | Has `required` attribute |
| `[data-price]` | Has `data-price` attribute |
| `[type="email"]` | Exact value `email` |
| `[data-status="active"]` | Exact status |
| `[href^="https://"]` | Value starts with `https://` |
| `[href$=".pdf"]` | Value ends with `.pdf` |
| `[class~="active"]` | Contains whitespace-separated token `active` |

Example:

```html
<div class="product" data-price="1000">Mouse</div>
<div class="product" data-price="8000">Monitor</div>
<div class="product" data-price="3000">Keyboard</div>
```

```javascript
const products = document.querySelectorAll(".product");
products.forEach(function (product) {
  const price = Number(product.dataset.price);
  if (price > 5000) {
    console.log(product.textContent);
  }
});
// Monitor
```

## 13. The attributes collection

`element.attributes` returns a `NamedNodeMap` of attribute nodes, **not** an `HTMLCollection`.

```html
<img id="photo" src="mountain.jpg" alt="Mountain">
```

```javascript
const photo = document.getElementById("photo");
for (const attribute of photo.attributes) {
  console.log(attribute.name, attribute.value);
}
```

Typical output:

```text
id photo
src mountain.jpg
alt Mountain
```

`attribute.name` returns the name; `attribute.value` returns the value. Do not rely on attribute order unless the relevant API guarantees what you need. `NamedNodeMap` supports indexed access and `getNamedItem()`.

## 14. Working with multiple attributes

```javascript
const button = document.createElement("button");
button.setAttribute("id", "saveButton");
button.setAttribute("type", "button");
button.setAttribute("title", "Save changes");
button.textContent = "Save";
document.body.appendChild(button);
```

Equivalent use of common DOM properties:

```javascript
const button = document.createElement("button");
button.id = "saveButton";
button.type = "button";
button.title = "Save changes";
button.textContent = "Save";
document.body.appendChild(button);
```

Both approaches are valid for these attributes.

## 15. Attribute security

`setAttribute()` is not automatically safe for arbitrary untrusted values.

```javascript
link.setAttribute("href", userProvidedUrl);
```

A dangerous URL scheme, such as `javascript:`, can create risk when the link is activated.

For links that should use HTTP or HTTPS:

```javascript
function setSafeLink(link, value) {
  try {
    const url = new URL(value, document.baseURI);

    if (url.protocol !== "https:" && url.protocol !== "http:") {
      return false;
    }

    link.href = url.href;
    return true;
  } catch {
    return false;
  }
}
```

Breakdown of the condition:

```javascript
url.protocol !== "https:" && url.protocol !== "http:"
```

- `!==` means strict inequality.
- `&&` means logical AND.
- First comparison asks whether the protocol is not HTTPS.
- Second comparison asks whether the protocol is not HTTP.
- Both must be true for the condition to reject the URL.

Trace:

| Protocol | Not HTTPS | Not HTTP | Reject? |
|---|---|---|---|
| `https:` | false | true | No |
| `http:` | true | false | No |
| `javascript:` | true | true | Yes |

This only validates schemes. A real application may also need trusted-domain allowlists and other protections. Never assign untrusted strings to event-handler attributes.

## 16. Project: Product information card

### Complete HTML (`index.html`)

```html
<!doctype html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <title>Product Information</title>
  <script src="script.js" defer></script>
</head>
<body>
  <div id="product" data-product-id="101" data-name="Keyboard" data-price="3500" data-stock="available">
    <h2>Keyboard</h2>
    <button id="detailsButton">Show Details</button>
  </div>
  <p id="output"></p>
</body>
</html>
```

### Complete JavaScript (`script.js`)

```javascript
const product = document.getElementById("product");
const detailsButton = document.getElementById("detailsButton");
const output = document.getElementById("output");

detailsButton.addEventListener("click", function () {
  const productId = product.dataset.productId;
  const name = product.dataset.name;
  const price = Number(product.dataset.price);
  const stock = product.dataset.stock;

  output.textContent =
    `ID: ${productId}, Name: ${name}, Price: ${price}, Stock: ${stock}`;
});
```

### Execution trace

1. The browser loads the document and deferred script.
2. JavaScript selects the product, button, and output paragraph.
3. `addEventListener("click", ...)` registers a callback.
4. The user clicks the button.
5. The callback reads `data-product-id`, `data-name`, `data-price`, and `data-stock`.
6. `Number(...)` converts the price from a string to a number.
7. The template literal inserts values using `${...}`.
8. `textContent` displays the resulting string safely.

Expected output:

```text
ID: 101, Name: Keyboard, Price: 3500, Stock: available
```

### Understanding the template literal

```javascript
`ID: ${productId}, Name: ${name}`
```

- Backticks create a template literal.
- `${productId}` evaluates the `productId` variable and inserts its value.
- `${name}` does the same for `name`.
- The literal characters, such as `ID:` and `Name:`, remain unchanged.

## 17. Project: Enable and disable a form button

### HTML

```html
<label>
  <input id="agreement" type="checkbox">
  I agree to the terms
</label>
<button id="submitButton" disabled>Submit</button>
```

### JavaScript

```javascript
const agreement = document.getElementById("agreement");
const submitButton = document.getElementById("submitButton");

agreement.addEventListener("change", function () {
  submitButton.disabled = !agreement.checked;
});
```

### Understanding `!`

The `!` operator means logical NOT: it reverses a boolean.

| `agreement.checked` | `!agreement.checked` | Button state |
|---|---|---|
| `true` | `false` | Enabled |
| `false` | `true` | Disabled |

Execution trace:

1. Initially, checkbox is unchecked and button is disabled.
2. User checks the box.
3. Browser dispatches a `change` event.
4. Callback reads `agreement.checked` as `true`.
5. `!true` evaluates to `false`.
6. `submitButton.disabled = false` enables the button.
7. Unchecking the box reverses the result.

## 18. Common mistakes

| Mistake | Problem | Fix |
|---|---|---|
| `getAttribute()` on `null` | TypeError | Check selection first |
| Assuming `getAttribute()` returns a number | Returns string or `null` | Convert and validate |
| `disabled="false"` | Still disabled | Remove attribute or set property false |
| Confusing `value` attribute and property | Default/current differ | Choose correct API |
| Assuming `dataset.price` is numeric | String value | Use `Number()` |
| `dataset.product-id` | Not valid property access for that name | Use `dataset.productId` |
| Trusting arbitrary `href` values | Unsafe schemes possible | Validate URL and destination |
| Assuming every attribute has matching property | Not always | Consult DOM API |
| Expecting `undefined` for absent attribute | Returns `null` | Check `=== null` |
| Confusing `class` and `className` | Different API names | Use correct property |

## 19. Ten interview questions and answers

**Q1. What is an HTML attribute?**  
An attribute supplies configuration or additional information for an HTML element, such as `id`, `href`, `type`, or `required`.

**Q2. What does `getAttribute()` return when an attribute is missing?**  
It returns `null`. An existing attribute with an empty value returns `""`.

**Q3. What is the difference between `setAttribute()` and `removeAttribute()`?**  
`setAttribute()` creates or updates an attribute. `removeAttribute()` removes it.

**Q4. What does `hasAttribute()` return?**  
A boolean: `true` if present, `false` if absent.

**Q5. What does `toggleAttribute()` do?**  
It toggles presence or enforces a specified presence with an optional boolean force argument.

**Q6. Why does `disabled="false"` still disable a button?**  
`disabled` is a boolean HTML attribute, so its presence, not its string value, matters.

**Q7. What is the difference between an attribute and a DOM property?**  
Attributes are part of markup; properties belong to the JavaScript DOM object. Current property state can differ from the initial/default attribute.

**Q8. What is `dataset`?**  
It is a `DOMStringMap` that provides access to an element's `data-*` attributes.

**Q9. What type does `dataset.price` return?**  
A string, even if it contains digits.

**Q10. Can `setAttribute()` introduce security risks?**  
Yes. Untrusted URL values and event-handler attributes can be dangerous. Validate values and use safe APIs.

## 20. Ten coding exercises and solutions

### Exercise 1: Read an attribute

```html
<a id="link" href="https://example.com">Example</a>
```

Task: Print the `href` attribute.

```javascript
const link = document.getElementById("link");
console.log(link.getAttribute("href"));
// https://example.com
```

Explanation: `getElementById` selects the anchor, then `getAttribute("href")` retrieves the stored URL string.

### Exercise 2: Update an attribute

Task: Change the link destination.

```javascript
const link = document.getElementById("link");
link.setAttribute("href", "https://developer.mozilla.org");
```

Explanation: The first argument identifies the attribute; the second supplies the new value.

### Exercise 3: Remove an attribute

```html
<button id="button" disabled>Submit</button>
```

Task: Enable the button.

```javascript
const button = document.getElementById("button");
button.removeAttribute("disabled");
```

Explanation: Removing the boolean attribute removes the disabled state.

### Exercise 4: Check attribute existence

Task: Print whether the button has `disabled`.

```javascript
const button = document.getElementById("button");
console.log(button.hasAttribute("disabled"));
```

Explanation: The result is `true` or `false` depending on current presence.

### Exercise 5: Toggle an attribute

Task: Toggle disabled state.

```javascript
const button = document.getElementById("button");
button.toggleAttribute("disabled");
```

Explanation: If present, remove it; if absent, add it.

### Exercise 6: Read a data attribute

```html
<div id="product" data-price="2500"></div>
```

Task: Print the price.

```javascript
const product = document.getElementById("product");
console.log(product.dataset.price); // "2500"
```

Explanation: `dataset.price` accesses `data-price` and returns a string.

### Exercise 7: Convert dataset to a number

Task: Add 500 to the price.

```javascript
const product = document.getElementById("product");
const price = Number(product.dataset.price);
console.log(price + 500); // 3000
```

Step by step:

1. Read `"2500"` from `dataset.price`.
2. `Number("2500")` evaluates to `2500`.
3. `2500 + 500` evaluates to `3000`.
4. Print `3000`.

Without conversion, `"2500" + 500` would concatenate to `"2500500"`.

### Exercise 8: Update a data attribute

Task: Change price to 3000.

```javascript
const product = document.getElementById("product");
product.dataset.price = "3000";
```

Explanation: Assigning the dataset property updates `data-price` in the DOM.

### Exercise 9: Read all attributes

```html
<img id="photo" src="photo.jpg" alt="Sample photo">
```

Task: Print attribute names and values.

```javascript
const photo = document.getElementById("photo");
for (const attribute of photo.attributes) {
  console.log(attribute.name, attribute.value);
}
```

Explanation: `photo.attributes` is iterable. Each iteration receives an attribute node with `name` and `value` properties.

### Exercise 10: Checkbox-controlled button

```html
<input id="agree" type="checkbox">
<button id="submit" disabled>Submit</button>
```

Task: Enable Submit only when checked.

```javascript
const agree = document.getElementById("agree");
const submit = document.getElementById("submit");

agree.addEventListener("change", function () {
  submit.disabled = !agree.checked;
});
```

Step by step:

1. Select the checkbox and button.
2. Register a `change` listener.
3. When the checkbox changes, read `agree.checked`.
4. Apply `!` to reverse the boolean.
5. Assign the result to `submit.disabled`.
6. Checked -> `true` -> `!true` -> `false` -> button enabled.
7. Unchecked -> `false` -> `!false` -> `true` -> button disabled.

## 21. Knowledge check

Answer before consulting the key.

**1. What does `getAttribute()` return for an absent attribute?**

A. `undefined`  
B. `false`  
C. `null`  
D. `0`

**2. What does `disabled="false"` do on a button?**

A. Enables it  
B. Disables it  
C. Removes `disabled`  
D. Throws an error

**3. How do you read `data-user-id` using `dataset`?**

A. `element.dataset.user-id`  
B. `element.dataset.userId`  
C. `element.data.userId`  
D. `element.getData("user-id")`

**4. What type is `dataset.price`?**

A. Number  
B. Boolean  
C. String  
D. BigInt

**5. Which method removes an attribute?**

A. `deleteAttribute()`  
B. `removeAttribute()`  
C. `clearAttribute()`  
D. `unsetAttribute()`

### Answer key

1. **C - `null`.** `getAttribute()` returns `null` when the named attribute is missing.
2. **B - Disables it.** Presence of the boolean attribute is what matters.
3. **B - `element.dataset.userId`.** `data-*` names are converted to camelCase.
4. **C - String.** Dataset values are strings, even when they look numeric.
5. **B - `removeAttribute()`.** It removes the named attribute.

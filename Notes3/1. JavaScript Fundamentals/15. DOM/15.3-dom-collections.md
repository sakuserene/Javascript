## 2. What Is a DOM Collection?

A DOM collection is an object that gives access to multiple DOM nodes or elements.

```html
<ul>
  <li>Apple</li>
  <li>Banana</li>
  <li>Orange</li>
</ul>
```

```javascript
const items = document.querySelectorAll("li");
console.log(items.length); // 3
console.log(items[0].textContent); // Apple
console.log(items[1].textContent); // Banana
console.log(items[2].textContent); // Orange
```

Conceptual diagram (not an actual JavaScript array):

```text
items (NodeList)
|-- [0] --> li --> "Apple"
|-- [1] --> li --> "Banana"
\-- [2] --> li --> "Orange"
```

**Syntax breakdown:** `const` declares a non-reassignable binding; `items` is its name; `=` assigns the result; `document` is the page's document object; `.` accesses a property or method; `querySelectorAll` is a method that accepts a CSS selector; `("li")` supplies the selector string; `;` ends the statement. The brackets in `items[0]` retrieve the item at index zero. `.textContent` reads its text.

**Execution trace:** The browser evaluates `document.querySelectorAll("li")`, matches three `li` elements in document order, returns a static `NodeList`, and assigns that collection reference to `items`. Indexes 0, 1, and 2 refer to the three elements.

## 3. HTMLCollection

An `HTMLCollection` is an array-like collection of **elements**. Common sources include `getElementsByClassName()`, `getElementsByTagName()`, and an element's `children` property.

```html
<p class="message">Hello</p>
<p class="message">Welcome</p>
<p class="message">Goodbye</p>
```

```javascript
const messages = document.getElementsByClassName("message");
console.log(messages.length); // 3
console.log(messages[0].textContent); // Hello
console.log(messages.item(1).textContent); // Welcome
```

**Methods and properties:**

- `.length` is a numeric property, not a function.
- `[index]` accesses an item by its zero-based index.
- `.item(index)` accesses an item by index.
- `.namedItem(name)` looks for a suitable matching ID or name in the collection.

```javascript
console.log(messages[99]);       // undefined
console.log(messages.item(99));  // null
```

The difference matters: bracket lookup for an absent index evaluates to `undefined`, whereas `.item()` returns `null`.

**Named lookup:**

```html
<form id="loginForm"></form>
<form id="registerForm"></form>
```

```javascript
const forms = document.forms;
console.log(forms.namedItem("loginForm")); // the login form element
console.log(forms.namedItem("missing"));   // null
```

`document.forms` is an `HTMLCollection` of form elements. Do not assume every DOM collection supports `.namedItem()`; `NodeList` does not.

## 4. NodeList

A `NodeList` is an array-like collection of nodes. A `NodeList` can contain element nodes, text nodes, comment nodes, or other nodes depending on how it was obtained.

```html
<div class="box">A</div>
<div class="box">B</div>
```

```javascript
const boxes = document.querySelectorAll(".box");
console.log(boxes.length); // 2
console.log(boxes.item(0).textContent); // A
```

`querySelectorAll()` returns a **static NodeList** of matching elements. In contrast, `childNodes` returns a **live NodeList** of a node's direct children.

```html
<div id="container"><p>Hello</p>World</div>
```

```javascript
const container = document.getElementById("container");
const nodes = container.childNodes;
console.log(nodes.length); // 2
console.log(nodes[0].nodeType); // 1 (element)
console.log(nodes[1].nodeType); // 3 (text)
```

## 5. HTMLCollection vs NodeList vs Array

| Feature | HTMLCollection | NodeList | Array |
|---|---|---|---|
| Stores | Elements | Nodes | Any JavaScript values |
| Indexed access | Yes | Yes | Yes |
| `.length` | Yes | Yes | Yes |
| `.item()` | Yes | Yes | No |
| `.namedItem()` | Yes | No | No |
| `.forEach()` | No | Yes | Yes |
| `.map()` | No | No | Yes |
| `.filter()` | No | No | Yes |
| `.push()` | No | No | Yes |
| Live or static | Usually live | Depends on source | Fixed membership until explicitly changed |
| `for...of` | Yes in modern browsers | Yes | Yes |

**Key rule:** Determine liveness from the API that returned the collection, not simply from its type.

## 6. Live Collections

A live collection automatically reflects changes to the underlying DOM.

```html
<div id="container">
  <p class="item">Item 1</p>
  <p class="item">Item 2</p>
</div>
```

```javascript
const items = document.getElementsByClassName("item");
console.log(items.length); // 2

const newItem = document.createElement("p");
newItem.className = "item";
newItem.textContent = "Item 3";
console.log(items.length); // 2: new element is still detached

document.getElementById("container").appendChild(newItem);
console.log(items.length); // 3: live collection updates

newItem.remove();
console.log(items.length); // 2
```

**Execution trace:**

| Step | Operation | `items.length` |
|---|---|---:|
| 1 | Query `.item` elements | 2 |
| 2 | Create detached `p` | 2 |
| 3 | Set its class and text | 2 |
| 4 | Append it to document | 3 |
| 5 | Remove it | 2 |

The original collection object is reused; no new query is required.

## 7. Static Collections

A static collection retains its **membership** from the time it was created.

```html
<div id="container">
  <p class="item">One</p>
  <p class="item">Two</p>
</div>
```

```javascript
const items = document.querySelectorAll(".item");
console.log(items.length); // 2

const extra = document.createElement("p");
extra.className = "item";
extra.textContent = "Three";
document.getElementById("container").appendChild(extra);

console.log(items.length); // 2
const refreshed = document.querySelectorAll(".item");
console.log(refreshed.length); // 3
```

**Important distinction:** Static membership does **not** make the referenced DOM elements immutable.

```javascript
items[0].textContent = "Updated"; // Updates the actual element
items[0].remove();                 // Removes it from the document
console.log(items.length);         // Still 2
```

The old `NodeList` can retain references to detached elements.

## 8. children vs childNodes

```html
<div id="container"><p>Hello</p>World</div>
```

```javascript
const container = document.getElementById("container");
console.log(container.children.length);   // 1
console.log(container.childNodes.length); // 2
```

`children` is a live `HTMLCollection` of direct **element** children. `childNodes` is a live `NodeList` of **all** direct child nodes.

```text
container (div)
|-- p element
|   \-- text node "Hello"
\-- text node "World"
```

**Whitespace warning:** Newlines and indentation in HTML can produce additional text nodes.

```html
<div id="example">
  <span>Hi</span>
</div>
```

Here, `childNodes` typically includes whitespace text nodes before and after the `span`; `children` contains just the `span`.

## 9. Traditional for Loops

```html
<p class="message">First</p>
<p class="message">Second</p>
<p class="message">Third</p>
```

```javascript
const messages = document.getElementsByClassName("message");
for (let i = 0; i < messages.length; i++) {
  console.log(messages[i].textContent);
}
```

**Break down every part of `for (let i = 0; i < messages.length; i++)`:**

- `for`: starts a loop.
- `(` and `)`: surround the three loop-control expressions.
- `let`: declares a reassignable variable.
- `i`: index variable.
- `=`: assigns the initial value.
- `0`: first index.
- First `;`: separates initialization from condition.
- `i < messages.length`: continues while `i` is less than the number of elements.
- `<`: less-than comparison operator.
- Second `;`: separates condition from update.
- `i++`: increments `i` after each iteration.
- `{` and `}`: contain the repeated statements.
- `messages[i]`: element at the current index.
- `.textContent`: its text.
- `console.log(...)`: prints the text.

**Trace:**

| Check | `i` | `i < 3` | Action |
|---|---:|---|---|
| 1 | 0 | true | Print First |
| 2 | 1 | true | Print Second |
| 3 | 2 | true | Print Third |
| 4 | 3 | false | Stop |

**What does `i++` do?** Used as a standalone statement, it increments the variable by one, just like `i = i + 1`. But postfix increment returns the *old* value if that returned value is used:

```javascript
let i = 5;
const before = i++;
console.log(before); // 5
console.log(i);      // 6

let j = 5;
const after = ++j;
console.log(after); // 6
console.log(j);     // 6
```

`++j` is prefix increment: it returns the new value.

## 10. while Loops

```javascript
const messages = document.querySelectorAll(".message");
let i = 0;
while (i < messages.length) {
  console.log(messages[i].textContent);
  i++;
}
```

A `while` loop checks its condition **before** each iteration. `i` starts at zero, the condition is evaluated, the body executes when true, and `i++` moves to the next index. Forgetting `i++` can cause an infinite loop.

**A special use with live collections:**

```javascript
const items = document.getElementsByClassName("item");
while (items.length > 0) {
  items[0].remove();
}
```

`items.length > 0` means "there is at least one matching element." Each removal shrinks the live collection, so the first element is removed repeatedly until none remain.

## 11. for...of and Control Flow

```javascript
const messages = document.querySelectorAll(".message");
for (const message of messages) {
  console.log(message.textContent);
}
```

`for` begins iteration; `const message` declares a new binding for the current iteration; `of` obtains values from an iterable; `messages` is the iterable collection. Unlike `for...in`, `for...of` iterates **values**, not enumerable property keys.

**Stop early with `break`:**

```javascript
for (const message of messages) {
  if (message.textContent === "Second") {
    break;
  }
  console.log(message.textContent);
}
// Prints First only
```

`===` checks strict equality. `break` exits the loop entirely.

**Skip one iteration with `continue`:**

```javascript
for (const message of messages) {
  if (message.textContent === "Second") {
    continue;
  }
  console.log(message.textContent);
}
// Prints First, then Third
```

`continue` skips the rest of the current iteration but does not end the loop.

## 12. forEach and Callbacks

`NodeList` provides `.forEach()`; `HTMLCollection` does not generally provide it directly.

```javascript
const messages = document.querySelectorAll(".message");
messages.forEach(function (message, index, collection) {
  console.log(index, message.textContent);
});
```

**Syntax breakdown:** `messages.forEach` accesses a method; the outer `(...)` supplies a callback; `function` declares a function expression; `(message, index, collection)` names the callback's parameters; `{...}` is its body; `);` closes the callback and method call. The DOM API calls the function once per node.

- `message`: current node.
- `index`: current zero-based position.
- `collection`: original `NodeList`.

The same operation with an arrow function:

```javascript
messages.forEach((message) => {
  console.log(message.textContent);
});
```

`=>` is the arrow-function token. It is not a comparison operator. The parentheses surround the parameter; braces contain the function body.

**Important:** `break` cannot be used to exit the `forEach()` callback. Choose `for...of` when early exit is needed.

## 13. Converting Collections into Arrays

DOM collections are not JavaScript arrays, so `.map()` and `.filter()` are not directly available on them.

**Option A: `Array.from()`**

```javascript
const messages = document.querySelectorAll(".message");
const array = Array.from(messages);
console.log(Array.isArray(array)); // true
```

`Array.from()` creates a new array containing the current values of an iterable or array-like object. `Array.isArray()` returns `true` when its argument is an array.

**Option B: Spread syntax**

```javascript
const array = [...messages];
```

The three dots `...` inside an array literal expand values from an iterable into the new array. Both approaches copy **references** to DOM elements, not the elements themselves.

**Option C: Convert and map in one step**

```javascript
const texts = Array.from(messages, function (message) {
  return message.textContent;
});
```

`return` sends the current element's text back to the mapping operation, producing an array of strings.

## 14. map, filter, find, some, every

```html
<div class="product" data-price="1000">Mouse</div>
<div class="product" data-price="3000">Keyboard</div>
<div class="product" data-price="7000">Monitor</div>
```

```javascript
const products = Array.from(document.querySelectorAll(".product"));
```

**`map()` transforms every item:**

```javascript
const names = products.map(function (product) {
  return product.textContent;
});
console.log(names); // ["Mouse", "Keyboard", "Monitor"]
```

**`filter()` keeps items whose callback returns truthy:**

```javascript
const affordable = products.filter(function (product) {
  const price = Number(product.dataset.price);
  return price < 5000;
});
console.log(affordable.length); // 2
```

**Breakdown of `Number(product.dataset.price) < 5000`:**

- `product` is the current DOM element.
- `.dataset` exposes its `data-*` attributes.
- `.price` accesses the `data-price` value as a string.
- `Number(...)` converts that string into a number.
- `<` compares two numbers.
- `5000` is the threshold.
- `return` provides the boolean result to `filter()`.

**Trace:**

| Product | Raw data-price | Converted number | `< 5000` | Included |
|---|---|---:|---|---|
| Mouse | `"1000"` | 1000 | true | Yes |
| Keyboard | `"3000"` | 3000 | true | Yes |
| Monitor | `"7000"` | 7000 | false | No |

**`find()` returns the first match or `undefined`:**

```javascript
const expensive = products.find(function (product) {
  return Number(product.dataset.price) > 5000;
});
console.log(expensive.textContent); // Monitor
```

**`some()` returns true if at least one matches:**

```javascript
const anyExpensive = products.some(function (product) {
  return Number(product.dataset.price) > 5000;
});
console.log(anyExpensive); // true
```

**`every()` returns true only if all match:**

```javascript
const allAffordable = products.every(function (product) {
  return Number(product.dataset.price) < 5000;
});
console.log(allAffordable); // false
```

| Method | Returns | Main purpose |
|---|---|---|
| `map()` | New array | Transform each value |
| `filter()` | New array | Keep matching values |
| `find()` | First matching value or `undefined` | Find one |
| `some()` | Boolean | Does any value match? |
| `every()` | Boolean | Do all values match? |

## 15. Mutation Pitfalls and Safe Removal

**Problem:** Removing items while iterating forward over a live collection can skip items.

```html
<ul>
  <li class="item">A</li>
  <li class="item">B</li>
  <li class="item">C</li>
  <li class="item">D</li>
</ul>
```

```javascript
const items = document.getElementsByClassName("item");
for (let i = 0; i < items.length; i++) {
  items[i].remove();
}
```

**Exact execution trace:**

| Step | `i` | Live collection before removal | Removed | Live collection after removal |
|---|---:|---|---|---|
| Start | 0 | A, B, C, D | - | A, B, C, D |
| 1 | 0 | A, B, C, D | A | B, C, D |
| 2 | 1 | B, C, D | C | B, D |
| Stop | 2 | B, D | - | B, D |

At the final check, `i < items.length` is `2 < 2`, which is false. B and D remain.

**Solution A: Remove the first item repeatedly:**

```javascript
while (items.length > 0) {
  items[0].remove();
}
```

**Solution B: Iterate backward:**

```javascript
for (let i = items.length - 1; i >= 0; i--) {
  items[i].remove();
}
```

`items.length - 1` is the last valid index; `i >= 0` means "i is greater than or equal to zero"; `i--` decrements i by one each iteration. Going backward prevents removal of the current element from shifting any *unvisited earlier* indexes.

**Solution C: Snapshot before removing:**

```javascript
Array.from(items).forEach(function (item) {
  item.remove();
});
```

The array's membership remains unchanged even as the live DOM collection shrinks.

## 16. Snapshots, References, and Cloning

```html
<p class="item">Original</p>
```

```javascript
const live = document.getElementsByClassName("item");
const snapshot = Array.from(live);

snapshot[0].textContent = "Updated";
console.log(live[0].textContent); // Updated

snapshot[0].remove();
console.log(live.length);     // 0
console.log(snapshot.length); // 1
```

The array is new, but its element reference points to the same DOM object. Removing the object from the document does not automatically remove the reference from the array.

**Cloning is different:**

```javascript
const clone = snapshot[0].cloneNode(true);
```

`cloneNode(true)` creates a new DOM node and recursively clones its descendants. The clone is detached until inserted. It does not automatically copy JavaScript event listeners registered using `addEventListener()`.

## 17. Performance and Memory

- Avoid repeatedly running the same query when the matches do not need refreshing.
- Use a static snapshot when you want predictable iteration while mutating the DOM.
- Use a live collection when automatically updated membership is genuinely helpful.
- Avoid retaining large collections or references to detached elements after they are no longer needed.
- Do not assume a method is always faster without profiling; rendering and layout can dominate DOM query costs.

```javascript
// Query once if repeated work needs the same elements.
const items = document.querySelectorAll(".item");
for (const item of items) {
  item.classList.add("processed");
}
```

## 18. Complete Project: Dynamic Task List

This project demonstrates live collections, safe text insertion, DOM creation, removal, and updating a count.

**index.html**

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Task List</title>
  <script src="script.js" defer></script>
</head>
<body>
  <h1>Task List</h1>
  <label for="taskInput">New task</label>
  <input id="taskInput" type="text" placeholder="Enter a task">
  <button id="addTask" type="button">Add Task</button>
  <ul id="taskList"></ul>
  <p id="taskCount" aria-live="polite">Total tasks: 0</p>
</body>
</html>
```

**script.js**

```javascript
const taskInput = document.getElementById("taskInput");
const addTaskButton = document.getElementById("addTask");
const taskList = document.getElementById("taskList");
const taskCount = document.getElementById("taskCount");

// Live HTMLCollection of li descendants of taskList.
const tasks = taskList.getElementsByTagName("li");

function updateCount() {
  taskCount.textContent = `Total tasks: ${tasks.length}`;
}

function addTask() {
  const taskText = taskInput.value.trim();

  if (taskText === "") {
    return;
  }

  const li = document.createElement("li");
  const label = document.createElement("span");
  label.textContent = taskText;

  const removeButton = document.createElement("button");
  removeButton.type = "button";
  removeButton.textContent = "Remove";

  removeButton.addEventListener("click", function () {
    li.remove();
    updateCount();
  });

  li.append(label, " ", removeButton);
  taskList.appendChild(li);
  taskInput.value = "";
  updateCount();
}

addTaskButton.addEventListener("click", addTask);
updateCount();
```

**Detailed explanation:**

1. `getElementById()` obtains references to four existing elements.
2. `getElementsByTagName("li")` creates a live collection scoped to the task list.
3. `function updateCount()` defines a reusable function.
4. The backticks in `` `Total tasks: ${tasks.length}` `` create a template literal; `${...}` inserts the evaluated length.
5. `taskInput.value` reads the current input string.
6. `.trim()` removes leading and trailing whitespace.
7. `=== ""` checks whether the trimmed text is empty.
8. `return;` exits `addTask()` without adding a blank item.
9. `createElement()` constructs a detached `li`, `span`, and button.
10. `label.textContent = taskText` inserts user text safely as text rather than parsing it as HTML.
11. `addEventListener("click", function () {...})` registers a callback that runs when that button is clicked.
12. `li.remove()` removes that specific task; the live collection automatically shrinks.
13. `li.append(label, " ", removeButton)` inserts the label, a space text node, and button into the task element.
14. `taskList.appendChild(li)` inserts the task into the page; the live collection automatically grows.
15. `taskInput.value = ""` clears the input.
16. `updateCount()` reads the live collection's current length and updates the display.

**Execution trace for adding two tasks and removing one:**

| Action | Live `tasks.length` | Display |
|---|---:|---|
| Page loads | 0 | Total tasks: 0 |
| Add "Read" | 1 | Total tasks: 1 |
| Add "Practice" | 2 | Total tasks: 2 |
| Remove "Read" | 1 | Total tasks: 1 |
| Try blank input | 1 | Total tasks: 1 |

**Why `defer`?** It lets the browser parse the document before executing this external classic script, so the selected elements exist.

## 19. Common Mistakes

| Mistake | Why it is a problem | Correct approach |
|---|---|---|
| `collection.length()` | `length` is a property | `collection.length` |
| `nodeList.map(...)` | NodeList has no native map | `Array.from(nodeList).map(...)` |
| `htmlCollection.forEach(...)` | HTMLCollection has no native forEach | `Array.from(htmlCollection).forEach(...)` |
| Assume all NodeLists are static | `childNodes` is live | Check the source API |
| Assume `children` includes text nodes | It contains only elements | Use `childNodes` for all nodes |
| Remove while iterating a live collection forward | Indexes shift | Use while, backward iteration, or snapshot |
| Assume a snapshot clones nodes | It copies references | Use `cloneNode()` when needed |
| Assume `collection[99]` is null | Missing bracket access returns undefined | Check for `undefined` |
| Assume `.item(99)` is undefined | It returns null | Check for `null` |
| Keep references to detached nodes indefinitely | Can retain memory | Release unused references |

## 20. Interview Questions and Answers

**1. What is an HTMLCollection?**  
An array-like collection of DOM elements. Common instances are live and update when the DOM changes.

**2. What is a NodeList?**  
An array-like collection of DOM nodes. It can be live or static depending on how it is obtained.

**3. What is the difference between `children` and `childNodes`?**  
`children` contains direct child elements; `childNodes` contains all direct child nodes, including text and comment nodes.

**4. Is `querySelectorAll()` live or static?**  
Static. Its membership does not automatically change when the DOM changes.

**5. Can you call `.map()` directly on a NodeList?**  
No. Convert it to an array with `Array.from()` or spread syntax first.

**6. What does `Array.from()` do?**  
It creates a new array from an iterable or array-like value. For DOM collections, the array contains references to the existing DOM nodes.

**7. Why can forward removal from an HTMLCollection skip elements?**  
Because the collection updates immediately and remaining elements shift to lower indexes.

**8. What is the difference between `collection[10]` and `collection.item(10)` for a missing index?**  
Bracket access returns `undefined`; `.item()` returns `null`.

**9. Does converting a collection to an array clone the elements?**  
No. It copies references to the same DOM elements.

**10. Which loop is convenient for removing all matching elements from a live collection?**  
A `while` loop that repeatedly removes `collection[0]` until `collection.length` is zero.

### Exercise 1: Count matching elements

```html
<p class="item">A</p>
<p class="item">B</p>
<p class="item">C</p>
```

**Task:** Print the number of matching elements.

**Solution:**

```javascript
const items = document.getElementsByClassName("item");

```

`getElementsByClassName` returns a live `HTMLCollection`; `.length` reads its current size.

### Exercise 2: Read the second item

**Task:** Print `B`.

**Solution:**

```javascript
const items = document.querySelectorAll(".item");
console.log(items[1].textContent); // B
```

Indexes start at zero, so index 1 is the second element.

### Exercise 3: Print every item using for

**Solution:**

```javascript
const items = document.querySelectorAll(".item");
for (let i = 0; i < items.length; i++) {
  console.log(items[i].textContent);
}
// A, B, C
```

Trace: `i=0` prints A, `i=1` prints B, `i=2` prints C, `i=3` fails the condition and stops.

### Exercise 4: Print every item using for...of

**Solution:**

```javascript
const items = document.querySelectorAll(".item");
for (const item of items) {
  console.log(item.textContent);
}
// A, B, C
```

`item` refers to each DOM element in sequence; no manual index is required.

### Exercise 5: Print every item using forEach

**Solution:**

```javascript
const items = document.querySelectorAll(".item");
items.forEach(function (item) {
  console.log(item.textContent);
});
// A, B, C
```

The callback runs once for each element in the `NodeList`.

### Exercise 6: Convert a NodeList into an array

**Solution:**

```javascript
const items = document.querySelectorAll(".item");
const array = Array.from(items);
console.log(Array.isArray(array)); // true
console.log(array.length);         // 3
```

`Array.from` creates a new array; it does not clone the underlying DOM elements.

### Exercise 7: Extract text using map

**Solution:**

```javascript
const items = document.querySelectorAll(".item");
const texts = Array.from(items).map(function (item) {
  return item.textContent;
});
console.log(texts); // ["A", "B", "C"]
```

`map` transforms each element reference into its text string and returns a new array.

### Exercise 8: Remove all matching elements safely

**Solution:**

```javascript
const items = document.getElementsByClassName("item");
while (items.length > 0) {
  items[0].remove();
}
console.log(items.length); // 0
```

The live collection shrinks after each removal. Always removing index 0 avoids skipping items.

### Exercise 9: Filter products by price

```html
<div class="product" data-price="1000">Mouse</div>
<div class="product" data-price="7000">Monitor</div>
<div class="product" data-price="3000">Keyboard</div>
```

**Task:** Print names of products costing less than 5000 using (A) a plain loop and (B) array methods.

**Solution A - plain loop:**

```javascript
const products = document.querySelectorAll(".product");
for (let i = 0; i < products.length; i++) {
  const price = Number(products[i].dataset.price);
  if (price < 5000) {
    console.log(products[i].textContent);
  }
}
// Mouse, Keyboard
```

**Solution B - built-in methods:**

```javascript
const products = Array.from(document.querySelectorAll(".product"));
products
  .filter(function (product) {
    return Number(product.dataset.price) < 5000;
  })
  .forEach(function (product) {
    console.log(product.textContent);
  });
// Mouse, Keyboard
```

**Trace:** Mouse: 1000 < 5000 is true; Monitor: 7000 < 5000 is false; Keyboard: 3000 < 5000 is true. Both approaches print Mouse and Keyboard.

### Exercise 10: Compare live and static collections

```html
<div id="container">
  <p class="item">One</p>
  <p class="item">Two</p>
</div>
```

**Task:** Select with both collection types, append a matching element, and print their lengths.

**Solution:**

```javascript
const liveItems = document.getElementsByClassName("item");
const staticItems = document.querySelectorAll(".item");

console.log(liveItems.length);   // 2
console.log(staticItems.length); // 2

const newItem = document.createElement("p");
newItem.className = "item";
newItem.textContent = "Three";
document.getElementById("container").appendChild(newItem);

console.log(liveItems.length);   // 3
console.log(staticItems.length); // 2
```

**Trace:** The initial queries both match two items. `createElement` creates a detached element, so neither collection changes. Appending inserts it into the document: the live collection grows to 3, while the static collection stays at 2.

## 23. Summary and Navigation

- `HTMLCollection` contains elements and is commonly live.
- `NodeList` contains nodes and may be live or static depending on its source.
- `querySelectorAll()` returns a static `NodeList`.
- `children` is a live `HTMLCollection` of element children; `childNodes` is a live `NodeList` of all direct child nodes.
- Both collection types support indexes and `.length`, but they are not arrays.
- Convert to arrays to use `.map()`, `.filter()`, and other array-only methods.
- Be careful when modifying a live collection during iteration.
- A collection snapshot stores references to nodes, not cloned nodes.

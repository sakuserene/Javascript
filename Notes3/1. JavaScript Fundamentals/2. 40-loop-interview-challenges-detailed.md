### 1.1 Shopping cart subtotal

**Difficulty:** Intermediate.

**Interviewer:** "You are given the data below. Build a solution for **shopping cart subtotal** using a traditional for loop. Explain each variable, the loop termination condition, and why your output is correct. Do not hard-code the result."

**Input provided by the interviewer:**

```javascript
const prices = [19.99, 5.5, 12.25];
```

**Your tasks:** Describe the algorithm, implement it, predict the output, trace the loop by hand, and discuss one edge case.

#### Complete code answer

```javascript
const prices = [19.99, 5.5, 12.25];
let total = 0;
for (let i = 0; i < prices.length; i++) total += prices[i];
console.log(total.toFixed(2));
```

#### Expected console output

```text
37.74
```

#### Step-by-step explanation: separate code pieces

**Step 1 - Set up or execute**

```javascript
const prices = [19.99, 5.5, 12.25];
```

Declare `prices` and assign its starting data. Arrays use `[ ]` to hold ordered items; objects use `{ }` for named properties. This prepares the input or result collection.

**Step 2 - Understand this statement**

```javascript
let total = 0;
```

Declare `total` and give it an initial value. This is the starting state used by later loop iterations; check whether it must reset for each outer-loop pass.

**Step 3 - Understand this statement**

```javascript
for (let i = 0; i < prices.length; i++) total += prices[i];
```

This is the loop header. **Initialize:** `let i = 0` (once). **Check:** `i < prices.length` before each pass. **Update:** `i++` after each completed pass. If the condition is false, the body is skipped.

**Step 4 - Understand this statement**

```javascript
console.log(total.toFixed(2));
```

`console.log(...)` displays the final value or intermediate result. It does not change the underlying calculation.

#### Hand-worked execution trace

1. 19.99 + 5.50 + 12.25 = 37.74.
2. The running total changes from 0 to 19.99, then 25.49, then 37.74.
3. Compare the final computed value with the expected console output. Walk through the loop condition one additional time to see why iteration stops.

#### Interview follow-up

**Question:** What changes if the input array is empty?

**How to approach it:** State your assumptions, identify the affected line or condition, and describe one concrete test case. Avoid changing the algorithm until you know which behavior should be preserved.

#### Complexity discussion

- **Time:** O(n) for a single pass; a fixed number of months/pages is constant for fixed-size input.
- **Space:** Depends on whether the solution only accumulates a scalar or stores a result collection. Output arrays require additional space proportional to the number of results.

## Glossary

- **Accumulator:** A variable storing a running result such as a sum or count.
- **Index:** The zero-based position of an element in an array.
- **Iteration:** One execution of a loop body.
- **Outer loop:** The enclosing loop that chooses a group, row, or dimension.
- **Inner loop:** The loop that visits elements within the selected outer group.
- **Deep nested loop:** Three or more loops arranged inside one another.
- **Predicate:** A function or expression evaluated as true or false.
- **Short-circuit:** Stop evaluating further elements after a decisive result.
- **Time complexity:** How the amount of work grows as input grows.

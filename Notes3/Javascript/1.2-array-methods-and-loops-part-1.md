## 1. Understanding iteration

Iteration is the process of repeatedly performing an operation.

When working with arrays, iteration commonly involves visiting elements one after another and performing an operation on each element.

Consider the following array:

```javascript
const numbers = [10, 20, 30, 40, 50];
```

Suppose we want to display every number.

Without iteration, we could write:

```javascript
console.log(numbers[0]);
console.log(numbers[1]);
console.log(numbers[2]);
console.log(numbers[3]);
console.log(numbers[4]);
```

Output:

```text
10
20
30
40
50
```

This works, but what happens if the array contains 10,000 elements?

Writing 10,000 statements would be impractical.

Instead, we can use a loop:

```javascript
for (let i = 0; i < numbers.length; i++) {
    console.log(numbers[i]);
}
```

The output remains the same:

```text
10
20
30
40
50
```

The difference is that our loop automatically adapts to the number of elements in the array.

### Visualizing iteration

```text
Index:  0    1    2    3    4
Value: [10] [20] [30] [40] [50]
        -->  -->  -->  -->  --> end
```

| Current index | Condition | Current element | Output so far |
|---:|---|---:|---|
| 0 | `0 < 5` true | 10 | 10 |
| 1 | `1 < 5` true | 20 | 10, 20 |
| 2 | `2 < 5` true | 30 | 10, 20, 30 |
| 3 | `3 < 5` true | 40 | 10, 20, 30, 40 |
| 4 | `4 < 5` true | 50 | 10, 20, 30, 40, 50 |
| 5 | `5 < 5` false | None | 10, 20, 30, 40, 50 |

The loop visits each index, accesses the corresponding value, performs the operation and moves to the next index.

### Iteration, traversal and looping

These terms are closely related, but they do not mean exactly the same thing.

| Term | Meaning |
|---|---|
| Iteration | Repeatedly performing an operation |
| Iteration step | One repetition |
| Traversal | Visiting elements of a data structure |
| Loop | A construct that repeats instructions |
| Counter | Tracks repetitions or quantities |
| Iterator | Object that produces values through an iteration protocol |
| Iterable | Value supporting the iterable protocol |
| Accumulator | Stores a progressively calculated result |

For example, we can iterate without using an array:

```javascript
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
```

Output:

```text
1
2
3
4
5
```

Here we are generating numbers rather than traversing an existing collection.

This is our first example of something plain loops can accomplish without requiring an array.

## 2. Plain loops

JavaScript provides several loop statements.

| Loop | Typical purpose |
|---|---|
| `for` | Counter-controlled repetition |
| `while` | Condition-controlled repetition |
| `do...while` | Execute at least once, then repeat conditionally |
| `for...of` | Traverse iterable values |
| `for...in` | Enumerate enumerable string properties |
| Nested loops | Repeat operations inside other loops |

Nested loops are not a separate JavaScript statement. They are a combination of existing loop statements.

We will begin with the ordinary `for` loop because it provides precise control over indexes, direction, boundaries and repetition.

### The for loop

```javascript
for (initialization; condition; update) {
    // Instructions to repeat
}
```

```javascript
for (let i = 0; i < 4; i++) {
    console.log(i);
}
```

Output: `0, 1, 2, 3` (on separate lines).

The loop consists of four important parts.

#### Initialization

```javascript
let i = 0;
```

- `let` declares a reassignable variable.
- `i` is the variable name.
- `=` assigns a value.
- `0` is the starting value.

The initialization runs only once.

The variable name `i` is a convention, not a requirement.

We could also write:

```javascript
for (let index = 0; index < 4; index++) {
    console.log(index);
}
```

#### Condition

```javascript
i < 4
```

The condition determines whether another iteration should occur.

When the condition evaluates to `true`, the loop body executes. When it evaluates to `false`, the loop terminates.

#### Update

```javascript
i++
```

The increment operator increases `i` by one.

In this loop's update clause, it has the same effect as:

```javascript
i += 1
```

Or:

```javascript
i = i + 1
```

These expressions have different expression return values in some contexts, but their effect on this counter is equivalent.

#### Loop body

```javascript
{
    console.log(i);
}
```

The body contains the instructions that execute whenever the condition is truthy.

### Execution order

```text
Initialize --> Condition -- false --> End
                  |
                 true
                  v
                 Body --> Update --+
                  ^                |
                  +-- Condition <--+
```

| Step | i | Condition | Output | After update |
|---:|---:|---|---:|---:|
| 1 | 0 | true | 0 | 1 |
| 2 | 1 | true | 1 | 2 |
| 3 | 2 | true | 2 | 3 |
| 4 | 3 | true | 3 | 4 |
| 5 | 4 | false | None | No update |

The condition is checked five times, but the body executes four times.

### Forward iteration

Suppose a library has a list of available books and wants to display them in their original order.

```javascript
const books = ["The Hobbit", "Dune", "Foundation", "Dracula"];
for (let i = 0; i < books.length; i++) {
    console.log(`${i + 1}. ${books[i]}`);
}
```

```text
1. The Hobbit
2. Dune
3. Foundation
4. Dracula
```

Notice the difference between:

```javascript
i
```

And:

```javascript
books[i]
```

`i` represents the index, whereas `books[i]` represents the value stored at that index.

We use `i + 1` for the displayed numbering because humans commonly start counting at one, while array indexes start at zero.

The expression `i + 1` does not modify `i`.

### Backward iteration

Sometimes we need to process elements from the end toward the beginning.

For example, display recorded activities from newest to oldest.

```javascript
const activities = ["Account created", "Profile updated", "Photo uploaded", "Password changed"];
for (let i = activities.length - 1; i >= 0; i--) {
    console.log(activities[i]);
}
```

```text
Password changed
Photo uploaded
Profile updated
Account created
```

| Component | Forward | Backward |
|---|---|---|
| Start | 0 | length - 1 |
| Condition | `i < length` | `i >= 0` |
| Update | `i++` | `i--` |

Backward traversal is useful for `lastIndexOf`, `findLast`, `findLastIndex`, `reduceRight`, reverse searching and in-place removal.

### Iterating with different step sizes

A loop does not have to visit every element.

Suppose a sensor records a measurement every hour, but we only want to inspect measurements recorded every three hours.

```javascript
const measurements = [12, 15, 18, 21, 24, 27, 30, 33, 36, 39, 42, 45];
for (let i = 0; i < measurements.length; i += 3) {
    console.log(`Index ${i}: ${measurements[i]}`);
}
```

```text
Index 0: 12
Index 3: 21
Index 6: 30
Index 9: 39
```

Instead of incrementing by one, we increment by three.

This is called strided iteration.

It is useful for sampling, processing fixed-size groups, skipping positions and working with structured data.

#### Array method alternative

We could achieve the same result using `filter()`:

```javascript
const selected = measurements.filter((value, index) => index % 3 === 0);
console.log(selected); // [12, 21, 30, 39]
```

However, there is an important difference.

The loop visits only the required indexes. The `filter()` method evaluates its callback for every existing element in this dense array.

| Approach | Elements examined |
|---|---:|
| Strided loop | 4 |
| `filter()` | 12 |

The loop provides more direct control over which positions are visited.

### Iterating through a specific range

Sometimes we do not want to process the entire array.

Suppose we have seven daily rainfall measurements and only want to inspect the third, fourth and fifth days.

```javascript
const rainfall = [5, 12, 8, 20, 14, 3, 9];
for (let i = 2; i < 5; i++) {
    console.log(rainfall[i]);
}
// 8, 20, 14 (separate lines)
```

The start is inclusive and end exclusive, as with `slice` and `fill`.

```javascript
rainfall.slice(2, 5).forEach(value => console.log(value));
```

The loop avoids creating the intermediate slice.

Experiment with `[10,20,30,40,50,60,70,80]`: start 1, end 7, step 2 visits indexes 1, 3, 5 and values 20, 40, 60. Change the boundaries and predict the output.

### Iterating without an existing array

Array methods generally process existing collections. Plain loops can generate values independently.

#### Generating a sequence

Suppose we want to generate the first ten positive multiples of seven.

```javascript
const multiples = [];
for (let i = 1; i <= 10; i++) {
    multiples[multiples.length] = i * 7;
}
console.log(multiples);
// [7, 14, 21, 28, 35, 42, 49, 56, 63, 70]
```

Notice that we have not used any array methods.

The expression:

```javascript
multiples[multiples.length] = i * 7;
```

Appends a value to the array.

Initially, the length is zero, so the first assignment is equivalent to:

```javascript
multiples[0] = 7;
```

The length automatically becomes one.

During the next iteration:

```javascript
multiples[1] = 14;
```

This is the fundamental append operation behind many of the algorithms we will develop.

We could also use:

```javascript
multiples.push(i * 7);
```

But we will sometimes deliberately avoid array methods to understand the underlying logic.

#### Generating a numerical range

We can write a reusable function that generates an inclusive range.

```javascript
function range(start, end, step = 1) {
    if (!Number.isSafeInteger(start) ||
        !Number.isSafeInteger(end) ||
        !Number.isSafeInteger(step) || step <= 0) {
        throw new RangeError("Invalid range arguments");
    }
    const result = [];
    for (let i = start; i <= end; i += step) {
        result[result.length] = i;
    }
    return result;
}
console.log(range(3, 8)); // [3, 4, 5, 6, 7, 8]
console.log(range(10, 30, 5)); // [10, 15, 20, 25, 30]
console.log(range(8, 3)); // []
```

Supports ascending integer ranges and positive steps, not descending or fractional ranges. Production code should enforce a maximum result size.

### Multiple counters

A `for` loop can maintain more than one counter.

Suppose we want to inspect elements in pairs, beginning from opposite ends.

```javascript
const letters = ["A", "B", "C", "D", "E", "F"];
for (let left = 0, right = letters.length - 1;
     left < right;
     left++, right--) {
    console.log(letters[left], letters[right]);
}
```

```text
A F
B E
C D
```

The declaration creates two variables. The condition checks whether left precedes right. The comma operator evaluates the updates left to right.

| Iteration | left | right | Pair |
|---:|---:|---:|---|
| 1 | 0 | 5 | A, F |
| 2 | 1 | 4 | B, E |
| 3 | 2 | 3 | C, D |
| Stop | 3 | 2 | Condition false |

This is the two-pointer technique, useful for reversal, palindromes, pair searching and partitioning.

### Omitting clauses in a `for` loop

All three clauses in a `for` loop are optional.

For example, the initialization can occur outside the loop:

```javascript
let i = 0;
for (; i < 3; i++) {
    console.log(i);
}
```

```javascript
for (let i = 0; i < 3;) {
    console.log(i);
    i++;
}
```

```javascript
for (let i = 0;; i++) {
    if (i === 3) {
        break;
    }
    console.log(i);
}
```

```javascript
let i = 0;
for (;;) {
    if (i === 3) {
        break;
    }
    console.log(i);
    i++;
}
```

All produce 0, 1, 2 on separate lines. An omitted condition is always true; another termination mechanism is necessary unless indefinite repetition is intended.

### Variable step sizes

The update does not have to be addition or subtraction.

Suppose we want to display powers of two that do not exceed 128.

```javascript
for (let number = 1; number <= 128; number *= 2) {
    console.log(number);
}
// 1, 2, 4, 8, 16, 32, 64, 128 (separate lines)
```

`number *= 2` means `number = number * 2`. Useful for exponential growth and logarithmic algorithms.

| Update | Example sequence |
|---|---|
| `i++` | 0, 1, 2, 3, 4 |
| `i += 2` | 0, 2, 4, 6, 8 |
| `i--` | 5, 4, 3, 2, 1 |
| `i *= 2` | 1, 2, 4, 8, 16 |
| `i /= 2` | 32, 16, 8, 4, 2 |
| `i = i * i` | 2, 4, 16, 256 |

Choose starting values and termination carefully: doubling zero never changes it.

### The `while` loop

A `for` loop is convenient when we have a recognizable initialization, condition and update.

However, sometimes we do not know how many iterations will be required.

The `while` loop repeats instructions as long as its condition remains truthy.

```javascript
while (condition) {
    // Instructions
}
```

A tank contains 100 litres; a machine consumes 15 per operation.

```javascript
let water = 100;
let operations = 0;
while (water >= 15) {
    water -= 15;
    operations++;
    console.log(`Operation ${operations}: ${water} litres remaining`);
}
console.log(`Total operations: ${operations}`);
```

```text
Operation 1: 85 litres remaining
Operation 2: 70 litres remaining
Operation 3: 55 litres remaining
Operation 4: 40 litres remaining
Operation 5: 25 litres remaining
Operation 6: 10 litres remaining
Total operations: 6
```

The remaining water sequence is 100 -> 85 -> 70 -> 55 -> 40 -> 25 -> 10. The number of repetitions need not be known beforehand.

```javascript
const cities = ["Tokyo", "Cairo", "Oslo"];
let i = 0;
while (i < cities.length) {
    console.log(cities[i]);
    i++;
}
```

Equivalent to `for (let i = 0; i < cities.length; i++) { console.log(cities[i]); }`. Both print Tokyo, Cairo, Oslo on separate lines.

#### Processing digits

```javascript
let number = 5832;
let sum = 0;
while (number > 0) {
    const digit = number % 10;
    sum += digit;
    number = Math.floor(number / 10);
}
console.log(sum); // 18
```

Remainder extracts the last decimal digit; floor division removes it for nonnegative integers. Assumes a nonnegative safe integer.

| Before | Digit | Sum | After |
|---:|---:|---:|---:|
| 5832 | 2 | 2 | 583 |
| 583 | 3 | 5 | 58 |
| 58 | 8 | 13 | 5 |
| 5 | 5 | 18 | 0 |

### The `do...while` loop

The `do...while` loop is similar to `while`, except that its condition is checked after executing the body.

```javascript
do {
    // Instructions
} while (condition);
```

Therefore, its body executes at least once when control reaches the loop.

Consider:

```javascript
let number = 10;
do {
    console.log(number);
    number++;
} while (number < 5);
// 10
```

```javascript
let number = 10;
while (number < 5) {
    console.log(number);
    number++;
}
// No output
```

`while` checks first; `do...while` executes first and checks afterward.

#### Pagination simulation

```javascript
function getPage(page) {
    return { page: page, totalPages: 3 };
}
let page = 1;
let response;
do {
    response = getPage(page);
    console.log(`Processing page ${response.page}`);
    page++;
} while (page <= response.totalPages);
```

```text
Processing page 1
Processing page 2
Processing page 3
```

The first operation is necessary before the continuation condition can be determined.

### The `for...of` loop

When we only need the values of an array, maintaining a counter manually may be unnecessary.

JavaScript provides `for...of`:

```javascript
const languages = ["JavaScript", "Python", "Rust"];
for (const language of languages) {
    console.log(language);
}
```

Output: JavaScript, Python, Rust on separate lines. `for (const value of iterable)` obtains values through the iterable protocol, which also supports strings, sets and maps.

```javascript
const planets = ["Mercury", "Venus", "Earth"];
for (const [index, planet] of planets.entries()) {
    console.log(index, planet);
}
```

```text
0 Mercury
1 Venus
2 Earth
```

`entries()` yields index-value pairs, destructured into `index` and `planet`.

```javascript
const numbers = [2, 4, 6];
for (let number of numbers) {
    number *= 10;
}
console.log(numbers); // [2, 4, 6]
for (let i = 0; i < numbers.length; i++) {
    numbers[i] *= 10;
}
console.log(numbers); // [20, 40, 60]
```

Reassigning a primitive loop variable does not modify the array. Indexed assignment does.

```javascript
const products = [
    { name: "Notebook", stock: 10 },
    { name: "Pencil", stock: 20 }
];
for (const product of products) {
    product.stock += 5;
}
console.log(products);
// [{ name: "Notebook", stock: 15 }, { name: "Pencil", stock: 25 }]
```

Objects are shared through reference values, so property mutation affects the original objects.

### The for...in loop

```javascript
const colors = ["Red", "Green", "Blue"];
for (const key in colors) {
    console.log(key, colors[key]);
}
// 0 Red\n1 Green\n2 Blue
for (const key in colors) {
    console.log(typeof key);
}
// string, string, string (separate lines)
colors.description = "Primary display colors";
for (const key in colors) {
    console.log(key, colors[key]);
}
```

```text
0 Red
1 Green
2 Blue
description Primary display colors
```

`for...in` enumerates enumerable string keys, including inherited enumerable properties. Prefer `for`, `for...of` or an array method for normal array traversal.

## 3. Controlling loop execution

So far, our loops have continued until their normal termination conditions were reached.

But sometimes we need to skip particular elements, terminate early or control an outer loop from inside an inner loop.

JavaScript provides `break` and `continue`.

### The `break` statement

The `break` statement immediately exits the nearest enclosing loop or switch statement, unless a label specifies another valid target.

Suppose we have an array of equipment identification numbers and want to determine whether equipment number 104 exists.

```javascript
const equipment = [101, 102, 104, 107, 110];
let found = false;
for (let i = 0; i < equipment.length; i++) {
    if (equipment[i] === 104) {
        found = true;
        break;
    }
}
console.log(found); // true
```

101 and 102 are checked, 104 is found, and 107 and 110 are not visited. `break` exits the nearest loop or switch unless a valid label specifies another target.

```javascript
const found = equipment.includes(104);
console.log(found); // true
```

The native method uses SameValueZero equality, unlike the strict equality in our loop. They differ for `NaN`.

### The `continue` statement

The `continue` statement skips the remaining instructions in the current iteration and proceeds to the next iteration.

Suppose a weather station uses `null` to represent missing readings.

We want to display only available readings.

```javascript
const readings = [24, null, 28, null, 31];
for (let i = 0; i < readings.length; i++) {
    if (readings[i] === null) {
        continue;
    }
    console.log(readings[i]);
}
// 24, 28, 31 (separate lines)
```

```javascript
readings.filter(reading => reading !== null)
    .forEach(reading => console.log(reading));
```

The loop filters and displays in one traversal without an intermediate array.

| Behavior | break | continue |
|---|---|---|
| Skip remaining body | Yes | Yes |
| Terminate loop | Yes | No |
| Next iteration | No | If condition permits |

Experiment:

```javascript
for (let i = 1; i <= 5; i++) {
    if (i === 3) {
        continue; // Replace with break and compare.
    }
    console.log(i);
}
```

With `continue`: 1, 2, 4, 5. With `break`: 1, 2.

#### A while loop mistake

```javascript
// WARNING: Infinite loop. Do not execute as written.
let i = 0;
while (i < 5) {
    if (i === 2) {
        continue;
    }
    console.log(i);
    i++;
}
```

The increment is skipped when i reaches two. Correct it:

```javascript
let i = 0;
while (i < 5) {
    if (i === 2) {
        i++;
        continue;
    }
    console.log(i);
    i++;
}
// 0, 1, 3, 4 (separate lines)
```

In a `for` loop, `continue` normally transfers control to the update clause before checking the condition again.

## 4. Fundamental loop problem-solving patterns

### Pattern 1: Traversal

Display laboratory sample identifiers.

```javascript
const samples = ["S101", "S102", "S103"];
for (const sample of samples) {
    console.log(`Inspecting ${sample}`);
}
// Array method alternative:
samples.forEach(sample => console.log(`Inspecting ${sample}`));
```

Each approach prints:

```text
Inspecting S101
Inspecting S102
Inspecting S103
```

### Pattern 2: Counting

```javascript
const components = ["good", "defective", "good", "defective", "defective"];
let count = 0;
for (const component of components) {
    if (component === "defective") {
        count++;
    }
}
console.log(count); // 3
```

| Component | Matches? | Count |
|---|---|---:|
| good | No | 0 |
| defective | Yes | 1 |
| good | No | 1 |
| defective | Yes | 2 |
| defective | Yes | 3 |

```javascript
const count = components.filter(component => component === "defective").length;
// Alternative (run separately):
const countWithReduce = components.reduce((total, component) => {
    return total + (component === "defective" ? 1 : 0);
}, 0);
```

There is no standard array `count()` method.

### Pattern 3: Accumulation

```javascript
const distances = [12, 18, 9, 25, 16];
let total = 0;
for (const distance of distances) {
    total += distance;
}
console.log(total); // 80
```

| Distance | Previous total | New total |
|---:|---:|---:|
| 12 | 0 | 12 |
| 18 | 12 | 30 |
| 9 | 30 | 39 |
| 25 | 39 | 64 |
| 16 | 64 | 80 |

```javascript
const total = distances.reduce((sum, distance) => sum + distance, 0);
```

Both carry a calculated result from one iteration to the next.

### Pattern 4: Collection

Collect books with at least 300 pages.

```javascript
const books = [
    { title: "Book A", pages: 180 },
    { title: "Book B", pages: 350 },
    { title: "Book C", pages: 240 },
    { title: "Book D", pages: 420 }
];
const selected = [];
for (const book of books) {
    if (book.pages >= 300) {
        selected[selected.length] = book;
    }
}
console.log(selected);
```

```javascript
// Output:
[
    { title: "Book B", pages: 350 },
    { title: "Book D", pages: 420 }
]
```

```javascript
const selected = books.filter(book => book.pages >= 300);
```

Create an empty result, visit each element, append matching elements, return the result. This is the basic filtering algorithm.

### Pattern 5: Transformation

```javascript
const metres = [1.5, 2, 3.2, 4];
const centimetres = [];
for (let i = 0; i < metres.length; i++) {
    centimetres[i] = metres[i] * 100;
}
console.log(centimetres); // [150, 200, 320, 400]
```

```javascript
const centimetres = metres.map(value => value * 100);
```

Create a result array, visit each element, transform it, store the transformed value. This is the basic map algorithm for dense arrays.

### Pattern 6: Tracking the best candidate

```javascript
const speeds = [18, 35, 22, 41, 29];
let highest = speeds[0];
for (let i = 1; i < speeds.length; i++) {
    if (speeds[i] > highest) {
        highest = speeds[i];
    }
}
console.log(highest); // 41
```

| Current | Previous highest | New highest |
|---:|---|---:|
| 18 | Initial | 18 |
| 35 | 18 | 35 |
| 22 | 35 | 35 |
| 41 | 35 | 41 |
| 29 | 41 | 41 |

Initializing to zero fails for all-negative arrays such as `[-15, -8, -20]`. Handle empty input explicitly.

```javascript
function maximum(numbers) {
    if (numbers.length === 0) {
        return undefined;
    }
    let highest = numbers[0];
    for (let i = 1; i < numbers.length; i++) {
        if (numbers[i] > highest) {
            highest = numbers[i];
        }
    }
    return highest;
}
console.log(maximum([-15, -8, -20])); // -8
console.log(maximum([])); // undefined
```

Assumes a dense array of valid numbers.

```javascript
const highest = speeds.reduce((best, current) => current > best ? current : best);
```

This reduction requires a nonempty dense array.

### Pattern 7: State tracking

```javascript
const measurements = [12, 15, 13, 18, 21, 17];
let increases = 0;
for (let i = 1; i < measurements.length; i++) {
    if (measurements[i] > measurements[i - 1]) {
        increases++;
    }
}
console.log(increases); // 3
```

| Previous | Current | Increased? | Count |
|---:|---:|---|---:|
| 12 | 15 | Yes | 1 |
| 15 | 13 | No | 1 |
| 13 | 18 | Yes | 2 |
| 18 | 21 | Yes | 3 |
| 21 | 17 | No | 3 |

`measurements[i - 1]` accesses the preceding element. Start at one because zero has no predecessor. Useful for trends, consecutive sequences and local peaks.

## 5. Combining multiple operations in one loop

One of the greatest advantages of plain loops is that we can perform several related operations during a single traversal.

Suppose a laboratory records the following measurements.

We want to calculate:

- The total.
- The average.
- The highest reading.
- The lowest reading.
- The number of readings above 30.
- An array containing those high readings.

Using array methods, we could write:

```javascript
const readings = [18, 32, 25, 41, 12, 36];
const total = readings.reduce((sum, value) => sum + value, 0);
const average = total / readings.length;
const highest = Math.max(...readings);
const lowest = Math.min(...readings);
const highReadings = readings.filter(value => value > 30);
const highCount = highReadings.length;
```

This is readable and perfectly reasonable for a small array.

However, it performs multiple operations over the collection.

We can combine them into a single plain loop (run separately):

```javascript
const readings = [18, 32, 25, 41, 12, 36];
let total = 0;
let highest = readings[0];
let lowest = readings[0];
let highCount = 0;
const highReadings = [];
for (const reading of readings) {
    total += reading;
    if (reading > highest) {
        highest = reading;
    }
    if (reading < lowest) {
        lowest = reading;
    }
    if (reading > 30) {
        highCount++;
        highReadings[highReadings.length] = reading;
    }
}
const average = total / readings.length;
console.log({ total, average, highest, lowest, highCount, highReadings });
```

```javascript
// Output:
{
    total: 164,
    average: 27.333333333333332,
    highest: 41,
    lowest: 12,
    highCount: 3,
    highReadings: [32, 41, 36]
}
```

| Reading | Total | Highest | Lowest | High count |
|---:|---:|---:|---:|---:|
| 18 | 18 | 18 | 18 | 0 |
| 32 | 50 | 32 | 18 | 1 |
| 25 | 75 | 32 | 18 | 1 |
| 41 | 116 | 41 | 18 | 2 |
| 12 | 128 | 41 | 12 | 2 |
| 36 | 164 | 41 | 12 | 3 |

Loop fusion combines compatible operations into one traversal. Both approaches are O(n) under ordinary assumptions. Actual performance depends on the engine, data and implementation. Define behavior for empty arrays and invalid measurements in production.

## 6. Choosing the appropriate loop

| Requirement | Suitable approach |
|---|---|
| Visit every value | `for...of` |
| Direct indexes | `for` |
| Backward traversal | `for` |
| Fixed strides | `for` |
| Multiple pointers | `for` or `while` |
| Changing condition | `while` |
| Execute at least once | `do...while` |
| Enumerate properties | `for...in` |
| Stop at match | `break` |
| Skip unwanted values | `continue` |
| Generate sequences | `for` or `while` |
| Several operations together | Plain loop |
| Transform | `map` or loop |
| Collect matches | `filter` or loop |
| Combined result | `reduce` or loop |

No loop is universally best. Choose based on control, readability and behavior.
